# AI Playground Android v1.19.0

- 設定画面をWeb版と同じ見た目と構成にしました。10個のタブ（一般、APIキー、プロンプト、表示、データ、アカウント、セキュリティ、2要素認証、フィードバック、MCP）で、スマートフォンでは横に並び、タブレットでは左側に縦に並びます。
- 設定の検索で、一致した件数と項目の一覧を表示するようにしました。項目を押すと、そのタブの該当する設定へ移動します。
- APIキーをアプリ内で設定できるようにしました。OpenAI、Gemini、DeepSeek、Kimi、Mistral、Anthropic、xAI、Google（TTS）のキー、Geminiの接続方式（Gemini API／Vertex AI）、モデル別のAPIキーを設定できます。保存済みのキーは表示しません。
- プロンプトタブで、自動注入システムプロンプトを項目ごとにオン・オフし、文面を編集できるようにしました。
- 一般タブに、LLM文字起こしプロンプト、Gemini音声/動画 + Python の確認、一時チャットの切断タイムアウトの設定を追加しました。
- 表示タブで、テーマ色を色の選択画面から選べるようにしました。
- データタブに、レスポンス速度の計測とデバッグログの拡張送信の設定を追加しました。
- 入力欄の Compress の歯車から「画像・圧縮詳細設定」を開けるようにしました。画像の生成設定もここで変更できます。
- 設定の「画像圧縮」「セッション」タブはなくなりました。画像圧縮は「画像・圧縮詳細設定」で変更します。
