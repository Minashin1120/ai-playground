# Update Log (2026-04-14) - V4.8.417

## 修正と改善
* **PDF生成機能のさらなる改善**: 前回の修正でも要素（特に画像やテーブル）の上部がわずかに途切れる場合があったため、さらなる対策を実施しました。
  * **画像読み込み待機**: キャプチャ前に全ての画像がロードされるのを待機するロジックを追加し、レンダリング漏れを防止。
  * **`onclone` コールの活用**: `html2canvas` のクローン作成時に座標（left/top）を強制的に `0` にリセットし、親要素の影響を完全に排除。
  * **微小オフセットの導入**: PDFへの画像配置時（`addImage`）に上方向に `0.1mm` のオフセットを追加し、ページ境界でのクリッピングを緩和。
  * **JPEG品質の向上**: `toDataURL` の品質を `0.9` に引き上げ、視認性を向上。

## システム更新
* `APP_VERSION` を `2026-04-14-002` に更新。
* フロントエンドのリソースを `V4.8.417` に更新。
