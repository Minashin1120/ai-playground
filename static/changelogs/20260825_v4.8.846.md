# 更新履歴 - V4.8.846 (2026-08-25)

ミニマル表示のプロンプトバーで、プラスボタンを押すと通常表示・コンパクト表示と同じ設定項目（Search、Python、Canvas、Coding、高速、Thinking、Compress など）を変更できるポップアップが開くようになりました。画像モデルなど追加の設定パラメータを持つモデルの設定パネルは、ミニマル表示ではインラインに表示せず、このポップアップ内の「モデル設定」から変更できます。Thinking はポップアップで有効化すると、プロンプトバーの上に一時的な推論レベル調整スライダーがアニメーション付きで表示され、操作終了を検出すると自動で非表示になります。スライダーは下へスワイプしても閉じられます。
