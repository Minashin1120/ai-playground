# v4.8.743 — ランディングページの操作画面デモが表示されない問題を修正

- ランディングページの操作画面デモ（自動再生のチャットUI）とアニメーション付きSVGのマルチモデルハブが、**表示されない問題**を修正しました。
- 原因: Cloudflare Rocket Loader がページの `<script>` を専用タイプへ書き換えて読み込みを遅延させるため、従来 `DOMContentLoaded` を待って実行していた初期化処理（`window.LandingDemo.initDemo()`）が呼ばれない状態になっていました。Rocket Loader 実行時点では `DOMContentLoaded` は既に発火済みで、リスナーが実行されないためです。
- 修正: `static/js/landing_demo.js` が読み込み時に自身で初期化するよう変更（`document.readyState` が `loading` なら `DOMContentLoaded` を待ち、それ以外なら即時初期化）。初期化は二重実行防止ガード付きです。テンプレート側のインライン初期化スクリプトは削除しました。
- あわせて、JS読み込み中にデモ枠が高さ0で潰れて見える問題を防ぐため、`.chat-demo` に最小高さと「読み込み中...」プレースホルダを追加。ヒーロー部のカラム間隔・統計表示の余白も調整しました。
- DBスキーマ変更はありません。チャットデモとハブの描画・タイムラインを回帰テストで確認しました。
