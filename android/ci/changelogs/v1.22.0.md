# AI Playground Android v1.22.0

- ファイルライブラリをWeb版と同じ画面にしました。表示順（新しい順・古い順・名前順）とお気に入りのみの表示を選べます。ファイルを複数選んで、まとめて添付・ダウンロード・削除できます。
- ライブラリで1つ選んだファイルについて、名前の変更と、そのファイルを使っているチャットの確認ができるようにしました。
- ライブラリから添付するとき、選択中のモデルが音声・動画の入力に対応していない場合は、そのファイルを除外してお知らせします。
- サイドバーに「ブランチ管理」を追加しました。会話の分岐をツリーで確認でき、ブランチの切り替え・名前付け・固定・削除ができます。
