# V4.8.288 (2026-02-26)

## 「項目」ボタン関連の内部ロジックを削除（Nano Banana 2は維持）

`V4.8.287` ではプロンプトバーの `項目` ボタンUIのみ削除していましたが、今回その際に追加した内部ロジック（モデル別プロンプトバー項目上書き機能）もあわせて撤去し、`Nano Banana 2` 実装は維持したまま実質的に作業前の状態へ戻しました。

### 変更内容
* **内部ロジック撤去**: `templates/chat_app.js` からモデル別プロンプトバー項目上書き機能（localStorageキー / 関数群 / 初期化イベント / `toggleOptions()` への適用呼び出し）を削除。
* **Nano Banana 2 は維持**: `gemini-3.1-flash-image-preview` のモデル追加とバックエンド実装、入力目安表示はそのまま維持。
* **表示バージョン更新**: `chat.html` の表示バージョンと `chat_app.js` キャッシュバスターを `V4.8.288` に更新。
