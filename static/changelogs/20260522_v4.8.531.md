# 更新履歴 (V4.8.531)

## 2026-05-22

### 新機能
- **初回トークン待機中のシマーアニメーションを追加**
    - モデルがthinking中、初回トークンを待っている状態のときにメッセージテキストに白いグラデーションが左から右へ流れるアニメーション（pending-shimmer）を表示するように改善しました。
    - thinking中（推論プロセス準備中）には、思考ボックス（thought-container）に同様のシマーアニメーション（thinking-shimmer）を表示します。

### 変更
- **回答停止ボタンを送信ボタンに統合**
    - 専用の回答停止ボタン（`#stop-container` / `#stop-btn`）を廃止し、回答生成中は送信ボタン（`#send-btn`）を停止ボタンに一時的に置き換えるように変更しました。
    - 停止ボタンのデザイン: 赤色のグラデーション背景、中央に白い■アイコン
    - 回答完了後、または停止後は自動的に送信ボタンに戻ります。
