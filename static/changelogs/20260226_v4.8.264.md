# V4.8.264 (2026-02-26)

## 管理者スピードテストを回線速度テストへ差し替え

前回追加した Bot Detection の速度判定 dry-run は要件解釈が誤っていたため、`fast.com` 風の回線速度テスト（ブラウザ⇔このサーバー）に置き換えました。

### 変更内容
* **誤実装の置換**: `app.py` の `POST /api/bot/speed-test`（Bot Detection dry-run）を撤去。
* **回線速度テストAPI追加**: `GET /api/speedtest/ping`、`GET /api/speedtest/download`、`POST /api/speedtest/upload` を追加。
* **権限制御**: `.env` の `PRIMARY_ADMIN_USERNAME` でログイン中の管理者アカウントのみ実行可能に制限。
* **設定UI差し替え**: `templates/chat.html` の管理者向けスピードテスト欄を、回線速度テスト（ping/download/upload）説明へ更新。
* **フロント測定処理差し替え**: `templates/chat_app.js` でブラウザ計測（複数回 ping、download/upload の実測Mbps算出）を実装。
* **表示バージョン更新**: `chat.html` の表示を `V4.8.264` に更新。
