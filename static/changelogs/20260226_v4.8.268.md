# V4.8.268 (2026-02-26)

## グローバルロードスピナーの処理内容表示誤判定を修正（ライブラリ削除時）

ライブラリで画像/ファイルを削除した際、グローバルロードスピナーが `削除中...` ではなく `アップロード中...` と表示されることがある問題を修正しました。

### 変更内容
* **原因修正**: `static/js/progress_spinner.js` のURL推定ロジックで、`/api/files/delete` の `files` をアップロード判定として誤検知していたため、`delete/remove` 判定を先に評価するよう変更。
* **判定精度改善**: URLベースのアップロード推定から汎用的すぎる `file` キーワードを除外し、`upload` / `attachment` / `/photo` に限定。
* **キャッシュ対策**: `progress_spinner.js` 読み込みURLのクエリバージョンを `4.8.268` に更新（`chat` / `login` / `signup` / `verify_2fa` / `setup` / `landing` / `banned`）。
* **表示バージョン更新**: `chat.html` のタイトル表示を `V4.8.268` に更新。
