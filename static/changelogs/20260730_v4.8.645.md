# V4.8.645 — Coding Modeによる差分コード編集

## 変更内容

- プロンプトバーに、明示的にオンにした場合だけ動作する `Coding` トグルを追加
- Coding Modeでは、既定で現在のチャットにある最新コードブロックを編集対象として自動選択
- 各コードブロックに「編集対象」ボタンを追加し、過去の任意コードブロックを固定して編集可能
- モデルには完成コード全体ではなく、一意な `search` / `replace` 差分だけを生成させることで出力トークンを削減
- サーバー側で各差分が元コードに1件だけ一致することを検証し、安全に適用してから完成コードを保存・表示
- 曖昧・欠落した検索文字列や不正な編集JSONは適用せず、元コードを維持してエラー内容を表示
- コード内にMarkdownフェンスが含まれる場合も、より長いフェンスを自動選択して表示崩れを防止
