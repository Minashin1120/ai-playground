# v4.8.325 (2026-03-12)

### Gemini URL Context 機能の追加
- Gemini API の URL Context Tool に対応しました。
- チャット画面に「URLs」チェックボックスを追加し、手動で有効化できるようにしました。
- メッセージ内に URL が含まれる場合、Gemini モデル使用時に自動的に URL Context を有効化するロジックを追加しました。
- モデルがアクセスした URL の情報を「URL Context」として回答の最後に表示するようにしました。
- ユーザー設定に「デフォルトで URLs を有効化」する項目を追加しました。
- データベースに設定保存用のカラム `default_enable_url_context` と `last_enable_url_context` を追加しました。
