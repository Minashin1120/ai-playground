# Update V4.8.243 (2026-02-20)

## Gemini 3.1 Pro の実装
Google の次世代ネイティブ・マルチモーダル・推論モデルである **Gemini 3.1 Pro** を実装しました。

### 主な変更点
*   **モデルの追加**: 
    *   モデル ID `gemini-3.1-pro-preview` に対応。
    *   モデルセレクターの「Gemini 3.0」カテゴリ（Gemini 3系）に Gemini 3.1 Pro を追加。
    *   ウェルカム画面のクイックスタートボタンに Gemini 3.1 Pro を追加。
*   **推論機能 (Thinking) のサポート**:
    *   Gemini 3.1 を `is_gemini_3` 判定に含め、Thinking プロセスの表示を自動的に有効化。
*   **UI の改善**:
    *   モデルごとのオプション表示（Thinking Level 等）を Gemini 3.1 にも適用。
