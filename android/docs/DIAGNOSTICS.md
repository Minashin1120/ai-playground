# Android版の診断ログ

AI Playground のAndroid版（1.41.33以降）は、サーバーの**管理者アカウント**でログインしているときだけ、不具合の調査に使う診断ログを記録し、ログインしているサーバーへ送ります。管理者ではないアカウント、ログインしていない状態、「アカウントなしで開始」では、何も記録も送信もしません。

診断ログは、送信・回答・同期・チャットの読み込みが止まったり失敗したりしたときに、どの段階で何が起きたかを確かめるためのものです。通常（サーバー経由）とサーバー不使用モードのどちらでも記録します。

## 記録する内容

| 種類 | 内容 |
|---|---|
| 処理の段階 | 送信の開始・終了・停止・失敗、回答の生成の各段階、添付ファイルの保存と読み込み、同期、チャットを開く・再読み込みする・削除する操作、アプリの起動、アプリが画面に出た・離れたこと |
| 数値 | 所要時間、ファイルのサイズ、件数、入力した本文の文字数、アプリが使っているメモリーの量 |
| 種類・状態 | モデル名、添付ファイルのMIMEタイプ（`video/mp4` など）、通信先の種類（Gemini、Vertex AIなど）、AIの各社でのファイルの処理状態、プロンプトキャッシュなどの設定のオン・オフ |
| 識別子 | チャットのID、処理を行ったスレッドの名前、アプリのプロセス番号 |
| 表示された文言 | 送信中に表示される進み具合の文言と、回答に表示されたエラーの文言（1.41.35以降。1件1000文字まで）。エラーの文言はサーバーやAIの各社が返したもので、添付のファイル名を含むことがあります |
| 例外 | 例外の種類とメッセージ、アプリ内の呼び出し位置（最大24段）。アプリが異常終了したときも記録します |
| 停滞時のスタック | 送信・回答・同期・読み込みが20秒以上進まないとき、アプリのスレッドの呼び出し位置（最大24スレッド・各24段）。60秒に1回までです |

1つの項目は2000文字までに切り詰めます。

## 記録しない内容

- 入力した本文、回答の本文、思考の内容
- 添付ファイルの中身（画像・動画・文書のデータ）
- 添付のファイル名（上記のエラーの文言に含まれる場合を除く）
- APIキー、パスワード、ログイン情報

## 端末での保存

- 記録は、送れるまで端末のアプリ専用の領域（`noBackupFilesDir/diagnostics/pending.jsonl`）に置きます。アプリを強制終了しても、次に起動したときに送れるようにするためです。この領域は端末のバックアップに含まれません。
- 768KBを超えたときは、古い方の半分を削除します。
- サーバーが受け取った分は、端末から削除します。

## 送信

- アプリが動いている間、10秒ごとに、ログインしているサーバーの `POST /api/mobile/v1/diagnostics` へ送ります。1回に送るのは200件・約60万文字までです。オフラインのときは送りません。
- 通信は、ほかのAPIと同じログイン情報（Bearerトークン）を使い、https で送ります。
- サーバーが管理者ではないと応答した場合（403）、アプリは記録を止め、端末に残っていた記録を削除します。

## サーバーでの保存

- サーバーは管理者以外からの送信を拒否します（403）。1回の送信は1MB・500件まで、1分に60回までです。
- 受け取った1件を1行のJSONとして、アプリのディレクトリの `logs/android-diagnostics.log` に追記します。行には、受信時刻、アカウントのID、ログインセッションのID、アプリの User-Agent（80文字まで）が加わります。
- 1行が256KBを超える記録は、イベント名と大きさだけに置き換えます。
- ファイルが20MBを超えると `logs/android-diagnostics.log.1` へ移し（前の `.1` は上書きされます）、新しいファイルへ書き始めます。それ以外に自動で削除はしません。
- このファイルはGitの管理対象外です。

## 記録を止める・消す

- 診断ログは管理者アカウントだけが対象で、アプリにオン・オフの設定はありません。アカウントの管理者権限を外すと、アプリは次の送信で記録を止め、端末の記録を削除します。
- アプリのデータを消去すると、端末に残っていた記録も消えます。
- サーバーに保存された記録は、サーバーの運用者が `logs/android-diagnostics.log` と `.1` を削除して消します。

## 自分でサーバーを運用する場合

- 保存先は、アプリのディレクトリの `logs/android-diagnostics.log` です。サーバーを起動しているユーザーが `logs/` に書き込めるようにしてください。
- 記録には管理者アカウントでの利用状況（チャットのID、時刻、エラーの文言など）が含まれるため、ファイルの閲覧権限はサーバーの運用者だけにしてください。
