# V4.8.283 (2026-02-26)

## 回答停止後に「送信中」バブルへ戻る問題を修正

`V4.8.282` の停止後サイレント同期により、停止操作直後のサーバー `pending_job` 状態を拾ってしまい、途中まで表示されていた回答が `送信中...` バブルに置き換わるケースを修正しました。

### 変更内容
* **手動停止の同期タイミングを調整**: 停止ボタン押下時は `AbortError` 側での即時同期をスキップし、`/api/stop_chat` 実行後に同期するよう変更。
* **停止対象ジョブの pending 表示を抑制**: 明示的に停止した `job_id` をUI側で記録し、`renderThreadTree()` / `resumePendingStream()` で該当ジョブの pending バブル再表示を抑制。
* **停止後の部分回答表示を優先**: 停止直後に `送信中...` 表示へ戻りにくくし、既に表示されている途中回答を維持しやすく改善。
* **表示バージョン更新**: `chat.html` の表示バージョンと `chat_app.js` キャッシュバスターを `V4.8.283` に更新。
