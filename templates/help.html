高速モード（ブラウザ直接送信）

高速モードは、Gemini のテキストモデルへの送信をサイトのサーバーを経由せず、 ブラウザから Gemini API へ直接ストリーミングするモードです。サーバー往復が無いぶん、 送信のたびに API キーやモデル設定を読み込む時間が省かれ、応答開始までの待ち時間を短縮できます。

Gemini テキストモデル専用 Python（コード実行）対応 新規・既存チャット両対応 生成中は再読み込み禁止

使い方

  1. プロンプトバーの 高速 切替（雷アイコンのトグル）を ON にします。
  2. 初回は警告ダイアログが表示されるので、内容を確認して「理解して有効化」を押します。
  3. 選択中の Gemini モデルに登録されたモデル別キー（無ければ共通 Gemini キー）が自動で使われます。
  4. 通常どおりメッセージを送信すると、ブラウザから Gemini へ直接送信され、回答がストリーミング表示されます。
  5. 回答完了後、入力内容・回答・思考・添付情報が 1 回のトランザクションでチャット履歴へ自動保存されます。

高速モードでできること

  • 応答までの待ち時間を短縮 — サーバー中継の処理時間を省きます。
  • Thinking（推論プロセス）の表示 — 思考過程もその場でストリーミング表示されます。
  • Python（コード実行） — Gemini の codeExecution ツールで、API 側サンドボックス内でコードを実行できます。実行コードと出力が回答と一緒にライブ表示され、履歴にも保存されます。
  • 画像の添付 — 画像はブラウザ内に一時保持され、Gemini へ直接送信されます（新しいものから最大 4 枚・合計 12MB まで）。生成完了まではサイトのサーバーに保存されません。
  • 複数ターンの継続 — 保存後も高速モードは有効のため、既存チャットでも連続して利用できます。選択中の会話分岐の履歴が Gemini へ送信されます。

高速モードで利用できない機能

  • Search / URLs / Maps などの検索系機能
  • Gems / SysPrompt / PromptCache / Coding Mode / 引用・編集
  • これらは高速モード中に自動で無効化され、通常モードへ戻すと以前の設定へ復元されます。
有効化前に確認すべき注意点
  • 保存済みの API キーがサーバーで復号されてブラウザへ返されます。ブラウザ拡張・XSS・開発者ツールから取得されるリスクがあります。
  • 生成中に再読み込み・タブ終了・通信切断が起きると、生成と未保存内容は失われ再接続できません。
  • 回答完了後の履歴保存（後処理）が失敗すると、回答が履歴に残らないことがあります。
  • 共有管理者キー・環境変数キー・Vertex AI 認証情報はブラウザへ渡されません。
通常モードとの使い分け 検索・URL 参照・Coding Mode など拡張機能を併用する場合は通常モードが適しています。高速モードは、とにかく応答を素早く始めたい場合や、外部の拡張機能が不要なチャットでお使いください。

マルチモデル対応

1 つの画面から Google（Gemini）・OpenAI（GPT）・xAI（Grok）・Anthropic（Claude）・DeepSeek・Moonshot（Kimi） などの最新モデルを、モデル選択からワンクリックで切り替えて利用できます。40 以上のモデル・プロバイダに対応し、 最大 1M トークン級の長いコンテキストも 1 つの文脈として扱えます。

Gemini シリーズ

Gemini 3.6 / 3.5 Flash など。検索・Maps・コード実行と高い親和性があります。

GPT シリーズ

GPT-5.6 Sol / Terra / Luna など。高度な推論とコード生成に強みがあります。

Grok シリーズ

Grok 4.3 など。リアルタイム性の高い対話と画像生成（Grok Imagine）にも対応。

Claude シリーズ

Claude Opus 4.6 など。長文の理解と安全な応答に定評があります。

DeepSeek / Kimi

DeepSeek V4、Kimi K3。コスト性能バランスに優れた選択肢です。

会話中の切り替え

回答の内容に合わせてモデルを途中で変更しても、会話の文脈は引き継がれます。

BYOK（Bring Your Own Key）・プライバシー

Bring Your Own Key 方式を採用しています。AI モデルの API キーを各自で用意していただき、 モデル利用料金は API 提供元（Google・OpenAI・xAI など）に直接支払われるため、サブスクリプション料金はかかりません。

  • API キーは暗号化して保存され、画面には一切表示されません。
  • キーはチャットリクエストのたびにサーバー内でのみ使用され、ブラウザや第三者に公開されません。
  • モデルごとにモデル別キーと共通キーを設定でき、選択中モデルのキーを自動で使います。
  • アカウントのデータ（チャット・設定・ファイル）はあなたの管理下にあり、いつでもエクスポートできます。

Thinking（推論プロセス）の可視化

Thinking 対応モデルでは、回答が生成される前にモデルが「考える」過程（推論プロセス）を、 Thinking Process としてその場で表示できます。答えに至る思考の流れを追いながら、 より信頼性の高い回答を確認できます。

  • 思考の表示 / 非表示は切り替え可能。生成後は折りたためます。
  • モデルごとに思考レベル・推論 Effort・思考予算（トークン）を細かく調整できます。
  • Gemini の思考署名（thoughtSignature）にも対応し、思考の一意性を判定します。
  • 思考プロセスも会話履歴に保存され、あとから見返せます。

マルチモーダル（画像・PDF・音声）

画像や PDF ファイルをドラッグ＆ドロップ、またはクリップボードからの貼り付けで添付できます。 文書の要約・翻訳・解析・画像の説明など、そのまま質問できます。

  • 画像・動画・音声・PDF など多様なファイル形式に対応。
  • リッチ貼り付けは、Web 上のコンテンツを PDF 化してからモデルへ渡します。
  • 画像のみの送信も可能（添付がある場合は本文が空でも送信できます）。
  • 添付した画像の一部をマーカーでマークして、その範囲について質問できます。

検索・URL・地図・Python 連携

モデル単体の知識に加えて、以下の拡張ツールを統合できます。プロンプトバーのトグルで簡単に ON / OFF できます。

Search

最新情報や Web 検索結果を回答に反映します。日付・時事ネタに強い。

URLs

指定した Web ページの内容を取得して、要約や考察をさせられます。

Maps

地図情報の検索・周辺情報の取得（Gemini 3 系で利用可能）。

Python

モデルの API 側サンドボックスでコードを実行。計算・データ処理に。

Canvas / Coding Mode

Canvas Mode

コードブロックを画面右側の Canvas でプレビューできます。HTML・CSS・JavaScript の実行結果を、 チャットから離れずに確認・操作できます。

Coding Mode

既存コードの変更行だけをモデルに生成させ、完成コードへ安全に反映するモードです。 ファイル全体の書き換えによる副作用を防ぎ、コード修正を効率化します。

画像生成・音声会話

Nano Banana 2

高品質な画像生成。マスク編集（Mask）にも対応。

Grok Imagine

Grok による画像生成。クリエイティブな作風が特徴です。

GPT Image

OpenAI の画像生成モデル。テキストの書き込み精度に優れます。

音声入力 / TTS

マイクからの音声入力と、回答の音声合成（TTS）に対応。

リアルタイム音声対話

音声の無音検知による自動送信（Auto Send）にも対応した会話モデル。

チャット管理（分岐・PDF・検索）

  • 自動保存 — チャット履歴はすべて自動で保存され、サイドバーからいつでも再開できます。
  • スレッド分岐（ブランチ） — 会話の途中から別の方向へ分岐させて比較できます。
  • PDF 出力 — 現在のチャットを PDF として書き出せます。
  • 検索 — サイドバーの検索ボックスから過去のチャットを全文検索できます。
  • 引用（Quote） — 回答文のテキストを選択して引用し、続きの質問に使えます。
  • 編集 — 送信済みメッセージを編集して回答を再生成できます。
  • チャットの削除 — 個別に削除でき、ゴミ箱からの復元にも対応しています。

データ移行（エクスポート / インポート）

アカウントのデータをZIP ファイルとして書き出し（エクスポート）、別のアカウントや別の環境へ 取り込み（インポート）できます。設定・API キー／クラウド認証・チャット履歴・Gem・ファイル・ フィードバック・診断メトリクスをカテゴリ単位で選択できます。

エクスポート

バックグラウンドで ZIP を生成。完成後は設定画面からダウンロードできます。

インポート

作成直後のセットアップ画面または設定画面から取り込めます。進捗バー付き。

E2EE 連携

E2EE 有効化前にインポートしたデータは、完了後に自動で再暗号化されます。

安全な取り扱い

生成された ZIP は一定時間で自動削除され、所有者以外はダウンロードできません。

セキュリティとプライバシー

  • E2EE（エンドツーエンド暗号化） — 有効にすると、メッセージとファイルはサーバー上で復号できない形で暗号化して保存されます。
  • パスワードのハッシュ化 — 平文では保存されません。
  • 二段階認証（2FA） — ワンタイムパスワードとパスキー（WebAuthn）によるログインに対応。
  • ボット検出 — Cloudflare Turnstile による不正アクセス対策。
  • セッション管理 — ログイン中の端末を一覧表示し、遠隔で失効できます。
  • 一時チャット — 切断後にチャットと添付を自動削除するモード。

便利機能

低速回線モード

接続状況に応じて自動で切り替わり、省データで通信します。

Gems

よく使う指示・前提を保存したカスタムプロンプトを呼び出せます。

クライアント圧縮

ショートカット

カスタムテーマ

配色を自分好みにカスタマイズでき、端末に記憶されます。

よくある質問

アカウント作成やアプリの利用は無料ですか？
アカウント登録と設定は無料です。モデルの利用料金はご自身の API キーに請求されるため、API キーが無い状態ではチャットは利用できません。
高速モードと通常モードはどちらを選べばいいですか？
応答を素早く始めたい場合は高速モード、検索・URL 参照・Coding Mode などの拡張機能を使う場合は通常モードをおすすめします。高速モードは Gemini のテキストモデル専用です。
API キーはどこで入手できますか？
各プロバイダの公式サイト（Google AI Studio、OpenAI Platform、xAI、Anthropic など）から取得してください。取得したキーは設定画面でモデルごとに入力できます。
チャット履歴はサーバーに保存されますか？
チャット履歴・設定・ファイルはアプリのデータベースとストレージに保存されます。E2EE を有効にすると、サーバー上で復号できない形で暗号化して保存されます。
データを別の環境へ移行できますか？
はい。設定画面の「エクスポート」から ZIP を書き出し、別アカウントのセットアップ画面や設定画面から「インポート」できます。
回答の途中でページを閉じてしまいました。
通常モードでは接続が自動で再開され、生成中の回答も復元されます。高速モードでは生成中に閉じると未保存の内容は失われます。
エラーや不具合が起きたらどうすればいいですか？
画面上にエラー内容が表示されます。通信環境をご確認のうえ、時間をおいて再試行してください。解決しない場合は設定画面からフィードバックを送信できます。
