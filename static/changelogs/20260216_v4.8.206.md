# V4.8.206 (2026-02-16)

- 設定画面の 2FA タブで、パスキー名を付けて複数のパスキーを登録できるようにしました。
- 登録済みパスキー一覧（件数表示・登録日時・個別削除）を追加しました。
- `/api/settings` に `passkey_credentials` / `passkey_count` を追加し、UI で登録済みパスキーを表示可能にしました。
- `/api/2fa/webauthn/remove` を追加し、最後のパスキー削除時は `passkey_only_login` と 2FA 状態を自動で整合するようにしました。
- WebAuthn 資格情報の正規化ヘルパーを追加し、既存の単一オブジェクト形式や壊れた JSON の影響を緩和しました。
