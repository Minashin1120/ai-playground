# Change Log - V4.8.391 (2026-04-04)

## [Improved] リッチ貼り付け PDF 出力スタイルの大幅改善

プロンプトバーの「リッチ貼り付け」機能において、PDF 生成時にスタイルの大部分が欠落していた問題を修正しました。

### 変更点
- **インラインスタイルの保持**:
  - 太字 (`bold`, `strong`)、斜体 (`italic`, `em`)、リンク (`a`)、等幅 (`code`) の各スタイルを解析し、PDF 上で再現するように改善しました。
- **レンダリングロジックの刷新**:
  - 従来のプレーンテキスト変換から、スタイル情報を保持した「セグメント方式」の解析・描画ロジック (`writeRichTextBlock`) に移行しました。
  - スタイルが混在する行の折り返し処理を自前で実装し、レイアウトの崩れを抑制しました。
- **レイアウトの洗練**:
  - 見出し (`h1`-`h6`)、段落、引用、リストの余白とフォントサイズを調整し、より読みやすい PDF 出力を実現しました。
  - 引用ブロック (`blockquote`) に左側のボーダーラインを追加しました。
- **リンクの有効化**:
  - PDF 内のリンクをクリック可能なハイパーリンクとして埋め込むようにしました。

### 注意事項
- 標準の PDF フォント（Helvetica等）を使用しているため、日本語文字の表示には限界があります。日本語の完全な表示には将来的にカスタムフォントの導入が必要です。
- 複雑なテーブルレイアウトは引き続き簡易的な Markdown 形式で出力されます。
