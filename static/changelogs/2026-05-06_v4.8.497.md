# V4.8.497 (2026-05-06)

### 🚀 Performance Improvements
- **Gemini Live WebSocket Integration**: Implemented direct client-to-server WebSocket communication using ephemeral tokens. This follows the official Gemini API documentation for the lowest possible latency.
- **Client-side Audio Processing**: Audio capture and PCM conversion are now handled on the client side, allowing for immediate streaming to Gemini without waiting for backend processing.

### 🛠️ Technical Changes
- Added `/api/gemini/session` endpoint to generate experimental ephemeral authentication tokens (v1alpha).
- Added `/api/gemini/save_sts` endpoint to persist direct WebSocket conversation results to the database.
- Implemented `GeminiLiveClient` class in JavaScript for real-time bidirectional streaming.
- Re-architected Gemini 3.1 Flash Live to bypass backend audio upload bottlenecks.
