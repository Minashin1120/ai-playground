# 更新履歴 - V4.8.1182 (2026-11-25)

リアルタイム音声モデルをWeb版・Android版の両方で利用できるよう修正しました。Gemini Liveの各モデル（音声会話・音声翻訳・リアルタイム文字起こし）は、ブラウザーやアプリがAPIキーを受け取らず、認証済みのサーバー経由で接続する方式に統一しました。Vertex AIのGemini Liveにも対応し、リアルタイム文字起こしのモード・カスタム語彙・言語の自動判定、音声翻訳の翻訳先言語、Extended Thinkingの動作状態表示、セッション上限が近づいたときの通知を追加・修正しました。GPT-Liveの音声選択肢を追加し、Android版でGemini Live Transcribeがリアルタイム音声モデルとして表示されない問題も修正しました。
