# V4.8.621 (2026-07-11)

## 修正

- 一部または既存のチャットを開いた際、スケルトンローディングのまま本文が表示されない問題を修正
- チャット読み込み時に参照する PromptCache UI 更新関数を、すべての呼び出し元から参照できる共通スコープへ移動
- APIエラー、不正なレスポンス、描画時の例外が起きても無限ローディングにならず、再試行ボタン付きのエラー表示へ切り替わるよう改善

- 関数スコープと読み込み失敗時のフォールバックを検証する回帰テストを追加
