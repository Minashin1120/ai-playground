# V4.8.703 (2026-08-03)

## Turnstile チェックが終わるまでサーバー通信をブロック＋失敗時の BAN

V4.8.702 まで Turnstile のチェックが実質的に表示されず、リロードすれば普通に操作できてしまう（未検証でもサーバー通信が可能）状態でした。本版では、**Turnstile 検証が完了するまでそのユーザーのサーバー通信をできる限りブロック**し、チェックの失敗が繰り返された場合は BAN するように強化しました。

### 1. 未検証中はサーバー通信（POST）をブロック（`app.py`）

- 新しい `before_request` フック `gate_bot_detection_unverified` を追加。ボット検出が有効なユーザー（`globalEnabled` かつ `accountEnabled` かつ非管理者かつ Turnstile キー設定済み）で、Turnstile 未検証（Redis のマーカー `bot:tst:v:{user_id}` なし）の間は、**すべての POST リクエストを `403 {error:'turnstile_required'}` で拒否**します。GET はページ表示に必要な読み取りのため許可しています。
- ホワイトリスト: 検証エンドポイント `/api/bot/turnstile-verify`・テレメトリ `/api/bot-telemetry`・ログアウト・BAN 異議申し立て系・クライアントデバッグログ・静的アセットのみ未検証でも到達可能。その他すべての POST（送信・スレッド作成・設定保存・アップロード等）がブロックされます。
- セッション中のマーカー失効（TTL 15分）に備え、POST 本文に有効な `turnstile_token` が含まれる場合はインライン検証で通過させます。
- セットアップ未完了ユーザー（Turnstile ウィジェットが無い画面）は対象外とし、新規登録を妨げないようにしました。

### 2. クライアント側: 検証が終わるまで画面をオーバーレイでブロック（`chat_core.v4.8.703.js`）

- ページ読込時に `runBotDetectionGate()` を実行。ボット検出が有効で未検証の間は、フルスクリーンのオーバーレイ「安全性の確認中...」を表示してすべての操作をブロックし、Turnstile チャレンジを実行します。検証が成功（サーバー側 `/api/bot/turnstile-verify` 成功）するとオーバーレイを解除します。
- サーバー側で検証済み（`bot_config.turnstileVerified` が true）の場合はオーバーレイを表示しません（リロード時のちらつきなし）。
- セッション中に `403 turnstile_required` を受けた API 呼び出しは、`apiFetch` 内で再検証してから一度だけ再送します（マーカー失効に自動対応）。
- 検証が一定時間得られない場合はテレメトリ（`turnstile_failed`）を送り、サーバー側の失敗カウントに反映させます。

### 3. Turnstile チェック失敗時の BAN ロジック（`app.py`）

「一定回数ダメだったらバン / 成功すれば通す / それでも繰り返すならバン」という判定ロジックを実装しました。

- **失敗カウント**: 検証失敗（`/api/bot/turnstile-verify` の `turnstile_failed`、またはテレメトリの `turnstile_failed` 報告）のたびに `bot:tst:fail:{user_id}` を加算（TTL 30分）。**5 回に達すると BAN**。
- **成功でリセット**: 検証が成功すると失敗カウントをリセットし、通常どおり利用できます（`_bot_turnstile_register_success`）。
- **サイクリング検知**: 失敗→成功→失敗→成功と繰り返す挙動はボットの特徴とみなし、成功が失敗を伴って **3 サイクル**重なると BAN（`bot:tst:cycle:{user_id}`、TTL 30分）。
- BAN 時は `ban_related_accounts` により、同一 IP・クッキーで紐づく**関連ユーザーにも連鎖 BAN** を適用します。
- 従来の挙動スコア（高速クリック等）による BAN 判定も併存しています。

### 補足

- 対象外: 管理者・ボット検出無効ユーザー・Turnstile 未設定環境・セットアップ未完了ユーザー。
- 正常なユーザーはページ表示中に Turnstile が自動解決され（通常は非表示・瞬時）、オーバーレイは一瞬で消えます。ネットワーク遅延や広告ブロッカー等で Turnstile を読み込めない環境ではオーバーレイが表示されたままになり、5回失敗すると BAN されます（管理者の BAN 管理画面から解除可能）。
- `tests/test_turnstile_bot_detection_regressions.py` に失敗→BAN・成功リセット・サイクリング BAN・未検証 POST ブロック等のテストを追加（計29件）。全181件の回帰テスト成功。
