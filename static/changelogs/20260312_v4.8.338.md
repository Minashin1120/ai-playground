# Update 2026-03-12 (v4.8.338)

### 改善: レスポンス速度の計測（デバッグオプション）の強化
*   **詳細な待機時間の可視化**: 
    *   設定で「レスポンス速度の計測」が有効な場合、AIの回答バブルの下部に詳細な計測情報を表示するようにしました。
    *   「初回応答（Initial）」と「合計時間（Total）」を秒単位で表示し、ボトルネックの特定を容易にしました。
    *   併せて、サーバー側ログとの突き合わせに役立つ「Job ID」も表示されます。
*   **GPT-Image生成プロセスのフィードバック改善**:
    *   処理が遅い GPT-Image 系の画像生成モデルにおいて、現在の進捗状況（「OpenAI API呼び出し中...」「生成データをデコード中...」など）を細かく表示するようにしました。
    *   これにより、長時間待機が必要な場合でも、システムが正常に動作していることを視覚的に確認できます。
