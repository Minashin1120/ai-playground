# Update Log (2026-04-15) - V4.8.421

## WebAuthn / Passkey Support Improvements
- WebAuthn登録時のオプションを更新し、`resident_key=ResidentKeyRequirement.PREFERRED` を追加しました。これにより、Google アカウントなどの同期されたパスキー（Passkeys）をより確実に登録・利用できるようになります。
- オンデバイスの認証器だけでなく、クロスプラットフォームの認証器や同期された認証器の利用をブラウザに促すように改善しました。

## PDF Generation Improvements (Rich Paste)
- 大容量のコンテンツ（楽天などの複雑なWebページ全体など）をPDF化する際、ブラウザのCanvasサイズ制限やタイムアウトで処理が止まる問題を修正しました。
- チャンクレンダリング方式を導入し、コンテンツを分割して描画・結合することで、長大なページでも安定してPDF生成が可能になりました。
- **進行状況バーの追加**: PDF生成中に進捗（0%〜100%）を表示するようにし、処理が動いていることを視覚的に確認できるよう改善しました。
- レンダリング時のスケール調整とタイムアウト時間の延長（30秒 -> 120秒）を行い、低速な環境や重いページでの成功率を向上させました。

## System Updates
- `app.py` の `APP_VERSION` を `2026-04-15-003` に更新。
- フロントエンドのリソースを `V4.8.421` に更新。
