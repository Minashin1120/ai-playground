# v4.8.748 — 高速モードでコード実行（Python）に対応

- ブラウザ直接送信の高速モードで、Gemini の `codeExecution` ツールによる**コード実行（Python）**を利用できるようにしました。Google AI Studio と同様、ブラウザから Gemini API へ直接送信する方式のまま、API 側のサンドボックスでコードが実行されます。
- Python トグルを高速モードの制限対象から除外しました。有効な場合、送信リクエストに `codeExecution` ツールを追加し、実行されたコードと出力を回答本文とあわせてライブ表示します。
- 実行結果は回答履歴へ `pyexec` ブロックとして保存されるため、再読み込み後もコードと出力が Python Execution ボックスとして表示されます。
- 高速モードの警告ダイアログの文言を更新しました。検索・URLs・Maps・Gems・SysPrompt・PromptCache・Coding Mode・引用・編集は引き続き利用できません。
- DBスキーマ変更なし。`APP_VERSION=2026-08-06-007` / `SYSTEM_VERSION=V4.8.748`。
