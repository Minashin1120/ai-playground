# 更新履歴 - V4.8.903 (2026-09-03)

外部MCP（Model Context Protocol）サーバー連携機能を追加しました。設定画面の「MCP」タブから、Gmail・Google Drive・Google Docs・Google Sheets・Google Slides・Google Calendar・Google Chat・Google People の Google Workspace MCP サーバー（OAuth 認証）と、URL を指定するカスタム MCP サーバー（認証なし／Bearer／OAuth）を登録・管理できます。有効にしたサーバーは、DeepSeek・OpenAI系（GPT/Grok Responses）・Gemini・Claude のテキストチャットでモデルが外部ツールとして利用でき、変更を伴う操作は実行前に確認ダイアログを表示します。OAuth クライアント情報（Client ID / Secret）や Bearer トークンはユーザー単位で暗号化して保存し、MCP URL は SSRF 対策として接続先を検査します。ツール実行は監査ログに記録されます。
