# Update V4.8.556 (2026-05-27)

### xAI Grok TTS の単独モデル化

ユーザーのリクエストにより、xAI のスタンドアロン Text-to-Speech をモデル選択リストに追加しました。

#### 追加内容
- **Audio (TTS)** カテゴリに `grok-tts` を追加
- 選択時に xAI 専用音声（Eve, Ara, Rex, Sal, Leo）を表示するよう UI ロジックを拡張
- 言語・速度調整も対応
- 公式ドキュメントに基づく voices とパラメータ（speech tags 対応は今後）

#### 現状
- UI 上でモデルを選択可能になりました。
- バックエンドでの実際の xAI TTS API (`/v1/tts`) 呼び出しは、次のステップで完全実装予定（既存 TTS フローを壊さないよう慎重に）。

STT についてもモデルエントリ追加を検討中です。
