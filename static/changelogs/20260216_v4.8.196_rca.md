# RCA: 全体システムプロンプト参照表示の回帰 (2026-02-16)

- 回帰導入コミットは `24f8096` (V4.8.123, 2026-02-05)。
- 旧仕様復帰時の UI 再編で、以下の参照UIが同時に削除された。
  - 設定モーダルの `global-sys-prompt-preview`（非管理者向け全体プロンプト参照）

- さらに `16a3bb6` (V4.8.196, 2026-02-16) でプロンプトバー側の参照UIも復旧。

## 再発防止

- 設定モーダルとプロンプトバーモーダルの両方で、全体システムプロンプトの参照表示を確認するリリース前チェック項目を追加する。
- APIレスポンス変更時は「実効値表示（フォールバック含む）」をUI側で使っている箇所を一覧確認してから反映する。
