# V4.8.764 - gunicorn の graceful-timeout を短縮し再起動時間を改善

## 変更内容

- **gunicorn の `--graceful-timeout` を 30秒 → 10秒 に短縮しました。**
  - サービス再起動時に gunicorn（Webサーバー）がキープアライブ接続やSSE中継の完了を待つ時間を短くし、Webサービス停止・再起動を約24秒から約10秒へ短縮しました。
  - チャット生成は V4.8.697 より全処理をRQワーカー側へ委譲しているため、Webサーバーの停止で生成本体は失われません。SSE中継が切断されても、ブラウザは自動でジョブへ再接続して回答の続きを表示します。

## 補足

- DBスキーマ変更はありません。
- ワーカーの再起動は、実行中の回答を守るため従来どおり完走待ち（`TimeoutStopSec=660`）のままです。
