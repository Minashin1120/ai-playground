# V4.8.181 (2026-02-11)

## Gemini 接続先の選択機能（Gemini API / Vertex AI）

- 設定画面に `Gemini Backend` を追加し、`Gemini API` と `Vertex AI` を切り替え可能にしました。
- Vertex AI 用の `Project ID` / `Location` をユーザー設定として保存できるようにしました。
- `google-genai` クライアント初期化を拡張し、Gemini API（API Key）と Vertex AI（project/location）を実行時に切り替えるようにしました。
- 初期セットアップ画面にも同じ選択項目を追加し、初回導入時から Vertex AI を選択可能にしました。
- Vertex AI 利用時に Files API 経路へ進んだ場合は、切替案内付きのエラーメッセージを返すようにしました。
