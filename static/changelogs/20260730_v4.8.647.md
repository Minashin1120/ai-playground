# V4.8.647 — Coding Modeのリアルタイム差分表示

## 変更内容

- Coding Modeのモデル出力を、対象選択・各編集・完了を1行ずつ返すNDJSONプロトコルへ変更
- モデルが1件の編集を返した時点でサーバーが一意一致を検証し、`coding_diff`イベントとして即時配信
- 回答生成中のバブルへ「Live Code Changes」パネルを表示し、追加行・削除行・ハンクを色分け
- 複数編集を到着順に追加表示し、再接続時もRedisに一時保存した差分イベントを復元
- 完了時の回答へ全体のunified diffと更新後コードを保存
- フォローアップでは通常の会話履歴として、保存済み差分と更新後コードの両方をモデルへ提供
- 最終回答のdiffコードブロックは編集対象候補から除外し、更新後コードを次の既定対象として維持
- 従来の単一JSON編集形式もフォールバックとして解析可能
