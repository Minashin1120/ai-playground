# V4.8.677 (2026-08-02)

## モバイル端末の描画を軽量化

- タッチ端末ではLiquid Glassの色・縁・奥行きを維持しつつ、広い領域のぼかし半径と多層シャドウを軽量化しました。
- スクロール中だけガラス面のライブぼかしを停止し、停止後に自動で元の表現へ戻すことで、チャットやモーダルのスクロール負荷を抑えました。
- タッチ操作では使用されないポインター追従ハイライトの再描画と、入力欄・送信ボタンの常時シャドウアニメーションを停止しました。
- 回答ストリーミング中のMarkdown全文再描画を回答長に応じて調整し、長文ほど増えていたメインスレッド負荷を抑えました。
- 自動スクロール要求を1描画フレームに集約し、トークン受信ごとの同期レイアウト計算を防止しました。
- 通常送信、再開ストリーム、Geminiブラウザ高速モードの全経路へ同じ最適化を適用しました。

機能、モデル、Liquid Glass設定、ストリーミング表示、Markdown、数式、コード装飾は削除していません。
