# V4.8.691 (2026-08-03)

## 接続エラー通知バー・ローディングスピナーの表示位置を修正（プロンプトバーと重ならないように）

- 接続エラー通知バー（`#offline-banner`）とローディングスピナー（`#global-progress-spinner`）は画面右下に `fixed` 配置されていましたが、プロンプト送信バー（composer dock）や送信ボタンと重なってしまう問題がありました。
- CSS変数 `--composer-h` を導入し、`.composer-dock` の高さを `ResizeObserver` で常時監視して HTML ルートに反映するようにしました。
- 通知バーとスピナーの `bottom` を `calc(var(--composer-h, 0px) + 16px)` に変更し、プロンプトバーの上部に常に表示されるようにしました（プロンプトバーの高さが変化しても追従します）。
- 通知バー表示中はスピナーが通知バーより上に重ならないよう、`body.network-banner-visible` 時のオフセットも同様に `--composer-h` を基準に更新しました。
