# アップデート履歴 V4.8.593

**リリース日:** 2026-06-13

## 変更内容

### DeepSeek V4 画像解析機能を実装
- DeepSeek V4 Flash/Pro は画像非対応のため、画像が添付された場合は選択した Vision Model で自動解析し、結果を system message として注入する方式に変更。
- **設定 > Vision Model**: 画像解析に使用する Vision Model を選択可能（推奨: gemini-3-flash-preview）。
- **設定 > 画像解析プロンプト**: Vision Model に送信する解析指示文をカスタム可能（デフォルトは隅々まで詳細に記述させる高品質プロンプト）。
- **ファイルアップロードモーダル**: DeepSeek 選択時のみ Vision Model 情報を表示。「変更」ボタンで既存のモデル選択モーダルを流用して選択可能（コードコピーではなく参照）。
- **Image Analysis 表示**: ストリーミング中に画像解析の進捗・結果を独立したボックス（`image-analysis-box`）で表示。
- 対応 Vision Model: Gemini, OpenAI GPT-4o, Anthropic Claude, xAI Grok（保有APIキーにより自動ルーティング）。
- `DEFAULT_IMAGE_ANALYSIS_PROMPT` 定数を追加。DB移行関数 `ensure_user_vision_model_columns()` を追加。
