# Update V4.8.555 (2026-05-27)

### xAI Grok Voice モデル追加

公式ドキュメント確認に基づき、xAI Realtime Voice Agent の推奨エイリアスを追加実装しました。

#### 追加したモデル
- **`grok-voice-latest`**（推奨）
  - 常に最新のフラッグシップ音声モデルを指すエイリアス（現在は `grok-voice-think-fast-1.0`）。
  - 公式ドキュメントで最も推奨されている接続方法。
  - Realtime Audio (STS) カテゴリの先頭に配置。

#### 既存モデルの整理
- `grok-voice-think-fast-1.0`：現在の主力モデルとして説明を更新
- `grok-voice-fast-1.0`：レガシー（非推奨）であることを明記
- `grok-voice-agent`：既に deprecated 済み

#### 変更箇所
- `chat_core.v4.8.554.js` / `.555.js` に `grok-voice-latest` を追加（MODELS および STS_MODELS）
- `setup.html` の xAI 既定モデル選択肢に追加
- V4.8.555 へバージョンアップ、必要資産一式作成

これにより、音声系モデル選択時に公式推奨の最新モデルを簡単に選択できるようになりました。
