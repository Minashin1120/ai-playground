# 2026-02-18 V4.8.231

* **ログイン画面の認証アニメーション実装**
    * **内容**: 認証処理中、失敗時、成功時の視覚的フィードバックを強化。
    * **待機状態**: ログインボタンにパルス・グロウ効果を追加し、「認証中...」の状態を分かりやすく表示。
    * **失敗時**: 認証失敗時に入力フォームが揺れる（シェイク）アニメーションを実装。
    * **成功時**: 認証成功時にカードがフェードアウトし、チェックマーク付きの成功画面がふわっと表示される演出を追加。
    * **UI遷移**: 2FAが必要な場合も、カードがスムーズに切り替わるアニメーションを導入。
