# Update V4.8.553 (2026-05-27)

### xAI Grok 旧モデルの廃止（非推奨化）

公式ドキュメント（docs.x.ai）で現在推奨・利用可能な主力モデル以外を廃止処理しました。

#### 廃止対象（`deprecated: true` 付与、UIから非表示）
- grok-4.20-reasoning / non-reasoning / multi-agent
- grok-4-1-fast-reasoning / non-reasoning
- grok-4-fast-reasoning / non-reasoning

#### 維持（現在使用可能なモデル）
- **grok-4.3**（フラッグシップ）
- **grok-build-0.1**（Coding特化、今回追加したモデル）

#### 対応内容（AGENTS.md 厳守）
- `MODELS` 配列からは**一切削除せず**、各オブジェクトに `deprecated: true` を付与
- 既存の `renderModelList` / `syncModelApiKeyModelOptions` のフィルタで自動非表示（過去のチャット履歴・トークン計算には影響なし）
- `app/templates/setup.html` の既定モデル選択肢から廃止モデルを削除
- `app/templates/chat.html` のウェルカム画面クイックスタートは元々現行モデル2種のみだったため変更なし
- バージョン V4.8.553 にアップ、必要資産一式作成

これにより、モデル選択UIが現在公式で推奨されている2モデルに整理されました。過去のスレッドで使っていた旧モデルIDは引き続き動作します（履歴表示・再開用）。
