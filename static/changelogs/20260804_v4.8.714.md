# V4.8.714 (2026-08-04)

## アカウント作成直後に Turnstile 検証の誤検知で BAN される問題を修正

アカウント作成後、操作をしていないのに「Turnstile verification failed repeatedly」で BAN される誤検知を修正しました。

### 原因

Cloudflare Turnstile のトークンは **1回限り** です。ページ読込時にウィジェットの callback・`getTurnstileToken`・ボット検出ゲートが **同じトークンを並行して** `/api/bot/turnstile-verify` に送っていました。1件目が成功（`verify_ok`）した直後、残りが使い切り失敗（`verify_fail`）となり、失敗カウントが同一秒で 5 に達して BAN されていました。あわせて `apiFetch` が `turnstile_failed` の 403 を CSRF と誤認して同一ボディを再送し、失敗をさらに増やしていました。

### 修正内容

**サーバー（`app.py`）**
- 既に検証済みのユーザーは verify 失敗を BAN カウントに加算しない
- 同一トークンの多重送信を Redis で重複排除（最初の1件だけ siteverify／失敗カウント対象）
- 失敗カウントに 15 秒のクールダウンを設け、バーストで即 BAN しない

**クライアント（`chat_core.v4.8.714.js`）**
- 同一トークンのサーバー検証を単一フライト化し、多重 POST を防止
- `apiFetch` が `turnstile_failed` / `banned` / `rate_limit` / `account_locked` を CSRF と誤認して再送しないよう変更

### 補足

- DB 変更なし。`APP_VERSION=2026-08-04-002` / `SYSTEM_VERSION=V4.8.714`
- `tests/test_turnstile_bot_detection_regressions.py` に同一トークン再送・失敗クールダウン・単一フライト等の回帰テストを追加（計 59 件）
