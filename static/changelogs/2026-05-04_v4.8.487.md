# Changelog - V4.8.487 (2026-05-04)

## Bug Fixes
- **PDF Capture**: Fixed an issue where the PDF print frame was not reliably cleared after a capture attempt, preventing subsequent captures.
    - Added a robust `cleanup` function that is now called directly from the `afterprint` event listener.
    - Implemented a 60-second fallback timeout to clear the capture state if the print dialog is closed or fails to trigger the `afterprint` event.
- **CSP Compliance**: Fixed a Content Security Policy (CSP) violation in the PDF generation iframe.
    - Removed inline MathJax configuration scripts from the `srcdoc` template.
    - Re-implemented MathJax configuration using direct property assignment from the parent window's `onload` handler within the iframe context.
- **Debug System**: Updated internal debug logging version to `v4.8.487`.
