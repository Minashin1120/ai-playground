# V4.8.649

- Coding Modeで途中の`search`が見つからない場合、ただちに全体を失敗させず、同じモデルによる差分の自動修復を最大2回行うようにしました。
- 成功済みの編集を含む現在の仮コード、失敗理由、失敗した差分、残りの差分、元のユーザー指示を修復モデルへ渡します。
- 「編集対象」ボタンで手動選択したコードは修復中も固定し、モデルが別のコードブロックへ変更することを拒否します。
- 自動選択された対象も最初の選択後は固定し、修復途中の対象切り替えを防ぎます。
- 修復で適用された差分も`Live Code Changes`へ`Auto repair`として表示します。
- 最大2回の修復でも完了できない場合だけ、従来どおり元コードを保存せず安全なエラーを返します。
