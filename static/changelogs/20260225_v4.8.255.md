# V4.8.255 (2026-02-25)

## トークンカウント精度の向上と Thinking Process 可視化の改善

最新の公式ドキュメントに基づき、Gemini および OpenAI モデルにおける「思考プロセス（Thinking/Reasoning）」のトークン計上ロジックを完全に同期・修正しました。

### 1. Gemini モデルの計上ロジック修正
* **公式仕様への準拠**: Gemini 3.1 Pro / 3.0 Pro / 2.5 Flash 等の Thinking モデルにおいて、`usage_metadata.candidates_token_count`（回答）に `thoughts_token_count`（思考）が含まれない仕様を確認。
* **修正内容**: データベース保存時にこれらを手動合算して `tokens_out` とするように修正。これにより、これまで計上漏れしていた「思考トークン」が総トークン数に正しく反映されるようになりました。

### 2. OpenAI モデルの公式 Usage 取得対応
* **ストリーミング対応**: OpenAI 推論モデル（o1/o3/将来のGPT-5等）において、ストリーミング中に `usage` 情報を取得するための `stream_options: {"include_usage": true}` を追加。
* **精度向上**: ストリーム末尾で返却される公式の `usage` オブジェクトをキャプチャし、従来の `tiktoken` による手動計算（文字数近似）から、APIが報告する正確な `completion_tokens` および `reasoning_tokens` を使用して保存する方式へ変更。

### 3. チャット UI の改善
* **内訳の明示**: メッセージフッターのトークン表示において、Thinking トークンが存在する場合に `Out X (Thought Y)` の形式で内訳を明示するように改善。
* **透明性の向上**: 総トークン数が多く見える理由が「内部的な思考プロセス」にあることをユーザーが確認可能に。

### 4. その他
* **デバッグ強化**: トークンカウントが異常値（0など）になった際のサーバーサイドログ出力を追加。
* **バージョン更新**: システム全体のタイトルバージョンを `V4.8.255` へ更新。
