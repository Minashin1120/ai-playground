# V4.8.658

## Canvas Source タブの視認性を改善

- Source タブのコードを、長い行も強制的に折り返さない横長のコードビューへ変更しました。
  - コードの各行を上から順に並べ、長い行は横スクロールで確認できます。
  - インデントとコード本来の行構造を維持し、HTML や JavaScript の長い行が縦長に崩れる問題を解消しました。
- 行番号と行数表示を追加しました。
  - 横スクロール中も行番号が左端に残るため、現在位置を把握しやすくなりました。
  - 行へカーソルを重ねると対象行を薄く強調します。
- Copy は表示用の行番号を含めず、元のコードだけをコピーします。
- Source の縦横スクロール位置を維持する既存動作も継続します。
- Source タブの横長表示と行番号レンダリングに対する回帰テストを追加しました。
