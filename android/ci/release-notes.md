# AI Playground for Android

ブラウザーでアカウントを連携し、いつものチャット履歴をAndroidで利用できます。

- 表示名・提供元・対応能力・廃止状態が分かるモデル選択
- 対応モデルのThinking、Web検索、Prompt Cache設定
- 見出し・強調・リスト・引用・安全なリンクを含むMarkdown表示
- コピー・折り畳みに対応したコードブロック
- 数式・表・添付画像プレビューに対応した本文表示
- Web検索とPython実行の進行・結果カード
- メッセージのコピーと引用
- Web版のティール基調に揃えたライト／ダーク配色
- スマートフォンとタブレット（履歴＋会話の2ペイン）に対応
- 履歴検索、テキスト送信、ストリーミング表示
- 添付ファイルの送信・取得、生成の停止、切断後の再接続
- 端末内の認証情報をAndroid Keystoreで保護
- Webの保存時暗号化設定を継続利用（対応するサーバー版が必要）

Android 8.0以上に対応。下の `app-release.apk` をダウンロードしてインストールしてください。

このAPKはリポジトリに保存した共有debug鍵で署名しています。同じアプリID・署名で上書き更新できますが、公開された共有鍵の署名だけでは公式配布元を証明できません。このリポジトリのリリースから取得してください。

数式はネイティブの近似表示です。リアルタイム音声、Batch専用画面、Webの全設定画面、複雑な数式の完全な組版は含みません。「Web設定・安全性確認」からWeb版を利用できます。
