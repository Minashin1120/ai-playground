# AI Playground Android v1.28.0

- 添付の追加画面をWeb版の「ファイルアップロード」と同じ内容にしました。ファイルごとに「画像編集」「送信名」「削除」ができ、「リストをクリア」で添付をまとめて外せます。DeepSeek などの画像非対応モデルでは、画像解析に使う Vision Model をこの画面で変更できます。
- 画像にマーカーを引いたり、モザイクをかけたり、トリミングしたりできる「画像編集」を追加しました。二本指で拡大でき、「元画像も添付」を選ぶと編集前の画像も一緒に送れます。
- GPT-Image のマスクは、Web版と同じく用意したマスク画像を選ぶ方式に変わりました。
