# V4.8.263 (2026-02-26)

## 設定画面に .env 管理者向けスピードテストを追加

設定画面（管理者の Bot Detection 管理）から、`.env` の `PRIMARY_ADMIN_USERNAME` を対象にした速度判定の dry-run テストを実行できるようにしました。

### 変更内容
* **管理者用API追加**: `app.py` に `POST /api/bot/speed-test` を追加し、Bot Detection の既存スコア計算 (`evaluate_bot_score`) を使った deterministic な速度判定テストを実装。
* **安全な dry-run**: 対象は `.env` の `PRIMARY_ADMIN_USERNAME` を使用し、BAN や設定変更は行わず、スコア・理由・累積スコア見込みのみ返却。
* **設定UI追加**: `templates/chat.html` の「管理者: Bot Detection 管理」にスピードテスト実行ボタンと結果表示欄を追加。
* **フロント処理追加**: `templates/chat_app.js` にAPI呼び出しと結果整形表示（判定理由・閾値比較）を追加。
* **表示バージョン更新**: `chat.html` の表示を `V4.8.263` に更新。
