# V4.8.619 (2026-07-11)

## Liquid Glassモードの全面再設計

- Apple公式Human Interface Guidelines、WWDC25「Meet Liquid Glass」、Apple Newsroomの公開資料を調査し、Liquid Glassモードを設計から再実装
- ガラス表現をコンテンツ層から撤去し、サイドバー、モバイルヘッダー、入力ドック、モーダル、メディア操作部などの操作・ナビゲーション層へ限定
- 周囲の色を拾う多層グラデーション、明暗の縁取り、内側の反射、サイズに応じた影とぼかしでレンズ状の奥行きを強化
- ポインター位置に追従するスペキュラーハイライトを追加し、操作中に光が素材内を移動する表現を実装
- サイドバーと入力ドックを画面から浮く同心円的な角丸形状へ変更
- メッセージ、コード、思考表示、設定カードは標準マテリアルへ戻し、ガラス同士の重なりを防止
- テーマ色による着色を送信・保存などの主要操作へ限定
- メディアビューアーには透過率の高いClear相当、文字量の多いモーダルにはRegular相当の表現を使い分け
- コントラスト強調、透明度低減、動き低減、`backdrop-filter`非対応環境向けフォールバックを追加
- 機能層の限定と動的ハイライトを検証する回帰テストを追加

## バージョン更新

- `APP_VERSION=2026-07-11-004` / `SYSTEM_VERSION=V4.8.619`
- JS/CSS資産をv4.8.619へ更新し、旧v4.8.618資産を削除
