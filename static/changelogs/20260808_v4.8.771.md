# V4.8.771 (2026-08-08)

## 改善

- `/settings` コマンドで、設定変更に加えて現在の設定値を確認できるようにしました。
- 「現在のデフォルトモデルを確認」「Thinkingの設定を教えて」「現在の設定をすべて表示」などの確認プロンプトでは設定を変更せず、該当する現在値を回答バブルへ表示します。
- AIが変更操作と確認操作を別々のツールから選択するようにし、確認操作では設定更新処理とDB保存を実行しない読み取り専用フローにしました。
- 確認結果の各項目もタップでき、対応する設定画面の項目へ直接移動できます。
- APIキー、認証情報、管理者専用設定は確認対象に含めず、システムプロンプト等の長い本文はAIの意図判定用コンテキストへ送らないよう保護しています。
