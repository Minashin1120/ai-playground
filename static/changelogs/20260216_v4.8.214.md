# V4.8.214 (2026-02-16)

- チャット専用システムプロンプトの保持を安定化するため、`/api/threads/<thread_id>/settings` に `GET` を追加し、保存済み `custom_instruction` を直接取得できるようにしました。
- `Chat Instructions` モーダル表示時に、ユーザー設定APIとスレッド設定APIを並列取得し、対象チャットの `custom_instruction` を毎回再読込するように修正しました。
- モーダル表示中にスレッドが切り替わった場合の競合を避けるため、リクエスト世代番号とスレッドID一致チェックを追加しました。
- `chat.html` のタイトルを `V4.8.214` に更新しました。
