# 更新履歴 - V4.8.1043 (2026-09-29)

新しい音声モデルとして GPT-Live 1、OpenAI Realtime 2.1、OpenAI Realtime 2.1 Mini、Gemini 3.8 Flash TTS、Gemini 3.8 Flash-Lite TTS を追加しました。OpenAI Realtime 2・2.1・2.1 Mini では推論の強さ（Reasoning）を選べるようにし、Gemini 3.8 TTS では話し方の指示（Style）と、Voice design・Voice replication で作成した音声IDを使えるようにしました。リアルタイム音声モデル（OpenAI Realtime、Grok Voice、Gemini Live）と Lyria RealTime の不具合もまとめて修正しました。会話中の音声送信や再生操作、保存が「Session not found」で失敗することがある問題、OpenAI Realtime の会話が開始できない問題と選んだ音声・速度が反映されない問題、Gemini Live Translate で選んだ翻訳先の言語が使われない問題、Grok Voice で選んだ音声が反映されない問題を修正しました。OpenAI Realtime Translate では翻訳先の言語を選べるようにし、原文と訳文の文字起こしも保存するようにしました。停止したときの最後の発話の扱い、複数回のやり取りでの文字起こし、Gemini Live の接続が切れたときの通知と保存も改善しました。あわせて、Gemini 3.5 Transcribe で5分を超える音声が途中で打ち切られる問題を修正し、話者分離や単語タイムスタンプを有効にしたときは話者名と時刻を表示するようにしました。Grok TTS でカスタム音声IDが使われない問題、Gemini TTS で長い文章の音声が途中までしか保存されないことがある問題、音声入力の「LLM」方式で OpenAI のモデルを選ぶと失敗する問題、Grok の音声入力でブラウザの録音が認識されないことがある問題も修正しました。音声ファイル変換の安全性も強化しました。
