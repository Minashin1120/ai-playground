# v4.8.732 — インポート時のストレージ容量超過でファイルを選択できるよう改善

アカウントデータのインポート時に、ストレージ容量の上限を超えた場合にインポート全体が失敗してしまう問題を改善しました。

- インポートするアップロードファイルの合計がストレージ上限を超えると、その時点で中止するのではなく、ファイル一覧と各ファイルのサイズを表示して「インポートするファイルを選択」する画面を表示するようにしました。
- 選択画面はファイルライブラリとほぼ同じグリッドUIで、ファイルごとのチェックボックス、選択中の合計サイズと利用可能容量を表示します。容量を超えている場合は警告を表示します。
- 選択したファイルだけで再インポートできるため、容量に収まる範囲でチャット履歴・Gemなどと一緒にファイルを復元できます。ファイルを1つも選択しないことも可能です。
- 容量超過時にアップロード済みZIPを保持し、再試行時の再アップロードを不要にしました。キャンセル時や失敗時は従来どおりアップロードデータを自動削除します。
- インポートに失敗した際のアップロードデータ自動削除を改めて検証しました（失敗時・キャンセル時・完了後とも、一時アップロードデータは確実に削除されます）。
