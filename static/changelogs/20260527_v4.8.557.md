# Update V4.8.557 (2026-05-27)

### xAI Grok TTS 単独モデル化（バックエンド実装）

ユーザーの「できるものはすべて単独モデル化して」というリクエストを受け、最大限の実装を行いました。

#### 実施内容
- **UI**: `grok-tts` を Audio (TTS) カテゴリに追加。選択時に xAI 専用音声（Eve, Ara, Rex, Sal, Leo）と速度・言語設定が表示されるよう拡張。
- **Backend**: `app.py` の TTS Branch に xAI 専用処理を追加。
  - ユーザーの XAI API Key を使用して `POST https://api.x.ai/v1/tts` を呼び出し。
  - voice_id, language, speed パラメータに対応。
  - 既存の E2EE 処理や結果表示フローと統合。

#### 対応した「単独モデル化」
- Realtime Voice Agent（会話用）は以前のバージョンで対応済み。
- 今回、**読み上げ専用（TTS）** の単独モデルとして `grok-tts` を実装。

STT（音声→文字）の単独モデル化についてもモデルエントリは追加可能ですが、用途の性質上（主にアップロード音声の文字起こし）、完全なUI/フロー整備は次回以降としました。
