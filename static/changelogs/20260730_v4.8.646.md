# V4.8.646 — 入力中コードブロックの直接編集

## 変更内容

- Coding Modeで、ユーザーが現在のプロンプトへ入力したMarkdownコードブロックを編集対象にできるよう対応
- 入力内に複数の完全なコードブロックがある場合は、最後のコードブロックを自動選択
- 「編集対象」ボタンで固定した場合は、そのコードだけを必ず編集
- ボタンで固定していない場合は、入力内と履歴内のコード候補からプロンプトに合う対象をモデルが選択
- モデルの候補ID指定と差分の一意な一致先をサーバー側で照合し、別コードへの誤適用を防止
- バッククォートとチルダのフェンス、およびコード内に短いフェンスが含まれるケースへ対応
- 閉じフェンスのない未完成コードブロックは対象にせず、直前の完全なコードブロックを維持
- 入力中コードはユーザーメッセージに既に含まれるため、モデルへのコンテキストで全文を重複送信せず入力トークンを節約
- サーバー側でもユーザープロンプトから対象コードを再抽出し、クライアント指定を信頼せず検証
