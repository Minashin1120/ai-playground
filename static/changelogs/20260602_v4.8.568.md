# V4.8.568 (2026-06-02)

## ログイン画面オーロラ背景アニメーションのさらなる視認性強化

### 調整内容
V4.8.567 からさらに視認性を強く調整：

- `filter: blur(46px)` → **`blur(32px)`**（デスクトップ）
- モバイル `blur(36px)` → **`blur(28px)`**
- ベース不透明度 `0.38` → **`0.52`**
- 各blobの色強度を大幅アップ（teal 0.78→0.92、amber 0.68→0.82、cyan 0.55→0.68、violet 0.45→0.58）
- violet blob 不透明度も 0.30 → **0.42**
- blob サイズを少し拡大（780px / 700px など）
- 配置を画面中央寄りに少し移動（teal top -10%、amber right -10% など）し、フォーム周辺でも動きがよく見えるように

動きの速度・パターン（37s / 29s / 41s の穏やか drift）は変更なし。

### 影響
- ログイン / 新規登録 / 2FA 画面で、オーロラ風の光の流れがかなり明確に視認可能になった。
- カードの可読性は backdrop-blur と暗めの背景で維持。
- その他ページへの影響なし。
