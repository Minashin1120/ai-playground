# Update V4.8.555 (2026-05-27)

### xAI Grok Voice Realtime モデルの公式推奨エイリアス追加

xAI公式ドキュメント（docs.x.ai/developers/model-capabilities/audio/voice-agent）確認に基づき、Realtime Voice Agent で最も推奨されているモデルを追加しました。

#### 追加したモデル
- **`grok-voice-latest`**（最優先推奨）
  - 常に最新のフラッグシップ音声モデルを自動的に指す公式エイリアス
  - ドキュメントで「`wss://api.x.ai/v1/realtime?model=grok-voice-latest`」が推奨例として記載されている
  - 現在は `grok-voice-think-fast-1.0` を指すが、将来の新モデルにも自動追従

#### 既存モデルの位置づけ整理
- `grok-voice-think-fast-1.0`：現在の実際の主力モデル（高度な思考能力を持つフラッグシップ）
- `grok-voice-fast-1.0`：レガシーモデルとして非推奨方向であることを明記
- `grok-voice-agent`：既に `deprecated: true`（過去から）

#### 技術的変更
- `MODELS` 配列および `STS_MODELS` Set に `grok-voice-latest` を追加
- プロバイダー判定や音声設定UIは既存の xAI Realtime ロジックをそのまま利用
- `setup.html` の xAI Grok セクションに優先的に配置

#### 運用
- V4.8.555 バージョンアップ
- サービス再起動 + Cloudflare キャッシュ削除実施
