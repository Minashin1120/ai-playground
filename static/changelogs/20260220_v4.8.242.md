# 更新履歴 (2026-02-20)
## V4.8.242: チャット専用システムプロンプト保存問題の修正

* **スレッド解決ロジックの改善 (403エラー対策)**
    * **内容**: `resolve_thread_for_user` において、`public_id` を持つスレッドに対しても数値 ID でアクセスできるように修正。
    * **効果**: ページリロード後や古いリンクからのアクセス時にスレッド設定の保存が 403 Forbidden で拒否される問題を解消。
* **スレッド設定保存処理の強化**
    * **内容**: `update_thread_settings` において `updated_at` を明示的に更新し、DBセッションへの追加を確実に実行するように改善。
* **全体プロンプトの個別適用フラグを実装**
    * **内容**: `include_global_instruction` 設定をワーカー側で尊重するようにロジックを実装。
    * **内容**: `thread-modal` (Chat Instructions) に「全体プロンプトをこのチャットに含める」トグルを追加。
* **フロントエンドの保存安定性向上**
    * **内容**: モーダルを開いた時点の ID (`modalThreadId`) を保持するようにし、保存処理中にバックグラウンドでチャットを切り替えても正しいスレッドに保存されるよう修正。
