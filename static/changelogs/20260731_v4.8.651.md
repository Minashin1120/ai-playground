# V4.8.651 — コード未生成時のCoding Mode遅延有効化

- Coding ModeをONにしたままでも、現在の入力やチャット履歴にコードブロックがない場合は送信を中止せず、通常どおりコード生成を依頼できるようにしました。
- UI上のCoding Mode設定と、モデルへ渡す実効状態を分離しました。編集候補がない送信では実効状態をOFFに固定し、Coding Mode用の指示や候補をモデルへ渡しません。
- 通常回答のストリーミング中に閉じたMarkdownコードブロックが完成した瞬間、次回送信用の実効状態を自動的にONへ切り替えます。
- 生成途中で実効状態が切り替わっても、すでに進行中のモデルリクエストには反映されない送信時スナップショット方式にしました。
