# V4.8.318 (2026-03-10)

- `Nano Banana 2` の Gemini 画像応答を `candidates[0]` 固定ではなく、レスポンス全体の全候補から走査して画像パートを回収するよう修正しました。
- `Nano Banana 2` がまれにテキストのみ返した場合は、自動で1回だけ画像優先モードへフォールバック再試行するよう追加しました。
- 再試行時は画像出力を優先するため `Search` ツールを外し、`response_modalities=["IMAGE"]` で再要求します。
- これにより、画像モデル選択時に説明文だけ返って画像が保存・表示されないケースを減らします。
- 画面内の表示バージョンと `chat_app.js` のキャッシュバスターを `V4.8.318` に更新しました。
