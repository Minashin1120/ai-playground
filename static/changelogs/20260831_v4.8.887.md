# 更新履歴 - V4.8.887 (2026-08-31)

モデルが作成したファイルと同じ種類（Markdown・コード・CSV・JSON・Excel・HTML など）のファイルを、ユーザー自身の端末からアップロードできるようになりました。File ツールがサーバー上で作成するファイルの拡張子がアップロードの許可リストに含まれていなかったため、ダウンロードしたファイルをそのままアップロードし直すことができませんでした。あわせて、アップロードした Markdown・JSON・コード等のファイルをモデルがテキストとして読み取れるようにし、HTML/SVG ファイルはブラウザーで実行されずダウンロードされるようにしました。
