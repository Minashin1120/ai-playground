# Changelog - V4.8.310 (2026-03-04)

## 新機能: デフォルトモデル設定の追加
* **設定画面でのデフォルトモデル設定**:
    * 設定モーダルの「チャット既定値」セクションにて、新規チャット開始時に使用されるデフォルトモデルを設定・変更できるようになりました。
    * 「前回の設定を保存して継続する」がオフの場合、このデフォルトモデルが適用されます。
* **初期セットアップでのデフォルトモデル選択**:
    * 新規アカウント作成時の初期セットアップ画面（Step 2）にて、APIキーの設定と同時にデフォルトモデルを最初に決定できるようになりました。
* **モデル保持の改善**:
    * `User` モデルに `default_model` および `last_model` カラムを追加しました。
    * 「前回の設定を継続」設定がオンの場合、直前に使用したモデルが保存され、次回チャット開始時に引き継がれるようになりました。

## 内部的な変更
* データベース自動マイグレーション処理に `default_model` および `last_model` カラムの追加処理を追加しました。
* `chat_app.js` の `applyChatDefaults` ロジックを、モデルの初期化に対応するよう拡張しました。
