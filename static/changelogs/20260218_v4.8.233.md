# 更新履歴 (V4.8.233) - 2026-02-18

* **ログイン画面の二段階認証 UI の不具合を修正**
    * **内容**: ログイン画面内 (`login.html`) で動的に表示される 2FA セクションにおいて、欠落していた `backToLogin` および `switch2FATab` JavaScript 関数を実装。これにより「ログイン画面に戻る」ボタンと「Security Key」タブの切り替えが機能するように修正。
    * **内容**: 2FA 認証用の別ページ (`verify_2fa.html`) のボタン文言を「キャンセルしてログアウト」から「ログイン画面に戻る」へ変更し、意図が伝わりやすいように改善。
    * **内容**: タブ切り替え時に `cursor-pointer` が適用されるようにし、クリック可能であることを視覚的にわかりやすく改善。
    * **内容**: ログアウト処理時にセッション中の `pre_2fa_user_id` を明示的に削除するようにし、再ログイン時の整合性を確保。
