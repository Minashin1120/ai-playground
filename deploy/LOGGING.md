# ログの収集と保存

フィードバック設定にある2つのスイッチは既定でオフです。「操作ログを記録する」は端末別、「サーバー調査ログを記録する」はアカウントごとの設定です。サーバー設定は同じアカウントでログインしたWeb版・Android版で共有し、「保存」で反映します。他のアカウントには影響しません。

記録するのは、処理の開始・結果・中断、固定エラー分類、HTTP状態、時間、件数、サイズ、固定の設定状態、検証済みの内部ID・操作のランダムIDです。プロンプト、回答、思考、チャットタイトル、添付・アップロード内容とファイル名、APIキー・パスワード・トークンは記録しません。例外・通知・console・事業者の応答の文言、任意のURLも収集せず、許可した項目・型・固定値だけを保存します。

端末の未送信操作ログは記録から1時間で削除します。ブラウザーやアプリの停止中はコードを実行できないため、次回起動時に送信より先に削除します。サーバー調査ログはRedisの `diagnostic:v2:` 名前空間に保存し、各イベントに1時間のTTLを付けます。追加記録や読み出しで既存イベントの期限を延長しません。アカウントごとに直近最大2000件を参照でき、無効化時は未送信分を削除します。調査ログを既存の運用ファイルへ複製しません。

端末の操作ログがオフでも、サーバー調査ログだけをフィードバックへ添付できます。返信はログ添付のチェックが必要です。ログ添付を選択したフィードバック・返信には、その端末の操作ログと、同意が有効で残っている本人のサーバー調査ログを保存します。送信済みコピーは `feedback/<ID>/logs/` へ調査用として保持し、既存の件数・容量・フィードバック削除のルールに従います。受信時も許可項目を検証するため、旧クライアントが送る自由文は保存しません。

既存のサーバー運用ログと管理者Android診断ログは、1時間削除の対象外です。新しく出力する内容には同じ機密除外を適用します。旧形式の既存保存ログは書き換えません。アプリの運用ログは発生箇所・重大度・安全な呼び出し位置を残し、自由文・SDK応答・SQLパラメータ・例外本文は出力しません。

明示選択によるチャットコピー、フィードバック本文、添付画像はログとは別の機能です。これらを選んだ場合の送信内容は従来どおりです。

Android管理者診断の送信間隔・容量上限などは [診断ログの説明](../android/docs/DIAGNOSTICS.md) を参照してください。
