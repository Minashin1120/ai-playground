# 更新履歴 (V4.8.485)

## 箇条書きリスト描写の根本的修正 (2026-05-04)

* **箇条書きリストの Markdown 描写を完全に復元**
    * 番号付きリストをプレーンテキストとして保護するロジックが箇条書きにも干渉していた問題を、`marked` 拡張機能（Interceptor 方式）を導入することで解決しました。
    * これにより、箇条書き（`*`, `-`, `+`）については標準の Markdown としてパース・描写され、リスト内の太字（`**...**`）なども正しく表示されるようになりました。
* **リストスタイルのさらなる改善**
    * リスト記号（ディスク）が確実に表示されるよう、CSS の `list-style-type` と `list-style-position` を調整しました。
    * リスト内の段落 (`p`) が原因で余計な余白や改行が発生しないよう、表示スタイルを最適化しました。
* **番号付きリストの仕様維持**
    * 番号付きリストについては、引き続きご指示通り「モデルの出力番号をそのまま表示する（プレーンテキスト扱い）」仕様を維持しています。
