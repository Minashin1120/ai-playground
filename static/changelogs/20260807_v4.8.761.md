# V4.8.761 - Grok Imagine Image Pro の廃止対応

## 変更内容

- **Grok Imagine Image Pro を非推奨（Deprecated）に設定しました。**
  - xAI API における `grok-imagine-image-pro` の提供終了に伴い、新規選択UI（モデルリスト・モデル選択プルダウン・セットアップ画面の既定モデル選択肢）から除外しました。
  - 過去のチャット履歴の表示やトークンカウントの計算に影響が出ないよう、内部定義は維持しています。

## 補足

- DBスキーマ変更はありません。
- 廃止したモデルを利用していたチャット履歴は、引き続き正常に表示されます。
