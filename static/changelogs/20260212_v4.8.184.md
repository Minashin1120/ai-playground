# V4.8.184 (2026-02-12)

- Gemini の Vertex AI 利用時に、ユーザーごとの認証方式に対応しました。
- 設定画面に `Vertex Service Account JSON`（任意）を追加し、ユーザー単位でサービスアカウントJSONを保存できるようにしました。
- Vertex AI 実行時は、このユーザー別JSON認証を優先し、未設定時のみサーバー側ADCを利用するようにしました。
- Vertex AI クライアント初期化時に `project/location` と `api_key` を同時指定しないよう修正し、`Project/location and API key are mutually exclusive` エラーを回避しました。
- 初期セットアップ (`setup.html`) と設定モーダル (`chat.html`) の説明文を更新し、ADCまたはユーザー別サービスアカウントJSONで認証できることを明記しました。
