# v4.8.734 — アカウントデータインポートの通信耐性を強化

アカウントデータのインポート中、応答の取得に失敗した場合に「インポート応答を取得できませんでした。通信環境をご確認のうえ、もう一度お試しください」と表示され、インポートを完了できなくなる問題を修正しました。

- インポートの応答が通信環境の影響で取得できなかった場合、サーバー側の進捗状態（処理ステータス）を確認して実際の結果を判定するようにしました。インポートがサーバー側で完了していた場合は正常な完了として表示し、失敗していた場合は実際のエラー内容を表示します。
- ストレージ容量超過時にファイルを選択する画面（409応答）のデータを、サーバー側の進捗状態にも記録するようにしました。応答ボディの取得に失敗しても、このデータからファイル選択画面を表示できるため、容量超過時にファイルを選んでインポートを続行できます。
- 通信が途切れた直後にサーバー側で処理が継続している場合は、終了するまで状態を監視してから結果を表示します。設定画面（設定モーダル）でも同じ修正を適用しています。
