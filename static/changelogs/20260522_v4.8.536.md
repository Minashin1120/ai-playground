# V4.8.536 (2026-05-22)

## 修正
- **URL パス履歴（PushState）の不具合を修正**: モーダルをオーバーレイ（背景）クリックで閉じた際に `hideModal()` が直接呼ばれていたため URL パスが更新されず、履歴が不整合になる問題を修正。モーダル固有の close 関数（`closeUploadModal` 等）を介して確実に `history.back()` が実行されるようになり、モデルセレクター等の別モーダル開閉時に前のモーダルが再表示される症状が解消されました。
