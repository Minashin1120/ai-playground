# Update V4.8.556 (2026-05-27)

### xAI Grok TTS 単独モデル化の開始（UI層実装）

xAI の音声系モデルで未実装のものについて単独モデル化を進め、**Grok TTSの単独モデル化**に着手しました。

#### 背景と目的
これまで xAI 音声は Realtime Voice Agent（会話用）のみがモデルとして扱われていました。公式が提供する高品質な **Text-to-Speech API**（`/v1/tts`）を、他のプロバイダーと同様に「読み上げ専用モデル」として選択できるようにする「単独モデル化」を目指しました。

#### 実施内容
- **Audio (TTS)** カテゴリに `grok-tts` を新規追加
- モデル選択変更時に xAI 専用音声リスト（Eve, Ara, Rex, Sal, Leo）が表示されるよう `updateTtsUi()` と `getTtsProvider()` を拡張
- 速度調整（0.7〜1.5）と言語指定UIも xAI 用に動作するよう対応
- `setup.html` の既定モデル選択肢に `grok-tts` を追加

#### このバージョンの位置づけ
- UI層での「単独モデル化」は完了
- バックエンドで実際に xAI TTS API を呼び出す処理は、既存TTS（OpenAI/Gemini/Google）の処理を安全に保つため、次バージョン（V4.8.557）で本格実装
