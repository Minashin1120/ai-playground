# 更新履歴 - V4.8.1174 (2026-11-17)

数学ステップ解説の「もっとやさしく」で、分割しすぎず、理由が分かる説明になるようにしました。
- 分割は1〜3個にし、1回の計算だけのステップは1個のまま理由を補うようにしました。
- 前提知識や用語の定義を先頭に置かず、各小ステップで「何のために、どの根拠でその操作をするのか」を先に説明します。
- 分割した小ステップは「元のステップ2の『…』から説明します」と書き出し、ヘッダーにも元のステップを表示します。
- 問題文・直前のステップ・次の見出しを踏まえて書き直すようにしました。
- Androidアプリも同じ動作に揃えました。
