# 更新履歴 - V4.8.1075 (2026-10-09)

### 変更・修正
- **回答が即座に終了したときの表示**: 添付ファイルの検証エラーなど、送信直後に処理が終わった回答で完了・エラーが画面に届かず「受信中」のまま止まることがある問題を修正しました。
- **ファイル作成とPython実行の併用**: ファイル作成をオンにしたGeminiの回答で、Python実行環境内で作ったファイルを保存済みのように案内してしまうことがある問題を修正しました。ファイルの作成・編集は専用のツールを使うよう案内を追加しています。
- **Androidアプリ**: サーバー不使用モードで添付ファイル付きの送信がサーバー経由になる場合の添付エラー、および回答の停止が失敗する問題を修正しました。
