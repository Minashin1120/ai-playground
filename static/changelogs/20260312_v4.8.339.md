# Update 2026-03-12 (v4.8.339)

### 改善: 合計レスポンス時間のサーバー記録対応
*   **合計レイテンシの永続化**: 
    *   フロントエンドで計測した「合計待機時間（Total Latency）」を、回答完了時にサーバーへ送信するようにしました。
    *   サーバー側では `chat_latency_trace` テーブルに、クライアント視点での完了時刻（`client_done_at`）と合計ミリ秒（`client_total_latency_ms`）を記録します。
    *   これにより、ネットワーク遅延を含めたユーザー体感速度をサーバー側で正確に把握・分析できるようになりました。
*   **メトリクスAPIの拡張**:
    *   `/api/metrics/first_token` エンドポイントで、初回トークンだけでなく「完了報告（is_total）」も受け取れるよう拡張しました。

### 付随更新
*   `app.py` の `APP_VERSION` を `2026-03-12-010` に更新。
*   `chat.html` の表示バージョンとキャッシュバスターを `V4.8.339` に更新。
