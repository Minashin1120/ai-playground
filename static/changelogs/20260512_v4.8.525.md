# Update V4.8.525 (2026-05-12)

### モーダルのURLパス対応（PushState）
全ての主要なモーダルにおいて、開閉時にページをリロードせずにURLパスを更新する機能を実装しました。これにより、以下のメリットが得られます：
- **ブラウザの戻るボタン対応**: モーダルを開いた後、ブラウザの「戻る」でモーダルを閉じることができます。
- **ディープリンク（直接アクセス）対応**: `/settings` や `/history` などのURLに直接アクセスすると、該当のモーダルが開いた状態でアプリが起動します。
- **直感的な操作感**: 設定画面などが独立したページのように振る舞いつつ、シングルページアプリケーション（SPA）としての高速な応答性を維持します。

#### 対象となるモーダルとパス:
- **設定**: `/settings`
- **アップロード**: `/upload`
- **ライブラリ**: `/library`
- **チャット履歴**: `/history`
- **ブランチ管理**: `/branch`
- **リッチ貼り付け**: `/paste`
- **カメラ撮影**: `/camera`
- **画像編集**: `/edit-image`
- **チャット設定（指示）**: `/chat-settings`
- **モデル選択**: `/model`
- **Gem作成/編集**: `/gem`
- **画像圧縮設定**: `/compression`
- **Bot管理（管理者）**: `/admin-bots`

#### 内部的な変更:
- `app/app.py` に各モーダルパス用のルートを追加。
- `chat_core.js` に `popstate` リスナーと、各モーダル専用の `open/close` グローバル関数を実装。
- モーダル外（オーバーレイ）クリック時もURL履歴と整合性が取れるよう修正。
