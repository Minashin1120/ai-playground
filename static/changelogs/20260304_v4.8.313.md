# V4.8.313 (2026-03-04)

- チャットジョブのキューを `ai_chat_fast_queue` / `ai_chat_heavy_queue` に分離。
- キュー経由ジョブで軽量条件を満たす場合は `ai_chat_fast_queue` へ投入し、`at_front=True` で先頭投入するよう変更。
- `worker.py` の既定監視キューを `fast/heavy/legacy` に拡張し、`WORKER_INSTANCE=1,2` は fast 優先、`3,4` は heavy 優先の順序で処理するよう変更。
- `ai-chat-worker@.service` に `WORKER_INSTANCE=%i` を追加し、インスタンス番号に応じた優先順制御を有効化。
