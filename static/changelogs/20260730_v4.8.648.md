# V4.8.648

- プロンプト送信時にCSRFトークンが古いと、送信APIが403を返した後に404画面として表示される問題を修正しました。
- 複数タブやサービス再起動後にページとセッションのCSRFトークンがずれた場合、現在のセッションからトークンを安全に再取得し、失敗した更新リクエストを1回だけ自動再送します。
- CSRFトークン再取得APIはキャッシュを禁止し、同一オリジンのセッションCookieを使用します。
- Apacheの403エラーページ参照先を、実在する静的エラーページへ修正しました。
- 正当な403が404へ誤変換されず、原因に合ったエラー状態を返すようになりました。
