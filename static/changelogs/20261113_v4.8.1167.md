# 更新履歴 - V4.8.1167 (2026-11-13)

プロンプトバーに、Gemini APIの有料枠と無料枠を切り替える「無料枠」スイッチを追加しました。設定画面で有料枠・無料枠のAPIキーを別々に保存でき、無料枠がオンのときは無料枠のキーだけを使用します（有料枠のキー、モデル別キー、管理者用の環境変数キーへは切り替えません）。Vertex AIを使用しているときはこのスイッチを使いません。スイッチの状態はプロンプトごとの設定として保存・復元され、Batch、Coding Modeの自動修復、ブラウザー高速モード、入力トークンの見積もりも同じ枠のキーを使います。Android版も同じスイッチ・キー設定・キー選択に対応しました。
