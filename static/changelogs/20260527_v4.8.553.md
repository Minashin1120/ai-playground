# Update V4.8.553 (2026-05-27)

### xAI Grok 旧モデル群の非推奨化（初回実施・後に一部訂正）

V4.8.552 で追加した Grok Build 0.1 以降の流れで、公式に現在推奨されている主力モデル以外を整理するため、xAI Grok テキストモデルの非推奨化を実施しました。

#### 初回廃止対象（このバージョンで `deprecated: true` を付与）
- grok-4.20-reasoning / non-reasoning / multi-agent
- grok-4-1-fast-reasoning / non-reasoning
- grok-4-fast-reasoning / non-reasoning

#### 維持対象（アクティブのまま）
- grok-4.3
- grok-build-0.1（V4.8.552で新規追加）

#### 重要な注意（このバージョンで発生した問題）
このバージョンで 4.20 系も含めて広めに廃止したため、**V4.8.554 で緊急訂正** が必要になりました（公式ドキュメント上 4.20 系がまだ利用可能であることが判明）。

#### 廃止時の互換性維持方針
- `MODELS` 配列からモデルを一切削除せず、`deprecated: true` フラグのみ追加（過去チャット履歴・トークン計算への影響を完全排除）
- `renderModelList` と `syncModelApiKeyModelOptions` の既存フィルタで自動非表示
- ウェルカム画面は元々影響少なかったため最小限の修正
- バージョンアセット一式作成 + サービス再起動 + CF purge + git push を実施
