# V4.8.716 (2026-08-04)

## 管理者アカウントの一時ロック除外

ボット検出のアカウント一時ロックについて、管理者アカウントを監視・適用対象外にしました。

### 変更内容

- **原因**: 連打ロック適用時にユーザーIDに加え IP / クッキーにもロックが記録され、同一ネットワーク上の管理者アカウントまでロック判定・ロック画面表示の対象になっていた
- **サーバー**: `_bot_lock_info` / `_apply_bot_lock` / `_bot_lock_gate` / `/api/bot/lock` で管理者（およびプライマリ管理者）を BAN の関連アカウント除外と同じ方針でロック対象外に
- **クライアント**: 管理者にはロック画面を表示しない（ページ読込時・`account_locked` 応答時・連打報告時）
- 一般ユーザーへの IP / クッキー経由のロック（cookie削除・新規アカウント作成によるバイパス防止）は従来どおり維持

### 技術メモ

- DB変更なし
- `APP_VERSION=2026-08-04-004` / `SYSTEM_VERSION=V4.8.716`
