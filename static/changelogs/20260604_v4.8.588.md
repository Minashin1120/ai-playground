# 更新履歴 (V4.8.588) - 2026-06-04

## 変更内容
- **セキュリティ強化**:
    - http://polyfill.io/ （および cdn.polyfill.io）など、最近乗っ取り被害が報告されている危険ドメインのスクリプトを検知する仕組みを追加。
    - モデルが生成したコードブロック内に `<script src="https://polyfill.io/...">` などの危険な外部スクリプトが含まれている場合、コードヘッダーに `⚠` バッジを表示してユーザーに警告。
    - HTML コードブロックの「Preview」ボタンをクリックして新規タブで開く場合：
        - 危険スクリプト（polyfill.io 系）を自動的に除去・置換し、赤い警告バナーを挿入した「安全プレビュー」HTML を生成して開く。
        - パスワード入力（`prompt('password...')` など）や認証情報を扱う疑わしいインラインスクリプトもヒューリスティック検知してブロック。
        - 検知時はトーストで「⚠ 危険な外部スクリプトを検知... プレビューではブロックして開きます。」と通知。
        - ボタンラベルを「Safe Preview」（盾アイコン）に変更して区別。
    - フォールバックとして DOMParser 失敗時も正規表現で最低限の polyfill.io スクリプト除去を実施。
    - javascript: プロトコルリンクもプレビュー内で無力化（防御深度）。

## 技術的な変更
- `app.py` の `APP_VERSION` を `2026-06-04-009`、`SYSTEM_VERSION` を `V4.8.588` に更新。
- `chat_core.v4.8.588.js` を新規作成（polyfill 検知・サニタイズロジック `detectBlockedScriptsInCode` / `sanitizeHtmlForPreview` / `openHtmlCodePreview` 修正、marked レンダラーの code フックにバッジ/ボタン分岐を追加）。
- `chat.custom.v4.8.588.css` を新規作成（`.suspicious-badge` スタイル追加。Tailwind は前バージョンからコピー）。
- 旧バージョン資産（v4.8.587 の JS/CSS）はリポジトリから削除（AGENTS.md 規定の「最新バージョンのみ保持」対応）。
- `static/changelogs/20260604_v4.8.588.md` を新規作成。
- サービス再起動 + Cloudflare CDN キャッシュパージ + git commit/push 予定（AGENTS.md 全手順厳守）。

これにより、LLM が不用意に生成した polyfill.io スクリプトがユーザーのプレビュー操作で実行されるリスクを大幅に低減します。コードブロックの表示時にも視覚的警告が入るため、ユーザーがコピーする前にも気づきやすくなりました。
