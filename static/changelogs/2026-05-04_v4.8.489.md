# Changelog - V4.8.489 (2026-05-04)

## Bug Fixes
- **PDF Capture Responsiveness**: Fixed an issue where the PDF capture button appeared to not react on the first click.
    - Added an immediate feedback toast ("PDF出力の準備中です...") on the first click.
    - Implemented a 5-second timeout for image loading within the PDF frame to prevent hanging on slow or broken images.
    - Switched from `srcdoc` to a Blob URL for the iframe to improve compatibility and avoid some CSP/Rocket Loader quirks.
    - Improved the locking mechanism to prevent multiple simultaneous capture attempts.
    - Corrected Japanese strings that had misplaced spaces.
