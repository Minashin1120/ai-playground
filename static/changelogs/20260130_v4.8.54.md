# 更新履歴 (V4.8.54) - 2026-01-30

## Grok Imagine 修正
- **Grok Imagine 画像生成エラーの修正**
    - `grok-imagine-image` モデルで画像生成（Text-to-Image）を行う際に、`aspect_ratio` が `TypeError` を引き起こす問題を修正しました。
    - OpenAI Python SDK の仕様に合わせ、xAI 独自のパラメータである `aspect_ratio` を `extra_body` 経由で送信するように変更しました。
- **Grok Imagine 画像編集の安定化**
    - 画像編集（Image-to-Image）時に不要なパラメータが送信されないよう調整しました。
