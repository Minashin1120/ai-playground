# V4.8.565 (2026-05-30)

## ログインページ上部が隠れる（クリップされる）問題の修正

### 問題
- ログインページ（`/login`）にて、ページ上部（ログインフォームのタイトルや入力欄）が画面上端で隠れて表示される不具合が発生していました。
- 特に以下の条件で顕著：
  - モバイル端末（iOS Safari 等）で画面高さが小さい場合
  - パスキーセクションや2FA画面表示時などコンテンツ全体の高さがビューポートを超えた場合
  - `viewport-fit=cover` 指定環境でのノッチ/セーフエリア非考慮
- 原因: `h-screen`（`height: 100vh`） + `justify-content: center` の組み合わせで、子要素（auth-card + footer）の合計高さがコンテナ高さを超えると、flexbox の中央寄せによりコンテンツ上部が負のオフセットでビューポート外に配置されクリップされていた。

### 修正内容
- `app/templates/login.html`:
  - `<body>` のクラスを `h-screen` → `min-h-screen` に変更（コンテンツ高さ超過時はコンテナが拡張され、上部クリップが発生しなくなる）。
  - body CSS ルールに `padding: max(1rem, env(safe-area-inset-*))` を追加し、ノッチ付きデバイスや Dynamic Island 環境でも上部・下部・左右のセーフエリアを確実に確保。
- 同様のレイアウト問題を抱えていた `signup.html` および `maintenance.html` も `h-screen` → `min-h-screen` に統一修正（予防的改善）。
- バージョン管理整合性のため、V4.8.565 向け必須4資産を準備（前バージョンからJS/CSSをコピー、本changelog作成）。

### 影響
- ログイン / 新規登録 / メンテナンス画面で、どのような画面サイズ・デバイスでもページ上部が隠れず、必要に応じてスクロールして全コンテンツが閲覧可能に。
- 通常のデスクトップ/十分な高さの画面では従来通り垂直中央寄せの見た目を維持。
- 他のページ（チャット画面等）のレイアウトやJS/CSSには一切影響なし。
