# V4.8.202 (2026-02-16)

- プロンプトバーに「詳細」トグルを追加し、コンパクト表示時はモデル選択のみ表示、必要なときだけ詳細設定を展開できるようにしました。
- 設定モーダル（一般）に「プロンプトバー表示 > コンパクト表示（モデル選択のみ表示）」を追加し、表示モードを切り替えられるようにしました。
- `/api/settings` に `compact_prompt_mode` を追加し、ユーザー単位で保存・復元できるようにしました。
- `user` テーブルへ `compact_prompt_mode` カラムを追加し、起動時マイグレーションで不足時に自動作成するようにしました。
- チャット画面タイトルを `V4.8.202` に更新しました。
