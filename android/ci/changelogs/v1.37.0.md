- The login screen now has a "接続先" (server) field. Besides the official server you can sign in to a self-hosted AI Playground server over https; the app checks the server first and only offers the sign-in methods it supports.
- On self-hosted servers, browser sign-in, account linking and the safety check return to the app through the app's own link (PKCE protected). Native Google sign-in and Play Integrity stay on the official server.
- The server you signed in to is stored with your session, and offline data is kept separately for each server.
- Gem instructions are now sent with your messages, the same as on the Web version.
