# V4.8.569 (2026-06-02)

## ログイン画面オーロラ背景アニメーションの速度向上

### 調整内容
ユーザーの「もっとアニメーションする速度を早くしてください」というリクエストに対応。

- アニメーション周期を大幅に短縮（約2倍速）：
  - drift-1: 37s → **18s**
  - drift-2: 29s → **14s**
  - drift-3: 41s → **20s**
  - violet (drift-1): 33s → **16s**
- animation-delay も比例して短縮（動きがより活発に感じられるように）
- 動きの軌道（キーフレームのtranslate量）は変更せず、**速度だけを速く**した
- 視認性（blur 32px / opacity 0.52 など）は V4.8.568 の強い設定を維持

### 影響
- ログイン / 新規登録 / 2FA 画面の背景の光の動きが、以前より明らかに活発でリズミカルに見えるようになった。
- それでもログイン作業を邪魔しない程度の速さ（ユーザーの「もっと早く」要望を反映）。
- その他ページ・機能への影響なし。
