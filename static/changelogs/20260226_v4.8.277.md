# V4.8.277 (2026-02-26)

## LLM方式の文字起こしで無音/極小音量時の誤文字起こしを抑制

LLM方式の文字起こしで、録音音声が入っていない（または極端に小さい）場合に存在しないテキストを生成してしまうケースがあったため、入力音声の検出とマイク取得設定を見直しました。

### 変更内容
* **LLM文字起こしの無音ガードを追加**: `ffmpeg` 変換後PCMの音量（RMS/peak）を確認し、無音/極小音量と判定した場合は文字起こしを実行せずエラーを返すよう変更。
* **LLMプロンプトを強化**: OpenAI/Gemini の LLM文字起こし指示に「推測禁止」「無音時は専用トークン返却」を追加し、幻覚的なテキスト生成を抑制。
* **ブラウザ録音のノイズ抑制を無効化**: 添付横STTボタン（非STS時）の `getUserMedia` で `noiseSuppression` / `autoGainControl` / `echoCancellation` を可能な範囲で明示的にOFFにし、声が消えるケースを低減。
* **表示バージョン更新**: `chat.html` の表示バージョンと `chat_app.js` キャッシュバスターを `V4.8.277` に更新。
