# 更新履歴 - V4.8.1047 (2026-10-03)

Ideogram 4.5 / 4.0 / 3.0 / 2a / 2.0 の画像生成モデルを追加しました。設定とセットアップに Ideogram API Key の入力欄を追加し、画像生成パネルで枚数、縦横比、解像度、品質、速度、Magic prompt、スタイル、除外する要素、Seed を指定できます。Ideogram 4.5 は、画像を添付するか直前の画像がある場合に Precise Edit で変更箇所以外を保ったまま繰り返し編集できます（マスクには対応していません）。Android版にも同じモデルと設定を追加し、サーバー不使用モードでも端末から直接生成できるようにしました。
