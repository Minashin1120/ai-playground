# V4.8.573 変更履歴 (バグフィックス)

**日付:** 2026-06-03

## 修正内容
- **Gemini ツール呼び出しエラー修正**: `Models.generate_content() got an unexpected keyword argument 'tools'` を解決。
  - google-genai 1.56.0 (v1系) では `tools=` / `system_instruction=` をトップレベル引数で渡せない。
  - 既存コード全体で使用されている `config=types.GenerateContentConfig(tools=..., system_instruction=...)` パターンに完全統一。
  - Gemini 3.1 Flash-Lite などでの設定AI機能が正常に動作するよう修正。
- **モデル選択モーダル表示修正**: 設定モーダル内で「モデル選択」を押した際にモデルモーダルが設定モーダルの下に隠れる問題を修正。
  - `#model-modal` の z-index を `z-50` → `z-[60]` に変更（カメラモーダルや alpha-bar と同等レベルに統一）。
  - 設定モーダル (z-50) の上に正しく重ねて表示されるようになりました。

## その他の変更
- JS側のAI適用エンドポイントURL構築をより堅牢な直接パスに修正（クエリ文字列汚染防止）。
- すべての変更で要素存在チェック・try-catch・AGENTS.mdのJS安全規則を遵守。

## 影響
- 設定AI機能（自然言語で設定変更）がGeminiモデルでも安定して利用可能に。
- モデル選択モーダルがどの画面から開いても正しい重ね順で表示。
- 既存の通常チャット・設定保存に影響なし。

**リリース**: AGENTS.md全手順厳守（V4.8.573資産コピー、changelog、引き継ぎ更新、サービス再起動、CDN purge、git push）。
