# V4.8.667 — MathJax数式が生記号のまま表示される問題を修正

## 修正内容
- **原因**: Markdownパーサ（marked）が `\(...\)` や `\[...\]` のバックスラッシュをエスケープとして除去し、MathJaxが認識できるデリミタが消えていた。
- **対応**:
  - 数式セグメントを `protectMathSegments` でプレースホルダへ退避してから marked で変換し、`restoreMathSegments` で復元
  - コードフェンス内の LaTeX ソースは保護対象外として維持
  - `$$...$$` / `\(...\)` / `\[...\]` / `$...$` / `\begin{...}` を対象
  - MathJax 設定に `$...$` と `\[...\]` を追加
  - ストリーム再描画後の typeset 失敗を防ぐため `typesetClear` を実行してから `typesetPromise`
