# 更新履歴 (V4.8.455) - 2026-04-26

## PDF生成フィルタリングの徹底強化

### 修正内容
* **タグフィルタリングの完全同期**:
    * `inline_markup` と `render_node` の両方の関数で、PDF生成に不要かつ ReportLab でエラーの原因となるタグ（`link`, `meta`, `head`, `script`, `style` 等）を同一の厳格なリストで除外するようにしました。
    * これにより、`paraparser: syntax error: invalid attribute name rel` などのパースエラーを根本から解決しました。
* **特殊ノード判定の堅牢化**:
    * `bs4` の `Doctype`, `Comment`, `Declaration`, `CData` 等の特殊なノードの判定を、クラス名を用いたより確実な方法に変更し、不適切なテキストが PDF エンジンに渡るのを防止しました。
* **ブロック要素の処理最適化**:
    * `html`, `body` などのルートレベルのタグが直接 `render_node` に渡された場合でも、その子要素を適切に再帰処理し、かつ不要なラッピングが発生しないようロジックを微調整しました。

* `app.py` の `APP_VERSION` を `2026-04-26-006` に更新。
* `chat.html` の表示バージョンを `V4.8.455` に更新。
