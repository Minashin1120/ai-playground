# Update V4.8.552 (2026-05-27)

### xAI Grok Build 0.1 (Coding) の新規追加実装

一連の xAI モデル整備作業の最初として、公式ドキュメントで新たに推奨されていた **Grok Build 0.1** を正式にサポートしました。

#### 追加モデル
- **ID**: `grok-build-0.1`（エイリアス: grok-code-fast-1, grok-code-fast）
- **位置づけ**: Agentic coding に特化した高速モデル
- **特徴**（公式情報）:
  - 256k コンテキスト
  - Vision（画像）入力対応
  - Function calling / Structured outputs / Reasoning 対応
  - 価格: Input $1.00 / Output $2.00 per 1M tokens

#### UI / 内部変更
- xAI Grok カテゴリに優先的に配置
- ウェルカム画面にクイックスタートボタンを追加
- セットアップ画面の既定モデル選択肢に追加
- 推論（reasoning_effort）対応を `grok_reasoning_*` 判定ロジックに追加（app.py）
- 既存の Grok 画像入力・ツール呼び出し経路をそのまま利用可能

この追加により、「コーディング用途では Build 0.1 を、汎用には Grok 4.3 を」という使い分けが明確になりました。
