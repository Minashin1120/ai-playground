# Update Log (2026-04-19) - V4.8.425

## Server-side PDF Payload and UI Fix
- サーバー側PDF生成の送信HTMLを、サニタイズ済みHTMLではなく生の `innerHTML` を送る形へ変更しました。
- サーバー側モードでも進行状況バーを表示し、送信中 / 受信中 / 添付中 / 完了を見える化しました。
- サーバー側PDFのフォールバックレンダラは削除し、失敗時は明示的にエラーを返すように戻しました。
- `missing_html` の場合は、ユーザーに取り込み不足を明示するエラーへ変更しました。

## Cloudflare Cache Purge Tool
- Cloudflare の CDN キャッシュを手動クリアできる `app/scripts/purge_cloudflare_cache.sh` を更新しました。
- `CF_ACCOUNT_ID` / `CF_ZONE_ID` / `CF_API_KEY` を `$HOME/.env` に保存し、実行時はそこから読み込みます。
- 既定では zone 名の hostname のみを purge し、ゾーン全体は消さないようにしました。
- 必要な場合だけ `CF_PURGE_HOSTS` で複数 hostname を上書きできます。

## Server-side PDF Error Handling Fix
- サーバー側PDF生成で `request.json` の強制パースにより 400 になりうる問題を修正しました。
- `request.get_json(silent=True)` とフォールバック解析に変更し、JSON受信失敗時でも明示的なエラーを返すようにしました。
- 受信時の `content_type` / `content_length` をログ出力するようにして、次回から原因追跡しやすくしました。
- `APP_VERSION` を `2026-04-19-004` に更新し、古いJSキャッシュをさらに避けやすくしました。

## Admin-only Server-side PDF Path
- 管理者アカウント向けに、リッチ貼り付け内容をサーバー側でPDF生成して送信する経路を追加しました。
- クライアント生成に失敗した場合でも、管理者はサーバー生成で同じ送信フローを使えます。
- `app.py` に `POST /api/rich-paste/pdf` を追加し、PDF生成は `reportlab` + `beautifulsoup4` で行います。
- フロント側には管理者専用の「サーバー側でPDF化して送信」ボタンを追加しました。
- `APP_VERSION` を `2026-04-19-003` に更新し、キャッシュによる古いJS配信を避けやすくしました。

## PDF Generation Improvements (Rich Paste)
- クリップボードのリッチ貼り付けをPDF化する際に、PDF側の一律カラーリセットで元の装飾が潰れる問題を修正しました。
- PDFレンダリング時に貼り付け内容を再サニタイズし、inline style を優先したまま描画するように変更しました。
- 太字、リンク色、背景色、見出し、テーブル、コードブロックの見た目が PDF でも維持されやすくなりました。
- 画像・フォントの読み込み待機を共通化し、PDF化時の再現性を改善しました。
- `pre > code` をブロックコードとして扱い、コードブロック内のインラインコード化や背景潰れを防ぐようにしました。

## Progress Bar Fix
- PDF生成中の進行状況バーを `width` 更新から `transform: scaleX()` 更新へ変更し、数値だけ変わってバーが動かない問題を修正しました。
- バーの初期状態を `scaleX(0)` にし、描画更新が安定して見えるようにしました。

## System Updates
- `app.py` の `APP_VERSION` を `2026-04-19-005` に更新。
- フロントエンドのリソースを `V4.8.425` に維持しつつ、PDF生成の見た目崩れ修正を反映。
