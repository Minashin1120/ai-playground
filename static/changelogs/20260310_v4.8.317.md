# V4.8.317 (2026-03-10)

- LLM へ途中で切り替えた場合でも、過去の回答で生成された画像を履歴入力へ含めるよう修正しました。
- `Gemini` テキストモデル、`OpenAI Responses`、`OpenAI Search`、`Grok` ネイティブSDKの各LLM経路で、`assistant` ロールに保存された画像も履歴コンテキストとして再送するよう統一しました。
- これにより、画像生成モデルで出した画像を踏まえて、そのままLLMへ切り替えて画像内容の続きの指示や質問を行いやすくなりました。
- 既存の画像生成モデル側の履歴画像再利用は維持しており、LLM から画像生成モデルへ戻した場合も過去画像を参照しやすい状態を継続します。
- 画面内の表示バージョンと `chat_app.js` のキャッシュバスターを `V4.8.317` に更新しました。
