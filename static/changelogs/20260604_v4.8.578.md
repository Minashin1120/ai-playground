# V4.8.578 変更履歴 (バグフィックス)

**日付:** 2026-06-04

## 修正内容
- **スラッシュコマンド候補ポップアップの画面外表示問題を修正**
  - `/` コマンド候補リストが入力欄の下に表示され、画面下部でビューポート外に出てしまう問題を解決。
  - スマートポジショニングを実装：
    - 下に十分なスペースがない場合は自動的に**入力欄の上**に表示するよう変更。
    - 利用可能なスペースに応じて `max-height` を動的に調整。
  - 横方向のはみ出しも最小限に抑える処理を追加。

これにより、画面サイズが小さい場合やチャット履歴が多い状態でもコマンド候補が快適に選択できるようになりました。
