# AI Chat Update (V4.8.324) - 2026-03-12

## Gemini ストリーミング表示のリアルタイム化最適化

Gemini モデル（特に Flash 系統）において、ストリーミング生成中の表示が数秒ごとにまとまって更新される（カクつく）現象を解消するための最適化を行いました。

### 1. バックエンド：Redis Publish の集約化
- `google-genai` SDK v2 において、1つの API レスポンスチャンク内に複数のテキストパート（Thought, Text）が含まれる場合、それらを結合して1つの Redis PubSub イベントとして送信するように変更しました。
- これにより、通信およびフロントエンドでの受信イベント数が削減され、オーバーヘッドが軽減されました。

### 2. フロントエンド：Markdown レンダリングのスロットリング
- ストリーミング受信ループにおいて、`reader.read()` 1回分（複数の JSON イベントが含まれる可能性がある）の処理を完了した後にまとめて DOM 更新を行うようにロジックを改善しました。
- Markdown レンダリング (`marked` + `DOMPurify`) に対して約 80ms のスロットリングを導入しました。
- テキストが長くなるにつれて指数関数的に増大するレンダリング負荷 (O(N^2)) を抑え、ブラウザのメインスレッドがブロックされるのを防ぎます。
- ストリーミング終了時には最終的なレンダリングを必ず実行し、漏れがないことを保証します。

### 3. システムバージョンの更新
- システムタイトルおよび UI 上のバージョン表示を `V4.8.324` に更新しました。
