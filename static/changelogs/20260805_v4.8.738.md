# v4.8.738 — サーバーメンテナンス中表示の判定を修正

接続状態バーの表示判定を修正しました。

- サーバー再起動時などに返される 503 でも「サーバーはメンテナンス中です（自動再接続します）」と表示されるようになりました。これまで 503 のうち専用ヘッダー付きのものだけをメンテナンスと判定し、それ以外の 503 は「サーバーが停止しているか応答していません」と表示していました。
- 通信自体が発生しないネットワーク接続エラー（接続が切れた、応答がない、タイムアウトなど）では「インターネット接続が切断されています」と表示されるようになりました。これまで `navigator.onLine` が true のまま通信が失敗した場合に「サーバーが停止しているか応答していません」と表示していました。
- 502/504 や Cloudflare の到達不能系ステータス（521〜524）では従来どおり「サーバーが停止しているか応答していません」と表示します。
