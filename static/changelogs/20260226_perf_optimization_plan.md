# 2026-02-26 軽量化計画（調査・計画のみ）

## 概要
最近の読み込み速度低下に対して、コードベースを確認し、実装前の軽量化プランを整理しました。

今回は **改善案の作成のみ** で、機能変更は行っていません。

## 調査で見えた主な要因候補
* `templates/chat.html` が大型化（約573KB / 9,500行超）
* 初回ロード時に重いライブラリを複数読み込み（MathJax / highlight.js / Tailwind CDN 等）
* `/api/threads/<id>` がスレッド本文を全件返却（長大スレッドで遅くなりやすい）
* 本番時の `DEBUG` ログ書込み頻度が高い（I/O負荷）

## 優先順位付きの改善案
### P0（先にやる）
* `chat.html` のJS/CSSを静的ファイルへ分割（HTML軽量化 + キャッシュ活用）
* `MathJax` / `highlight.js` / `browser-image-compression` の遅延ロード
* `cdn.tailwindcss.com` 依存の廃止（事前ビルドCSSへ）

### P1（次にやる）
* `/api/threads/<id>` の段階読み込み（初回は最新N件 + 追加読込）
* `log_force()` / 全リクエストDEBUGログの削減

### P2（追加最適化）
* gzip/brotli 圧縮有効化
* フォントの読み込み最適化
* 画像/サムネイル運用の見直し
