# V4.8.278 (2026-02-26)

## 自動注入システムプロンプト設定に `MathJax` 項目を追加

バックエンドに追加済みの自動注入システムプロンプト項目 `mathjax`（LaTeX数式出力案内）が、設定画面の一覧に表示されていなかったため、ユーザー設定/スレッド設定の自動注入システムプロンプト編集UIに追加しました。

### 変更内容
* **設定UI項目を追加**: `templates/chat_app.js` の `AUTO_SYS_PROMPT_ITEMS` に `mathjax`（`MathJax（LaTeX数式）`）を追加。
* **対象UI**: 設定モーダルのユーザー単位設定、およびスレッド設定側の自動注入システムプロンプト編集UIの両方に反映。
* **表示バージョン更新**: `chat.html` の表示バージョンと `chat_app.js` キャッシュバスターを `V4.8.278` に更新。
