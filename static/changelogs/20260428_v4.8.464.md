# 更新履歴 (V4.8.464)

**作成日:** 2026-04-28
**システムバージョン:** V4.8.464

### **ブランチ管理：モデル別トークン内訳表示の実装**
ブランチ（パス）内で複数のモデルを切り替えて使用した場合に、どのモデルがどれだけのトークンを消費したかを詳細に確認できるようになりました。

*   **モデル別内訳の表示**:
    *   ブランチ詳細パネルに「モデル別内訳（パス累計）」セクションを追加しました。
    *   パス（起点から選択したノードまで）で使用された全モデルをリストアップし、モデルごとに以下の数値を表示します：
        *   **Total**: そのモデルでの合計消費量
        *   **In / Out**: 入力トークンと出力トークンの内訳
        *   **Thought**: 推論モデル（Gemini 2.0 Thinking 等）を使用した場合の推論トークン数
*   **UIレイアウトの改善**:
    *   画面サイズに応じて、詳細パネルがツリー図の右側に正しく表示されるようレイアウトを調整しました。
    *   詳細パネル内の情報が増えたため、内訳セクションにスクロール機能を追加し、使いやすさを向上させました。
*   **計算ロジックの修正**:
    *   パス全体の累計トークン計算を、全メッセージの `tokens`, `tokens_in`, `tokens_out` を正確に合算するように最適化しました。
