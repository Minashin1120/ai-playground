# v4.8.249 (2026-02-24)

### 🚀 改善
* **回答生成中のプロンプト送信制限の強化**
    * 回答生成中（ストリーミング中）に別のプロンプトが送信されないよう、`sendMessage` / `resumePendingStream` / `mic-btn.onclick` に `abortController` によるチェックを追加しました。
    * 生成中に送信を試みた場合、警告トースト（「回答生成中です。完了までお待ちいただくか、停止してください。」）を表示するように改善しました。
    * これにより、Enterキー連打やボイス入力の重複起動による意図しない二重送信を完全に防止しました。
