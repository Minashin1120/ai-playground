# V4.8.273 (2026-02-26)

## STTボタンの文字起こし方式を設定から切替可能に

添付ボタン横の `STT` ボタンについて、設定画面から従来の OpenAI STT API に加えて、LLM（`gpt-audio-mini`）による文字起こしを選択できるようにしました。

### 変更内容
* **設定追加**: 設定 > 音声設定に `マイク文字起こし方式` を追加（`OpenAI STT API` / `LLM (gpt-audio-mini)`）。
* **設定保存**: ユーザー設定に `mic_transcribe_mode` を追加し、設定APIの GET/POST で保存・復元可能に変更。
* **STTボタン連携**: 添付ボタン横の `STT` ボタンは、設定された方式に従って `/transcribe` の処理を分岐。
* **LLM文字起こし実装**: 録音音声（webm等）をサーバー側で `ffmpeg` 経由で wav に変換し、`gpt-audio-mini` へ音声入力して文字起こしを実施。
* **後方互換**: 既存の `STTモデル` 設定は維持し、`OpenAI STT API` 選択時のみ使用。
* **表示バージョン更新**: `chat.html` の表示バージョンと `chat_app.js` キャッシュバスターを `V4.8.273` に更新。
