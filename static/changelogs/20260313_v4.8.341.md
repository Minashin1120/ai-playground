# Update 2026-03-13 (v4.8.341)

### 修正: GPT Image 系の画像生成における回答停止（キャンセル）対応
*   **Responses API と Background Mode の導入**:
    *   OpenAI GPT Image 系のモデル (`gpt-image-1.5`, `gpt-image-1`, `gpt-image-1-mini`) での画像生成に、新たに `Responses API` の `background: true` モードを採用しました。
    *   これにより、生成中に「停止」ボタンを押した際、サーバー側で OpenAI へのリクエストを確実にキャンセル（`client.responses.cancel`）できるようになりました。
*   **生成中断の同期**:
    *   以前は停止ボタンを押してもサーバー側で生成が継続されていましたが、今回の修正でサーバー側の処理も中断され、リロード後に生成が勝手に完了している問題を解消しました。
*   **ポーリングと停止監視**:
    *   生成ジョブの状態をポーリングしながらユーザーの停止操作を監視し、停止指示があれば即座にキャンセルコマンドを発行するロジックを実装しました。

### 付随更新
*   `app.py` の `APP_VERSION` を `2026-03-13-002` に更新。
*   `chat.html` の表示バージョンとキャッシュバスターを `V4.8.341` に更新。
