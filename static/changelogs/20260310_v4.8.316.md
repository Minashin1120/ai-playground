# V4.8.316 (2026-03-10)

- 画像編集モデルのフォローアップ送信で、2件目以降に先行ターンのプロンプトや画像が無視される問題を修正しました。
- `app.py` に画像系モデル向けの履歴コンテキスト再構築処理を追加し、過去のテキスト文脈と履歴画像を再利用するよう改善しました。
- `GPT Image` は、現在添付画像がなくても直前までの履歴画像を編集入力へ補完できるようになりました。
- `Gemini` 画像モデルは、履歴画像と会話文脈をまとめて `generate_content` に渡すよう変更しました。
- `Grok Imagine` は、フォローアップ時に履歴文脈をプロンプトへ統合し、履歴画像を編集入力として再利用するよう変更しました。
- 画面内の表示バージョンと `chat_app.js` のキャッシュバスターを `V4.8.316` に更新しました。
