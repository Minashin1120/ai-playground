# Update V4.8.554 (2026-05-27) - 訂正リリース

### 4.20 系モデルの廃止解除（訂正リリース）

V4.8.553 で実施した xAI 旧モデル廃止処理において、**grok-4.20 系を過剰に廃止してしまった**ため、緊急訂正リリースを実施しました。

#### 経緯
- 公式ドキュメント（docs.x.ai のモデル一覧・価格表）に `grok-4.20-0309-reasoning` などが現在も明記されていることを再確認

#### 訂正内容
- `grok-4.20-reasoning`、`grok-4.20-non-reasoning`、`grok-4.20-multi-agent` の `deprecated: true` を除去し、アクティブに戻す
- 廃止対象を「より古い fast 系（grok-4-fast / grok-4-1-fast）」のみに限定

#### 最終的な xAI Grok テキストモデルのステータス（V4.8.554時点）
**アクティブ**:
- grok-4.3
- grok-build-0.1
- grok-4.20-reasoning / non-reasoning / multi-agent

**deprecated**:
- grok-4-1-fast-reasoning / non-reasoning
- grok-4-fast-reasoning / non-reasoning

#### 対応詳細
- `chat_core.v4.8.553.js` のモデル定義を修正
- `setup.html` の xAI Grok optgroup に 4.20 系を復活
- 4.20系をモデル選択画面と初期設定画面へ復帰

この訂正により、公式に現在も利用可能とされているモデルが正しく選択可能になりました。
