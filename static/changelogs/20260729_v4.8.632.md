# V4.8.632

## リッチ貼り付けのダーク／ライト配色を保持

- 貼り付け元がダークモードのとき、明るい文字色だけが残って白いプレビューやPDF上で見えなくなる問題を修正しました。
- クリップボードHTML内で背景が覆っている本文量と文字色の分布を解析し、コンテンツごとにライト／ダークテーマ、背景色、既定文字色を判定するようにしました。
- クリップボードがページ背景を含めなかった場合も、明るい文字色が優勢なら読みやすいダーク背景を補完します。
- プレビュー、ブラウザPDF、管理者向けサーバーPDFで同じテーマ情報を共有し、ページ全面、タイトル、本文、表、コード、引用、リンク、ページ番号まで一貫した配色にしました。
- `rgb()`、16進色、HSLに加え、`oklab()` / `oklch()` をサーバー側のテーマ判定でも解析します。受信したテーマ値はCSSとして直接信頼せず、安全なRGB値へ正規化します。

## 画面用レイアウトによるPDF欠落を修正

- 固定サイドバー用の大きな左右余白や、デスクトップ画面用の固定幅がA4へ持ち込まれ、本文右端が切れる問題を修正しました。
- 大規模ページ、複雑なflex/grid、96px以上の画面用余白、720pxを超える固定本文幅を検出し、PDF生成時だけ印刷向けレイアウトへ変換します。
- 背景、文字色、フォント、罫線、コード装飾などの内容スタイルは維持します。

## 検証

- ChromiumでOpenAI Docs、MDN、GitHub DocsのダークモードとWikipediaのライトモードを実際に全選択コピーし、元ページとテーマ判定が一致することを確認しました。
- OpenAI Docsの実クリップボードからブラウザPDFとサーバーPDFを生成し、暗色のページ全面、明るい本文、コード背景、末尾までの出力を目視確認しました。
- MDNとGitHub Docsの実クリップボードからサーバーPDFを生成し、背景、本文、リンク、カード、コードの可読性を目視確認しました。
- 背景情報を含まない明色文字のテストでも、ダーク背景を補完して可読性を維持することを確認しました。
- Python／JavaScript構文検査と全33件の回帰テストに成功しました。
