# V4.8.765 - チャットUI全体のデザイン刷新（プロンプトバー・サイドバー・会話画面）

## 変更内容

### プロンプトバー
- 入力欄・添付・音声・送信を一体の入力シェルにまとめ、余白とボタンサイズを圧縮
- モデル選択や Canvas / Coding / 高速 をピル型チップに統一
- Search / Python / Thinking など詳細オプションをコンパクトなチップ列へ再配置
- 通常表示・コンパクト表示の両方で、情報量を保ったまま視認性と密度を改善

### サイドバー
- アイコンツールバー・検索・Gems・スレッド一覧の余白と階層を整理
- ログアウトやフッターリンクのトーンを抑え、操作導線を明確化

### チャット画面
- メッセージバブルの影・角丸・余白を調整し、読みやすさを向上
- ウェルカム画面を2列グリッド化（狭い画面では1列）し、導入文を追加
- 背景グリッドとトークンバーなど周辺UIのノイズを低減

### サイト全体
- デザイントークン（線色・パネル透明度）を `app-design.css` と同期
- 認証カード・機能カードの影とホバーを落ち着いたトーンへ調整
- Liquid Glass / パフォーマンスモードでも新しい入力シェルが破綻しないよう対応

DBスキーマ変更なし。
