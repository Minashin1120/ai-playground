# Changelog - V4.8.490 (2026-05-04)

## New Features
- **PDF Capture Progress Bar**: Added an animated progress bar to the PDF capture notification.
    - Shows real-time progress of data fetching, resource loading (fonts/images), and MathJax typesetting.
    - Displays progress percentage numerically.
    - Provides immediate visual feedback during the preparation phase.

## Bug Fixes
- **Japanese Strings**: Cleaned up extra spaces in Japanese toast messages that were introduced in previous versions.
- **Stability**: Refined the cleanup logic to ensure the progress toast is removed correctly upon completion or failure.
