# V4.8.53 (2026-01-30)

## Grok Imagine 完全実装
- **Grok Imagine Video (grok-imagine-video) を追加**
    - xAI の最新動画生成モデル「Grok Imagine Video」を統合。
    - テキストおよび画像からの動画生成に対応。
- **動画生成オプション UI の追加**
    - 生成時間（1〜15秒）、アスペクト比、解像度（720p / 480p）の選択に対応。
    - ポーリング（Deferred Request）方式による生成プロセス管理を実装。
- **Grok Imagine Image の名称修正と UI 改善**
    - モデル名を「Grok Imagine Image」に整理。
    - カテゴリ名を「Grok Imagine」に統一し、画像・動画の両方を配置。
- **非LLMモデルの制約を最適化**
    - 動画生成モデルにおいて Python 実行やシステムプロンプトなどの不要な UI を非表示化。
- **バックエンドの安定化**
    - 動画生成結果の自動ダウンロードとユーザーディレクトリへの保存（E2EE対応）。
