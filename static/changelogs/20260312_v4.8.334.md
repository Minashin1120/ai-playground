# 更新履歴 (2026-03-12) - V4.8.334

## 🚀 画像圧縮設定のカスタマイズ機能追加
クライアント側での画像圧縮設定をユーザーが自由に変更できるようになりました。

### 🛠 変更内容
- **プロンプトバーに設定アイコンを追加**: 「Compress」チェックボックスの横に歯車アイコンを追加し、設定モーダルを呼び出せるようにしました。
- **画像圧縮設定モーダルの実装**:
    - **最大ファイルサイズ (MB)**: 指定したサイズを超える画像を圧縮対象にします。
    - **最大幅/高さ (px)**: 縦横比を維持したまま、指定したピクセルサイズ内にリサイズします。
- **設定の永続化**: 変更した設定値はブラウザの `localStorage` に保存され、次回以降も自動的に適用されます。
- **圧縮ロジックの動的化**: `chat_app.js` 内の画像圧縮処理を、固定値から設定値を使用するように修正しました。

### 📦 バージョン更新
- システムバージョンを `V4.8.334` (Internal: `2026-03-12-004`) に更新しました。
