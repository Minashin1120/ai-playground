# v4.8.744 — ランディングページの横スクロールと余白を修正

- スマートフォン（幅360〜450px程度）でページが**横スクロールできる**問題を修正しました。
- 原因: ヒーロー部の対応モデルバッジ（`inline-flex`）が長いラベル（"Gemini 3.6 / GPT-5.6 / Grok 4.3 / Claude / DeepSeek / Kimi 対応"）を折り返さない単一フレックスアイテムとして扱い、**min-content幅が約410px**に広がっていたため、グリッドカラムがビューポート幅を超えて横にはみ出していました。
- 修正: ①バッジのテキストを `<span>` に分離して `flex-wrap` を追加し、狭い画面でも折り返して収まるように変更。②ヘッダーに `flex-wrap` を追加し、モバイルでロゴとナビゲーションが重ならないように変更。③`html, body` に `overflow-x: clip` を設定し、どの要素が原因でも横スクロールバーが発生しないようにガード（スクロールコンテナを生成しない `clip` を使用）。
- 余白も調整: ヒーロー部の上下パディングを縮小（`py-16 md:py-24` → `py-10 md:py-20`）し、狭い画面でヒーローが不必要に縦長にならないようにしました。
- CDP計測（`scripts/measure_landing_cdp.py`、幅360/375/414/768/1024/1345px）で横スクロール発生なし・負マージンなし・デモ/ハブのビルド正常を確認済み。
- DBスキーマ変更なし。`APP_VERSION=2026-08-06-003` / `SYSTEM_VERSION=V4.8.744`。旧V4.8.743資産を削除し必須4資産を作成（chat_core/CSS/Tailwindはv4.8.743とSHA-256一致、変更はランディング専用資産のみ）。`test_account_portability.py`のJS参照をv4.8.744へ更新。
