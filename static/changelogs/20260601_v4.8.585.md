# V4.8.585 (2026-06-01)

## プロンプトバブルのGem表示

プロンプトバブル（ユーザーメッセージ）に、送信時に選択していたGem名を表示するようにしました。
Gem名は紫色の `◆` アイコン付きでフッターに表示されます。アシスタントの回答にも同様に表示されます。

### 変更点

- **データベース**: `Message` モデルに `gem_uuid` / `gem_name` カラムを追加
- **バックエンド**: メッセージ保存時にGem情報を保存し、APIレスポンスに含めるように
- **フロントエンド**: `renderMessage()` に `gemName` パラメータを追加し、フッターに表示
  - ユーザーメッセージ送信時: `activeGem.name` を渡す
  - スレッド読み込み時: APIから返却された `gem_name` を表示
- **過去のメッセージ**: DBにgem情報がない場合は表示されません（後方互換性維持）
