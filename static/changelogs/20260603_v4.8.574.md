# V4.8.574 変更履歴 (緊急バグフィックス)

**日付:** 2026-06-03

## 修正内容
- **Gemini 設定AI 400エラー完全修正**: 
  - `Invalid JSON payload received. Unknown name "additional_properties" at 'tools[0].function_d...` を解決。
  - 原因: `_build_ai_settings_tool_schema()` で Gemini の `FunctionDeclaration.parameters` に `additional_properties=False` を渡していた。
  - Google Gemini API はツールスキーマ内でこのフィールドを認識せず 400 を返す。
  - 修正: Gemini 側では `additional_properties` を完全に削除し、明示的な `gtypes.Schema(type=..., description=...)` 構築に変更（type は大文字 "STRING"/"BOOLEAN"/"OBJECT"/"INTEGER" に正規化）。
  - OpenAI互換側は `additionalProperties: false` を維持（OpenAIでは有効）。

これにより Gemini 3.1 Flash-Lite などを使用した場合でも、設定モーダルのAI機能が安定して動作するようになりました。

## 影響
- 設定AI機能（自然言語プロンプトによる安全設定変更）が全対応モデルで正常に利用可能。
- 既存の通常のチャット・設定保存・権限制御に影響なし。
