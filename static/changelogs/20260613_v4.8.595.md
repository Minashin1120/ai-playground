# アップデート履歴 V4.8.595

**リリース日:** 2026-06-13

## 変更内容

### Canvas モードを追加
- プロンプトバーに `Canvas` チェックボックスを追加。
- 有効時は回答内のコードブロックを通常のバブル表示ではなく、右側の Canvas パネルへ回し、バブル側には `Canvasで表示中` を表示。
- HTML コードブロックは Canvas 内でリアルタイムに `srcdoc` プレビューし、生成途中でも逐次更新されるようにした。
- Canvas パネルにはプレビュー本体とソース表示を用意し、`Copy` / `Clear` / `Close` 操作を追加。
