# V4.8.685 (2026-08-02)

## チャット履歴リストにPull-to-Refreshを追加

- サイドメニューのチャット履歴（`#thread-list`）を指で上から下へ引っ張ると、1ページ目から履歴を再読み込みできるようになりました。
- 履歴モーダル内に表示される時も同じジェスチャーが使えます（要素の再配置をまたいで動作します）。
- 引っ張り中は矢印アイコンと「引っ張って更新」が表示され、しきい値を超えると矢印が反転して「離して更新」に変わります。
- 離すと「更新中...」のスピナーが表示され、読み込み完了後に自動で閉じます。
- チャット履歴検索中も検索結果を引っ張って再読み込みできます。
