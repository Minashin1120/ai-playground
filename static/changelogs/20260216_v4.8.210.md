# V4.8.210 (2026-02-16)

- 自動注入システムプロンプト設定に `添付ファイル名（LLM入力時）` を追加し、添付名の同送文言をユーザー単位で ON/OFF・編集できるようにしました。
- 添付ファイルの送信名（`send_name`）は LLM モデル時のみ生成・適用し、画像生成/TTS などの非LLMモデルでは送信名をモデルへ渡さないようにしました。
- Gemini/Grok/Responses 各LLM経路の「添付名リスト同送」を新設定項目に連動させ、設定OFF時は添付名テキストを送信しないようにしました。
- 画像編集入力（Grok Imagine / GPT Image）の multipart 名称は、送信名が無効な場合に保存ファイル名へフォールバックするように調整しました。
- `chat.html` のタイトルを `V4.8.210` に更新しました。
