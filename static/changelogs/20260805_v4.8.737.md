# v4.8.737 — モバイル版の引用操作を改善

モバイル版で回答文を選択したときの引用操作を改善しました。

- これまで、テキストを選択すると選択位置に浮かぶ引用ボタンを表示していましたが、モバイルではネイティブの選択UIと重なって見えないことがありました。
- モバイル版（幅768px以下）では、選択位置の浮かぶボタンの代わりに、プロンプトバーに選択したテキストを1行で（はみ出す部分は「…」で省略）表示し、その横に「引用する」ボタンを表示するよう変更しました。
- 「引用する」ボタンを押すと、そのテキストが引用として確定され、続けてメッセージを送信できます。×ボタンで引用を解除できます。
- PC版では従来どおり、選択位置に浮かぶ引用ボタンで引用します。動作は変更ありません。
