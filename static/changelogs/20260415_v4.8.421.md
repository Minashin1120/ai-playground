# Update Log (2026-04-15) - V4.8.421

## WebAuthn / Passkey Support Improvements
- WebAuthn登録時のオプションを更新し、`resident_key=ResidentKeyRequirement.PREFERRED` を追加しました。これにより、Google アカウントなどの同期されたパスキー（Passkeys）をより確実に登録・利用できるようになります。
- オンデバイスの認証器だけでなく、クロスプラットフォームの認証器や同期された認証器の利用をブラウザに促すように改善しました。

## System Updates
- `app.py` の `APP_VERSION` を `2026-04-15-001` に更新。
- フロントエンドのリソースを `V4.8.421` に更新。
