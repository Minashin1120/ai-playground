# V4.8.280 (2026-02-26)

## LLM文字起こしプロンプト既定文言の言語指定を削除

LLM文字起こしプロンプト（LLM方式）の既定文言に含まれていた `日本語で` の指定を削除し、言語を固定しない表現に変更しました。

### 変更内容
* **既定文言を修正**: `DEFAULT_LLM_TRANSCRIBE_PROMPT` を `この音声を正確に文字起こししてください。` に変更（言語指定なし）。
* **影響範囲**: 設定画面の既定プレースホルダ、および `llm_transcribe_prompt` 未設定時の `/transcribe` LLM方式に適用。
* **表示バージョン更新**: `chat.html` の表示バージョンと `chat_app.js` キャッシュバスターを `V4.8.280` に更新。
