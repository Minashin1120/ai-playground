## V4.8.170 (2026-02-08)
* **マルチターン会話における画像コンテキストの維持（OpenAI/Grok）**
    * **内容**: OpenAI Responses API および OpenAI Search API を使用するモデルにおいて、2回目以降のプロンプト送信時に過去のターンで送信された画像がコンテキスト（履歴）から脱落していた問題を修正。
    * **内容**: 履歴再構築ループ内でユーザーが過去に送信した画像を検出し、モデルへ再投入するロジックを追加。
    * **内容**: これにより、1回目のプロンプトで送った画像について、2回目のプロンプトで質問を継続することが可能になりました（Gemini/xAI SDK 支柱と同様の挙動へ統一）。
