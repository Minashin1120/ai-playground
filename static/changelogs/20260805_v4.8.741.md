# v4.8.741 — 画像を添付して送信した際に稀に520エラーが表示される問題を修正

- 画像を添付してプロンプトを送信すると、最初の応答トークンが届く前に Cloudflare の 520 エラーが表示されることがありました。
- 原因は、サーバー側の一時的な接続断（Apache と gunicorn の間で接続がリセットされた場合に Cloudflare が 520 を返す）に対して、自動再試行の対象が 502/504/521〜524 のみで、520 が含まれていなかったことです。
- 520 を接続状態の判定・自動再試行の対象に追加し、一時的な接続断が発生しても自動で再試行して回答を継続できるよう修正しました。
