# V4.8.707 (2026-08-03)

## 送信ボタン連打時にボットチェックダイアログを表示（サーバー負荷対策）

送信ボタンの連打（短時間に5回以上）でサーバーに大量の `chat_stream` リクエストが飛ぶのを防ぐため、**連打時はボットチェックダイアログ（Turnstile）を表示**して、検証が完了するまで送信を続行しないようにしました。

### 実装内容（`chat_core.v4.8.707.js`）

- `sendButtonSpamTimestamps` を導入し、`sendMessage()` が呼ばれるたびに `registerSendButtonSpam()` で2秒窓内の連打回数を記録。
- **2秒以内に5回以上**送信しようとした場合、`runSendSpamVerification()` を実行:
  - `showBotDetectionOverlay()` で可視のボットチェックダイアログ（Turnstileボックス）を表示
  - `getTurnstileToken(25000)` でダイアログ内のウィジェット解決を待つ
  - `verifyTurnstileOnServer(token, true, true)` で `challenged:true` として検証
  - 検証成功ならダイアログを閉じて送信を続行、失敗なら「送信操作が速すぎるため、確認後に再度お試しください。」のトーストを出して送信をブロック
- 連打カウンタは `resetSendButtonSpam()` でリセット（検証後もリセット）。
- 既存のボット検出（サイレント先行検証・ダイアログなしBAN防止・Turnstileボックス表示）はそのまま維持。

### 補足

- DB変更はありません。
