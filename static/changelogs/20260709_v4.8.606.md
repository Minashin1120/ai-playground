# V4.8.606 — 解答バブルのスケルトンローディング（シマー）

## 概要
ストリーミング生成が始まるまでの待ち時間に、解答バブル内でスケルトンローディング（シマー）を表示するようにしました。生成されるコンテンツの種類（モデル種別）に応じて見た目を変えています。

## 変更内容
- **テキストモデル**: 文章行を模したスケルトンライン
- **コードモデル**（Grok Build 等）: コードブロック風ヘッダー＋行スケルトン
- **画像モデル**（Nano Banana / GPT Image / Grok Imagine Image 等）: 正方形メディア枠＋アイコン
- **動画モデル**（Grok Imagine Video）: 16:9 枠＋再生アイコン＋プログレスバー
- **音声/TTS モデル**: ディスク＋波形バーアニメーション
- API 接続完了・status イベント時もスケルトンを維持し、下部のステータステキストのみ更新
- 初回コンテンツ／推論トークン到着時にスムーズに通常表示へ遷移
- `prefers-reduced-motion` 対応

## 技術詳細
- `chat_core.v4.8.606.js`: `getPendingSkeletonKind` / `buildPendingSkeletonHtml` / `updatePendingSkeletonStatus`
- `chat.custom.v4.8.606.css`: モデル別スケルトンスタイルとシマー／波形アニメーション
- 送信時・resume・スレッド再描画の pending バブルすべてに適用
