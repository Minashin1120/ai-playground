# V4.8.609 (2026-07-10)

## プロンプトキャッシング（PromptCache）

- プロンプトバーに **PromptCache** トグルを追加。有効化すると各プロバイダ向けのプロンプトキャッシュを利用します。
  - **Claude**: `cache_control`（ephemeral）による自動/システムプロンプトキャッシュ
  - **OpenAI / xAI (Responses API)**: `prompt_cache_key`（スレッド単位）
  - **xAI (Native SDK)**: `conversation_id` による会話ルーティング
  - **DeepSeek**: 互換 `prompt_cache_key`
  - **Gemini**: 対応モデルでは暗黙キャッシュを活用（UI制限は共通）
- **他APIモデルへの切替制限**: PromptCache 有効中は、同一 API プロバイダ（OpenAI / Gemini / Anthropic / xAI / DeepSeek 等）内のモデルのみ選択可能。モデル選択モーダルにもロック表示を追加。
- サーバー側でもスレッドの `prompt_cache_provider` を検証し、他APIへの変更リクエストを拒否。
- スレッドに `enable_prompt_caching` / `prompt_cache_provider` を保存し、履歴再オープン時に復元。
- 新規チャット開始時は PromptCache をオフにリセット。
