# v4.8.745 — ランディングページの余白とアニメーションを修正

- ランディングページでセクションの上下余白・グリッド間隔・レスポンシブ文字サイズなどが意図どおり適用されない問題を修正しました。
- 原因: 共有の `chat.tailwind.*.css` は主にチャット／認証画面から生成されるため、ランディング専用のユーティリティ（`py-16` / `py-20` / `md:py-24` / `gap-10` / `mt-10` / `mb-14` / `w-max` / `order-*` / `md:text-6xl` など）が含まれておらず、余白がブラウザ既定のままになっていました。あわせてマーキー用の `w-max` が無く、横スクロールアニメーションが実質動かない状態でした。
- 修正: 不足していたユーティリティを `static/css/landing.css` にポリフィルとして追加し、セクション余白・ヒーロー間隔・特徴カードのアイコン余白（横並び時の不要な下マージンを除去）を整えました。
- スクロールに応じて要素がフェードインする入場アニメーション（`.ld-reveal` + IntersectionObserver）を追加しました。ヒーロー・特徴カード・使い方・統計・FAQ・最終CTAに適用し、`prefers-reduced-motion` 時は即座に表示します。
- チャット操作デモとマルチモデルハブの自動再生アニメーションはそのまま維持しています。
- DBスキーマ変更なし。`APP_VERSION=2026-08-06-004` / `SYSTEM_VERSION=V4.8.745`。
