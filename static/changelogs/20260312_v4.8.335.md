# 更新履歴 (2026-03-12) - V4.8.335

## 🛠 画像・圧縮詳細設定の統合とWebP変換対応
画像圧縮と生成に関連するすべてのオプションをひとつのモーダルに集約し、より詳細な制御が可能になりました。

### 🚀 主な変更内容
- **詳細設定モーダルの統合**: 
    - 従来のクライアント側圧縮設定に加え、GPT-Image (DALL-E), Gemini (Nano Banana), Grok (Imagine) の各モデル固有の生成設定（サイズ、アスペクト比、クオリティ等）をすべて「画像・圧縮詳細設定」モーダルに集約しました。
    - プロンプトバーに表示されていた各モデルのオプションも、モーダルと双方向に同期されます。
- **WebP 変換対応**: 
    - クライアント側圧縮のオプションに「出力形式 (変換)」を追加しました。
    - `WebP に変換 (推奨)` を選択することで、添付画像をブラウザ側で WebP 形式に変換してから送信し、転送量の削減と高画質の両立が可能になります。
- **UI/UX の改善**: 
    - 選択中のモデルに応じて、モーダル内の関連設定セクションのみが表示されるように動的制御を導入しました。

### 📦 バージョン更新
