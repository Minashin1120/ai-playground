# V4.8.286 (2026-02-26)

## Nano Banana 2 追加とモデル別プロンプトバー項目上書き

Gemini 3.1 Flash Image を `Nano Banana 2` として追加し、モデルごとにプロンプトバー上の項目表示（Search / Python / SysPrompt / Thinking / Effort）をこのブラウザ単位で上書きできるようにしました。

### 変更内容
* **Nano Banana 2 を追加**: `templates/chat_app.js` のモデル一覧へ `gemini-3.1-flash-image-preview` を追加。
* **Gemini画像モデル分岐を修正**: `app.py` で `gemini-3.1-flash-image-preview` を正しく選択するよう変更（従来の `Nano Banana Pro` への誤振り分けを回避）。
* **Gemini 3.1 Flash Image のオプション反映**: `Search` / `Thinking` が有効な場合、Gemini画像生成リクエストの `GenerateContentConfig` に反映。
* **Gemini画像のテキスト応答対応**: Gemini画像応答に含まれる `text` パートもチャット画面へ表示。
* **モデル別項目上書きUI**: プロンプトバーに `項目` ボタンを追加し、モデルごとに `Search` / `Python` / `SysPrompt` / `Thinking` / `Effort` の表示を `既定 / 表示 / 非表示` で上書き可能（localStorage保存）。
* **Nano Banana 2 の既定プリセット**: `SysPrompt` / `Thinking` を表示上書きするプリセットを追加。
* **Gemini画像サイズUI調整**: Flash Image 系（2.5 / 3.1）は `1K` 固定としてサイズUIを制御。
* **表示バージョン更新**: `chat.html` の表示バージョンと `chat_app.js` キャッシュバスターを `V4.8.286` に更新。
