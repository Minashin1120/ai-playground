# V4.8.689 (2026-08-03)

## コンパクトモードの「詳細」ボタン展開アニメーションを滑らかに

- 従来は `max-height: 500px` へ 0→500px の遷移を当てていたため、実際のコンテンツ高（30px前後）と大きく乖離し、展開時に一瞬で広がる／折りたたみ時に最後まで待ってから急に閉じる「カクカクした」動作になっていました。
- CSS Grid の `grid-template-rows: 0fr → 1fr` 遷移方式（コンテンツの実高さに追従するアニメーション）へ変更し、展開・折りたたみともに滑らかなスライド動作にしました。
- アニメーション対象を包むインナーラッパー（`.prompt-details-inner`）を `chat.html` に追加し、実高さに追従するようにしています。
- `prefers-reduced-motion`（OSのアニメーション削減設定）が有効な環境では遷移を無効化し、即時表示に切り替えます。
