# Update v4.8.409 (2026-04-12)

## 修正内容
* **Gemini 3.1 Flash Live STS のパフォーマンスと音質改善**
  * **リアルタイム・オーディオ・ストリーミングの実装**: これまでの「回答生成完了後に一括再生」する方式から、生成された音声チャンクを即座にクライアントへ送り、逐次再生する方式（ストリーミング）へ変更しました。これにより、応答開始までの待ち時間が劇的に短縮されました。
  * **音声の途切れ・重複の修正**: Gemini 3.1 Live から送られてくる音声データの収集ロジックを最適化し、データの重複によるノイズや途切れを解消しました。
  * **フロントエンド・オーディオ・プレイヤーの刷新**: Web Audio API を活用した `RealTimeAudioPlayer` を導入し、ネットワーク経由で届く音声チャンクを隙間なくスムーズに再生できるようにしました。
* **バージョン更新**
  * システムバージョンを `2026-04-12-010` に更新しました。
  * `chat_core.js` を `v4.8.409` に更新しました。
