# V4.8.504 (2026-05-09)

### 新機能
- **Grok 4.3 の実装**: xAI の最新フラグシップモデル「Grok 4.3」を追加しました。100万トークンのコンテキストウィンドウをサポートし、推論（Reasoning）の深さを調整可能です。
- **Grok 推論オプションの拡張**: Grok 4.3 において、推論の強さを「なし (none)」「低 (low)」「中 (medium)」「高 (high)」から選択できるようになりました。
- **マルチエージェント設定の最適化**: Grok 4.20 Multi-Agent において、エージェント数を制御する推論設定を改善しました。

### 変更・修正
- **モデルの廃止 (Deprecation)**: 2026年5月15日のモデル引退に備え、以下のモデルを非推奨に設定し、新規選択 UI から除外しました。
    - `grok-4-1-fast` シリーズ
    - `grok-4-fast` シリーズ
    - `grok-imagine-image-pro` (非推奨設定の維持)
- **UI の改善**: ウェルカム画面に Grok 4.3 のクイックスタートボタンを追加しました。
- **不具合修正**: 特定のモデルにおける推論設定の表示ロジックを修正しました。
