# V4.8.272 (2026-02-26)

## 一時チャットのヘッダー秒数表示を設定値の固定表示に変更

前回追加した一時チャットのヘッダー表示について、カウントダウンではなく、設定値の秒数（例: `30秒`）を固定表示するよう修正しました。

### 変更内容
* **表示仕様変更**: 一時チャット時のヘッダー秒数バッジを、残り時間カウントダウンから設定秒数の固定表示へ変更。
* **表示条件維持**: 秒数バッジは一時チャットが有効な場合のみ表示。
* **負荷軽減**: ヘッダー秒数表示の1秒更新タイマー起動を停止（固定表示のため不要）。
* **表示バージョン更新**: `chat.html` の表示バージョンと `chat_app.js` キャッシュバスターを `V4.8.272` に更新。
