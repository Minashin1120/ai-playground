# 更新履歴 (2026-05-02)

## システムバージョン: V4.8.476

### 修正・改善
* **Markdown レンダリングの根本的改善（モデル出力の忠実な再現）**
  * リスト形式（番号付きリストや箇条書き）を Markdown の構造として解釈せず、プレーンテキストとして扱うように変更しました。
  * これにより、モデルが回答した「1.」「2.」などの数字や、「*」「-」などの記号が、ブラウザによって書き換えられることなく、モデルの出力通りの内容と順番で表示されるようになります。
  * リスト内の太字、斜体、リンクなどの装飾機能は引き続き利用可能です。
  * `white-space: pre-wrap` と組み合わせることで、モデルが意図した改行やインデントを正確に反映します。
