# V4.8.185 (2026-02-13)

- 管理者向けに API キー参照モードを追加しました。
- 設定モーダルで、管理者も通常ユーザーと同じ API キー入力欄（OpenAI/Gemini/xAI/Google TTS）を利用できるようにしました。
- `管理者APIキー参照モード` で `.env フォールバック`（既定）と `ユーザー設定のみ` を切り替え可能にしました。
- Gemini / OpenAI / xAI / Google TTS で使用している管理者の `.env` フォールバック判定を共通化し、選択モードどおりに動作するよう修正しました。
- `user.admin_api_key_mode` カラムを追加し、既存環境でも自動マイグレーションされるようにしました。
