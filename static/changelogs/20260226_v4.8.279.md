# V4.8.279 (2026-02-26)

## 設定に「LLM文字起こしプロンプト（LLM方式）」を追加

`/transcribe` の LLM方式文字起こしで使用する内部プロンプトについて、ユーザーごとに設定画面から編集できるよう別枠の設定を追加しました。

### 変更内容
* **ユーザー設定を追加**: `user.llm_transcribe_prompt` を追加し、`/api/settings` GET/POST で保存・復元できるよう拡張。
* **設定UIを追加**: 設定 > 音声設定に `LLM文字起こしプロンプト（LLM方式）` テキストエリアを動的追加（空欄保存で既定文面に戻る）。
* **LLM文字起こしへ反映**: `/transcribe` の LLM方式で、ユーザー設定プロンプト（未設定時は既定）を使用するよう変更。
* **安全ガード維持**: 無音時の推測禁止/専用トークン返却指示は、ユーザー設定とは別に自動付与を継続。
* **DB自己修復対応**: 起動時の `ensure_user_stt_settings_columns()` と `RUN_SCHEMA_MIGRATIONS` に `llm_transcribe_prompt` 列追加を反映。
* **表示バージョン更新**: `chat.html` の表示バージョンと `chat_app.js` キャッシュバスターを `V4.8.279` に更新。
