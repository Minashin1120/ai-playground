# 更新履歴 - V4.8.1027 (2026-09-24)

音声系モデル（WebSocket）の操作画面を見直しました。
- 音声スタジオを別画面に分けず、チャット画面の入力欄の位置に「音声ドック」として表示するようにしました。チャットを見ながら、マイクボタンで話し始め・停止できます。停止するとチャットに保存されます。
- 音声ドックに会話の文字起こしが表示されるようにしました。
- Voice・Thinking・Auto Sendなどの音声設定を「設定」ボタンで開閉できるようにしました。開閉状態はブラウザに保存されます。設定欄の文字と入力欄も大きくしました。
- 音声スタジオは拡大表示として残し、ドックの拡大ボタンから開けます。拡大表示を閉じても会話は中断されず、ドックから操作を続けられます。背景クリックで閉じた場合も、ドックが正しく元の位置に戻るよう修正しました。
- Android版も同様に、Realtime音声モデルの選択中は入力欄の位置に音声ドックを表示するようにしました。Voice・Thinking・翻訳先などは選択肢から選べます。
