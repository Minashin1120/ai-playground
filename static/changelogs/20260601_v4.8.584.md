# V4.8.584 変更履歴 (@コマンドでGem選択時のモデル保存修正)

**日付:** 2026-06-01

## 修正
- **`@` コマンドでGemを選択した際、モデル選択がチャットセッションに保存されない問題を修正**
  - Gemに `default_model` が設定されている場合、`applyActiveGem()` で自動的に `selectModelById()` を呼び出すように修正。
  - サイドバーからのモデル選択と同様に、`model-select` hidden input が更新され、メッセージ送信時に正しいモデルがスレッドに保存されるようになった。
