# V4.8.284 (2026-02-26)

## 停止処理の残留リスク対策（超早押し停止 / 停止後同期失敗通知）

`V4.8.282`〜`V4.8.283` の停止後同期改善に対して、再生成・プロンプト編集に影響し得る残留リスクを追加で対策しました。

### 変更内容
* **`/api/stop_chat` に `thread_id` フォールバック追加**: `job_id` 未取得時でも、同一スレッドの `pending_job` から `job_id` を解決して停止できるように変更。
* **停止API応答で `job_id` を返却**: フロント側がサーバー解決した `job_id` を pending抑制に使えるよう、`job_id` / `source` を返すよう拡張。
* **停止後同期の再試行を追加**: `syncThreadAfterAbortedStream()` に短時間の再試行（既定2回）を追加し、一時的な競合で同期失敗しにくく改善。
* **停止後同期失敗の通知を追加**: 再試行後も同期失敗した場合は警告トーストを表示し、UI状態が古いまま残るリスクをユーザーに明示。
* **表示バージョン更新**: `chat.html` の表示バージョンと `chat_app.js` キャッシュバスターを `V4.8.284` に更新。
