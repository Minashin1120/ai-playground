# Changelog (2026-05-06)

## [V4.8.495] - 2026-05-06

### Fixed
- 番号付きリストを含むメッセージが表示されない、またはフロントエンドでエラーが発生する不具合を修正しました。
  - `marked.js` の拡張機能 `numberedListInterceptor` において、`this.rules` が `undefined` になることで発生していた `TypeError` を解消するため、該当の拡張機能を削除しました。これにより、標準の番号付きリストのパース処理に戻り、正常に表示されるようになります。
- システムバージョン（`SYSTEM_VERSION`）を `V4.8.495`、`APP_VERSION` を `2026-05-06-001` に更新しました。
