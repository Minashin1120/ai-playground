# v4.8.749 — 回答のストリーミング生成中にページを再読み込みすると読み込みエラーになる問題を修正

- 回答のストリーミング生成中にページを再読み込みすると「チャットを読み込めませんでした」と表示され、生成中の回答を再開できない問題を修正しました。
- 原因は、スレッド読み込み時の描画処理（`renderThreadTree`）が、生成中の回答用のプレースホルダーを `DocumentFragment` へ追加する際に、Fragment に存在しない `insertAdjacentHTML` を呼び出していたことでした。その例外によって読み込み処理全体が中断し、読み込みエラーが表示されていました。
- 修正後は、プレースホルダーの追加先が `DocumentFragment` の場合も正しく要素として追加されるため、再読み込みすると生成中のストリーミングが自動的に再開され、完了後の回答が表示されます。
- 生成中（`pending_job` が存在する間）にのみ発生するため、生成完了後の再読み込みでは発生しませんでした。
- DBスキーマ変更なし。`APP_VERSION=2026-08-06-008` / `SYSTEM_VERSION=V4.8.749`。
