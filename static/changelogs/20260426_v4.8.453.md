# 更新履歴 (V4.8.453) - 2026-04-26

## サーバー側リッチ貼り付けPDF生成の安定性強化

### 修正内容
* **長大テーブルの分割処理 (CHUNK対応)**:
    * 非常に長いテーブルが含まれる場合にPDFビルドがタイムアウトしたりレイアウトが崩れたりする問題を解決するため、テーブルを一定行数（50行）ごとに分割して描画するロジックを導入しました。
* **リスト構造のパース強化**:
    * 入れ子になったリスト（Nested Lists）や、空のリスト項目が含まれる場合のレンダリングを最適化しました。
    * 段落間の余白やインデントの計算を改善し、より読みやすいレイアウトを実現しました。
* **サーバーリソースとタイムアウトの最適化**:
    * 大容量のPDF生成時に処理が中断されないよう、Gunicornのタイムアウト設定を300秒から600秒へ緩和しました。
    * 並列処理能力を向上させるため、ワーカー数とスレッド数を増強しました。
* **画像処理の堅牢化**:
    * `ReportLab` での画像リサイズ処理において、アスペクト比を維持しつつページ幅に収まるよう計算を精緻化しました。

### バージョン情報
* `app.py` の `APP_VERSION` を `2026-04-26-004` に更新。
* `chat.html` の表示バージョンを `V4.8.453` に更新。
