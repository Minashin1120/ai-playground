# v4.8.740 — Gemini Agentic View 実行時の504タイムアウトエラーを修正

- Gemini の Agentic View で Python コード実行（サーバー側コード実行ツール）を使うと、Google API から `504 DEADLINE_EXCEEDED`（制限時間超過）エラーが返ってくることがありました。
- 原因は、リクエストのタイムアウト（既定120秒）がそのまま `X-Server-Timeout` ヘッダーとして送信され、Python 実行を含む長時間の処理が完了する前にサーバー側が中断していたことです。
- Agentic View（コード実行ツール）のリクエストに専用の長いタイムアウト（既定10分）を設定し、Python 実行が完了するまで待機できるよう修正しました。
- 万一このエラーが発生した場合は、発生状況が分かる日本語の案内メッセージを表示するよう改善しました。
- タイムアウト値は環境変数 `GEMINI_AGENTIC_TIMEOUT_MS` で変更できます。
