# Changelog (2026-05-07)

## System Version V4.8.501

### Removed
- 診断システム (Diagnostic System) を削除しました。不具合が解消されたため、本番環境からデバッグ用のオーバーレイとスクリプトを撤去しました。

### Changed
- `chat_core.js` を `v4.8.501` に更新し、デバッグログ出力を停止しました。
- バージョン表示のクリック動作を元の `showAlphaInfo()` に戻しました。

---

## System Version V4.8.500

### Added
- Gemini API (google-genai) において、メディアファイル（画像、PDF、音声、動画）のアップロード時に `display_name` を設定するように変更しました。
- 画像ファイルについて、従来はテキストブロックでファイル名を補足していましたが、Gemini Files API を使用してアップロードし、API の `display_name` 機能を活用するように改善しました。

### Fixed
- システムバージョンの更新に伴う `chat_core.js` の読み込みエラー（404）を修正。
- `showModal` および `hideModal` 関数をグローバルスコープに公開し、サイドバーやメニューボタンの反応がなくなる問題を修正。
