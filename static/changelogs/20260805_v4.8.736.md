# v4.8.736 — 回答の引用ボタンが表示されない問題を再修正

回答文を選択したときに表示される引用（Quote）ボタンが、引き続き表示されない問題を修正しました。

- 引用ボタン `#quote-popover` は `position: fixed` で、選択位置のビューポート座標（`getBoundingClientRect`）を `top` / `left` に設定して表示しています。`position: fixed` は、祖先要素に `transform`（アニメーション含む）・`backdrop-filter` 等があると、ビューポートではなくその祖先を基準に座標が解釈される仕様です。
- 引用ボタンの入れ物 `#quote-popover-container` は、これまで `.fade-in` クラスによる `messagePop` アニメーション（`transform` を含む・`both` 指定のため適用後も変形が残る）と、ボタン表示時の `:has()` アニメーションルールが適用されており、この `transform` によりボタンの座標が入れ物（画面上端の外側にあるサイズ0のボックス）基準に解釈され、画面外へ押し出されて見えなくなっていました。
- 修正として、入れ物 `#quote-popover-container` から `fade-in` クラスを外し、`:has()` によるアニメーションルールを削除しました。入れ物には `transform` を一切適用しません。ボタン自体の表示アニメーション（`popoverIn`）はそのまま維持されます。
- ロジック（`handleQuotePopover`、`currentQuote`、`quote_text` 送信・保存・履歴表示）は変更なしです。
