# 更新履歴 - V4.8.1045 (2026-10-02)

- OpenAI公式ドキュメントに基づき、`gpt-6-astra`（GPT-6 Astra）、`gpt-6.1-sol`（GPT-6.1 Sol）、`gpt-6-luna`（GPT-6 Luna）、`gpt-6-sol`（GPT-6 Sol）を実装しました。
- モデル選択、ウェルカム画面のクイックスタート、初期設定の既定モデル、Android版のモデル情報へ追加しました。
- Responses APIの既存経路で、テキスト・画像入力、ストリーミング、Web検索、Pythonツール、プロンプトキャッシュ、バッチを利用できます。
- 公式の推論設定に合わせ、GPT-6 Astra と GPT-6.1 Sol では `low` / `medium` / `high` / `xhigh` / `max`、GPT-6 Luna と GPT-6 Sol ではこれに `none` を加えた設定を選べます。`none` を受け付けないモデルでは API 既定の `medium` で送信します。
- 公式の標準料金（入力、キャッシュ入力、出力）と、272K入力トークン超過時の長文脈料金をモデル一覧へ反映しました。
