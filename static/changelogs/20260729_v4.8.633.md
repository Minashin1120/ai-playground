# V4.8.633

## GPT Transcribe / GPT Live Transcribe

- OpenAI公式の `gpt-transcribe` を録音済みファイル向けSTTモデルとして追加しました。
- `gpt-transcribe` は設定画面の「STTモデル」から選択でき、`/v1/audio/transcriptions` を使用します。
- モデル一覧に「OpenAI Transcription」カテゴリを追加し、`gpt-transcribe` と `gpt-live-transcribe` を選択できるようにしました。
- 両モデルのRealtime文字起こしでは、24kHz PCM音声を `type: transcription` のRealtimeセッションへ送り、delta／completedイベントから文字起こしを取得します。
- 文字起こし専用モデルでは音声応答、Voice、Speed、Auto Playを要求せず、テキスト結果と元音声をチャット履歴へ保存します。
- 公式価格（`gpt-transcribe`: $0.0045/分、`gpt-live-transcribe`: $0.017/分）をモデル選択画面へ反映しました。

## 安定性

- OpenAI／xAIの既存Speech-to-Speech経路で、音声をPCMへ変換する処理が不足していた問題を修正しました。
- Python／JavaScript構文検査と全35件の回帰テストに成功しました。
