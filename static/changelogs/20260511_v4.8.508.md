# 更新履歴 (V4.8.508) - 2026-05-11

## 新機能と改善

- **OpenAI Realtime 2 系モデルの導入**
    - OpenAIの最新音声・リアルタイムモデルに対応しました。
    - **導入モデル**:
        - `gpt-realtime-2`: 高度な推論能力を備えた最新の音声フラグシップモデル。
        - `gpt-realtime-translate`: リアルタイム音声翻訳に特化したモデル。
        - `gpt-realtime-whisper`: 低遅延な文字起こしに特化したモデル。
- **バックエンドの最適化**
    - 各Realtimeモデル専用のエンドポイント（`/v1/realtime/translations` 等）への自動ルーティングを実装。
- **UIの更新**
    - ウェルカム画面への `gpt-realtime-2` クイックスタートボタンの追加。
    - 初期セットアップおよび設定画面での新モデル選択への対応。
