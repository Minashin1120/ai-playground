# 更新履歴 (V4.8.483)

## Markdown レンダリングの修正と改善 (2026-05-04)

* **Markdown 要素の描写を大幅に改善**
    * **テーブル (Table)**: 枠線、パディング、ヘッダー背景色などのスタイルを追加し、表形式のデータが読みやすくなるように修正しました。
    * **引用 (Blockquote)**: 引用ブロックの左側にアクセント線を追加し、スタイルを整えました。
    * **水平線 (HR)**: セクション区切りとしての水平線の描写を改善しました。
    * **箇条書きリスト (Bulleted List)**: 箇条書きが正常にリストとして認識され、中身の Markdown（太字など）も正しく描写されるように戻しました。
* **リスト描写の最適化**
    * 番号付きリストについては、指示通り「忠実な番号再現」を維持するため、現在の描写方式を継続しています。
    * 箇条書きリストについては、標準の Markdown 描写を有効化し、適切なインデントと箇条書き記号が表示されるようにしました。
* **スタイルの整合性向上**
    * `pre-wrap` 指定による改行保持と、Markdown 描写による構造化のバランスを調整しました。
