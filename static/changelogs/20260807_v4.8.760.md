# V4.8.760 - 設定モーダルのタブ分類

## 変更内容

- 設定モーダルの項目を用途別にタブ分割し、探しやすくしました。
  - **一般**: 送信・プロンプトバー・確認ダイアログ・チャット既定値・検索・音声・一時チャット
  - **APIキー**: 各プロバイダーAPIキー、Gemini接続方式、モデル別APIキー
  - **プロンプト**: システムプロンプト（自動注入を含む）
  - **表示**: テーマ、Liquid Glass、背景ぼかし
  - **データ**: キャッシュ、ストレージ、アカウントデータのエクスポート/インポート、デバッグ
  - **アカウント**: ユーザー名/パスワード、簡易ログイン、Google連携
  - **セキュリティ**: E2EE、セッション、Bot Detection（管理者）、アカウント削除 など
  - **2要素認証** / **フィードバック**: 従来どおり
- 設定検索は全タブを横断して検索し、該当タブへジャンプします。
- 表示まわりのトースト（背景ぼかし設定）は「表示」タブを開くようにしました。

## 補足

- DBスキーマ変更はありません。
- 既存の設定値・保存APIは変更していません（UIの分類のみ）。
