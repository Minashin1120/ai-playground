# V4.8.728 — アカウントデータ移行の一時ファイル保護強化

- アカウントインポート用のアップロード一時領域を、アクセス権限を可能な限り制限した構成（ディレクトリ `0700`・ファイル `0600`）に変更しました。
- インポートが完了した時点でアップロード一時ファイルを即時削除するようにしました（途中キャンセル・失敗・検証エラーの場合も同様）。
- 未完了のまま放置されたインポートアップロードは、定期的に自動掃除され、1時間経過したものは確実に削除されます。
- アカウントエクスポート用ZIPも保存時に `0600` を明示適用し、保存ディレクトリと合わせてアクセス権限を最小化しました。
- インポートのチャンク結合中に失敗した場合に残る一時ファイルを即時削除するよう修正しました。
