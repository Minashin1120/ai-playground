# V4.8.265 (2026-02-26)

## 回線速度テストボタンが反応しない問題を修正（テンプレートJSキャッシュ対策）

設定画面の「回線速度テスト実行」ボタンが押しても反応しないケースがあり、原因は `/assets/chat-app.js` の強いキャッシュにより古いJSが残ることでした。キャッシュ方針を見直し、URLも更新して解消しました。

### 変更内容
* **テンプレートJSのキャッシュ緩和**: `app.py` の `/assets/chat-app.js` レスポンスを `private, no-cache, max-age=0, must-revalidate` に変更。
* **URLキャッシュバスター追加**: `templates/chat.html` の `chat_app_js` 読み込みURLに `-v4.8.265` を付与し、既存キャッシュを確実にバイパス。
* **表示バージョン更新**: `chat.html` の表示を `V4.8.265` に更新。
