# V4.8.260 (2026-02-26)

## 回答バブル角丸のUI回帰修正

軽量化対応（Tailwind CDN 廃止 -> 事前ビルドCSS）後に、回答バブルが角ばって見える回帰を修正しました。

### 原因
* `templates/chat_app.js` 内で動的生成している `rounded-2xl` / `rounded-tl-none` が、事前ビルドした Tailwind CSS に含まれていませんでした（動的クラスのため抽出漏れ）。

### 変更内容
* **フォールバックCSS追加**: `static/css/chat.custom.v4.8.260.css` に `rounded-2xl` / `rounded-tl-none` の最小フォールバックを追加し、回答バブルの角丸表示を復旧。
* **キャッシュ回避**: `templates/chat.html` のカスタムCSS参照を `chat.custom.v4.8.260.css` に更新（長期キャッシュ済み環境でも新CSSを取得）。
* **表示バージョン更新**: `chat.html` の表示を `V4.8.260` に更新。
