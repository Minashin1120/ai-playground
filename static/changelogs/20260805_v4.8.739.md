# v4.8.739 — 切断表示のアイコンを修正

- 「インターネット接続が切断されています」のエラーバーで、左側に表示されるはずのアイコンが表示されていませんでした。
- 原因は、この状態で使用していたアイコン `fa-wifi-slash` が、本サイトが読み込んでいる Font Awesome 6.0.0 に存在しないため、アイコン要素が空のまま表示されていたことです。
- 切断状態のアイコンを、Font Awesome 6.0.0 に存在する `fa-unlink`（チェーンが切れたアイコン）へ変更しました。メンテナンス中・サーバーダウン・復帰・通信不安定のアイコンは変更ありません。
