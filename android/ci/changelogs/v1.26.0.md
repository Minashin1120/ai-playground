# AI Playground Android v1.26.0

- マイク入力をWeb版と同じ録音方式にしました。録音中は波形を表示し、止めると設定した方式（STT API または選択中のモデル）で文字起こしして入力欄に追加します。
- スラッシュコマンドをWeb版と同じ内容と説明にしました。ミニマル表示では設定系のコマンドも使え、「/thinking high」「/search on」のように値を指定できます。
- 「/settings」で、自然な文章で設定を確認・変更できるようにしました。変更した項目をタップすると設定画面が開きます。
- モデルのAPIキーが未設定のとき、その場でキーを保存して送信し直すか、他のモデルに切り替えられるようにしました。
- X（旧Twitter）のリンクを送るとき、Web版と同じく検索をオンにしてGrok 4 Fast Reasoningに切り替えます（設定でオフにしている場合は確認を表示します）。
- 選択中のモデルが対応していない音声・動画を添付して送ろうとしたときや、Mistral OCR に文書がないときに、Web版と同じ注意を表示するようにしました。
