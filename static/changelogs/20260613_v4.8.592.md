# アップデート履歴 V4.8.592

**リリース日:** 2026-06-13

## 変更内容

### DeepSeek V4 ストリーミング + リロード復帰の修正
- **推論プロセスが常に非表示だった問題を修正**: `reasoning_content` のストリーミング中、thought-content に `collapsed` クラスが付与されていたため推論テキストが不可視だった。ストリーミング中は展開状態で表示するよう変更。
- **途中リロード時にストリーミングが復帰しない問題を修正**: 長時間の推論生成中に `pending_job` の TTL が切れると `chat_stream_resume` が 404 を返していた。定期的に TTL を更新する仕組みを追加（バックエンドワーカー・SSEジェネレータ・resumeジェネレータの3箇所）。
- **`stream_options` を削除**: DeepSeek API との互換性を高めるため `include_usage` パラメータを送らないよう変更。
- **`reasoning_content` 抽出を強化**: `delta.__pydantic_extra__` からのフォールバック取得を追加。
