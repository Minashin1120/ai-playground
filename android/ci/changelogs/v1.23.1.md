# AI Playground Android v1.23.1

- サイドバーの「Batch処理」をWeb版と同じ画面にしました。すべて・実行中・終了で絞り込み、ジョブごとに状態、提供元、モデル、作成日時を確認できます。ジョブを開く、停止する、履歴から削除する操作もここで行えます。画面を開いている間は5秒ごとに自動で更新します。
