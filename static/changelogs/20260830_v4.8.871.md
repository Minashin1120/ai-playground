# 更新履歴 - V4.8.871 (2026-08-30)

設定の保存とログイン時の通知まわりを改善しました。
- 設定を保存した後、ページを再読み込みしたときに以前の保存の「設定を保存しました」通知が表示されることがある問題を修正しました。設定の保存結果はAJAXの応答（JSON）で返すようになり、保存直後にトーストで表示されます。あわせて、E2EE設定を変更した場合は保存直後にその旨の通知を表示するようにしました。
- ログインが必要なページへ未ログインでアクセスした際に発行される通知が、ログイン後のホーム画面に「ログインが必要」という内容のトーストとして表示されることがある問題を修正しました。この通知はログイン画面では表示されないため発行をやめ、既に溜まっていた古い通知も削除するようにしました。
