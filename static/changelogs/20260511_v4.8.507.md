# 更新履歴 (2026-05-11)

## Anthropic Claude 4.6 シリーズの実装 (V4.8.507)

* **内容**: Anthropic の最新モデル「Claude Opus 4.6」および「Claude Sonnet 4.6」を正式に実装しました。
* **バックエンド**:
    * `anthropic` SDK を導入し、専用のルーティングブランチ（Routing: Claude Branch）を実装。
    * 画像（Base64）および PDF ドキュメントの入力に対応。
    * **Extended Thinking (思考プロセス)** に対応。`Thinking` オプション有効時に、モデルの推論過程をリアルタイムに表示します。
* **フロントエンド**:
    * モデル選択リスト（MODELS）に「Anthropic Claude」カテゴリを追加。
    * 初期セットアップ画面および設定モーダルに Claude 4.6 シリーズと Anthropic API Key 設定項目を追加。
    * ウェルカム画面に Claude Sonnet 4.6 のクイックスタートボタンを追加。
* **システム**:
    * `User` モデルに `anthropic_api_key` カラムを追加し、API キーの安全な保存と同期に対応。
    * `chat_core.v4.8.507.js` を新規作成し、Claude 向けの UI 制御ロジックを統合。
* **バージョン**: `app.py` の `APP_VERSION` を `2026-05-11-001`、`SYSTEM_VERSION` を `V4.8.507` に更新。
