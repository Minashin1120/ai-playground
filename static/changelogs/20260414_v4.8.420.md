# Update Log (2026-04-14) - V4.8.420

## 修正と改善
* **PDF生成機能のスタイル改善（視覚的構造の修復）**: 
  * 前バージョンの強引な `!important` 指定によるデザイン崩れを修正しました。
  * `code` や `pre` 要素に対し、適切な背景色（薄いグレー）を再導入し、インラインコードやコードブロックの視覚的な区別を復活させました。
  * `line-height`, `vertical-align`, `letter-spacing` を明示的に制御することで、文字の重なりやクリッピング（断片化）を改善しました。
  * インラインコード要素を `inline-block` として扱うことで、レイアウトの安定性を向上させました。
  * `color-scheme: light` を強制し、ブラウザのダークモード設定による予期せぬ干渉をより細かく抑制しました。

## システム更新
* `APP_VERSION` を `2026-04-14-005` に更新。
* フロントエンドのリソースを `V4.8.420` に更新。
