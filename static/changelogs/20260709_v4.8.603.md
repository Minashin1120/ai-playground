# V4.8.603 — UI全面洗練リデザイン

**日付:** 2026-07-09  
**種別:** デザイン刷新（機能変更なし）

## 概要

ミッドナイトネイビー + リキッドグラス + teal/amber の世界観を維持しつつ、全画面でデザイン言語を統一。階層・余白・コンポーネントの完成度を向上。

## 主な変更

### デザインシステム
- 共有 CSS `static/css/app-design.css` を新設（トークン / ガラス / ボタン / 認証カード / オーロラ / ランディング）
- チャット用 `chat.custom` に同一トークン体系を統合（半径・影・表面階層・フォーカス）
- デフォルトテーマ色を `#0dd4bf` に統一（CSS / JS `THEME_DEFAULT` / 設定プリセット）

### チャット UI
- サイドバー・モバイルヘッダー・入力ドックをガラス階層で再整理
- ウェルカム画面をフラット灰からラジアル＋ガラスタイルへ
- メッセージバブル・コード枠の半径と境界を統一
- Alpha bar / flash を緑・青ノイズから teal ブランドへ
- 青ユーティリティ残留を theme teal に寄せる

### 全画面統一
- ログイン / サインアップ / 2FA / ランディング / セットアップ / 更新履歴
- 403 / 404 / メンテナンス / バン / オフライン
- Apache 直配信 500 / 503 のベース色を製品 navy に同期
- PWA `theme-color` を `#060b18` に

## 影響範囲

- 見た目のみ。API・ストリーム・設定ロジックは変更なし
- ユーザー保存済み `theme_color` は維持（未設定時のデフォルトのみ変更）
