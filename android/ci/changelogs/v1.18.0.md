# AI Playground Android v1.18.0

- 入力欄をWeb版と同じ見た目にしました。モデルボタン、Canvas・Coding・Batch、Search・Python・File・SysPrompt・Thinking・Effort・Safety・PromptCache・Compress・一時チャットのチップが、Web版と同じ並び・名前・色で表示されます。
- モデルごとに表示されるチップと選べる値をWeb版と同じにしました。Thinkingのレベル（Min／Low／Mid／High）とBudget、Effort、Safetyは入力欄のチップから選べます。
- File と SysPrompt のチップが送信内容に反映されないことがある不具合を修正しました。
- PromptCache を有効にすると、別のAPIのモデルへ切り替えられないようにしました（Web版と同じ動作です）。
- 会話の文字を選択して「Quote」を押すと、引用として入力欄に追加できるようにしました。引用は送信するメッセージと一緒に送られます。
- メッセージの編集中は「編集中: このメッセージを編集しています」と表示するようにしました。
- Coding Mode の対象を入力欄の上に表示するようにしました。コードブロックの「編集対象に指定」を押すと固定され、×で解除できます。Canvas と Coding を同時に使えるようにしました。
- 添付したファイルを入力欄の上にサムネイルで表示し、件数とアップロードの進み具合を表示するようにしました。
- Gem を選んでいるときの表示と固定プロンプトのボタンを、Web版と同じ見た目にしました。
- 入力中の内容の入力トークン数の見積もりを、入力欄の下に表示するようにしました。
- 送信ボタンと停止ボタンをWeb版と同じ見た目にしました。
- コンパクト表示では「詳細」ボタンでチップを開閉できるようにしました。
