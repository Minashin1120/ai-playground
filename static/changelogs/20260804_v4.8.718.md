# V4.8.718 — ローディングスピナーの通信状態表示を修正

## 修正

- ストリーミング回答の受信中も「送信中...」が続いていた表示を、通信段階に合わせて「送信中...」「モデルの応答待機中...」「受信中...」へ切り替えるよう修正しました。
- 通常送信、切断後のストリーム再接続、ブラウザ高速モードで、共通の自動追跡とチャット専用追跡が二重に動作しないようにしました。
- ストリーム受信完了時にチャット専用スピナーを終了し、回答後の画面更新中まで「受信中...」が残らないようにしました。
- 内容を特定できない通信の既定文言を「処理中...」から「通信中...」へ変更し、実際には処理を行っていない場面での誤解を減らしました。
- 通常の `fetch` / XMLHttpRequest も、レスポンス本文の読み取り開始時に「受信中...」へ切り替わるようにしました。
