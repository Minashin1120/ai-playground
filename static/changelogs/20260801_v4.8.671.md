# V4.8.671 (2026-08-01)

## 長い画像解析回答のDB保存エラーを修正

- 画像解析やPythonツール利用後の長い回答を保存すると、`Data too long for column 'content'` で回答が中断される問題を修正しました。
- 原因は、長文回答をE2EE暗号化した際に暗号文がMySQL `TEXT`の65,535バイト上限を超えることでした。
- メッセージ本文、思考データ、引用文、思考署名をMySQL `LONGTEXT`へ移行し、暗号化された長い回答や推論内容を省略せず保存できるようにしました。
- 任意マイグレーションが無効な環境でも起動時に必須カラム型を検査・修復し、修復できない場合は不完全な状態で稼働しないようにしました。
- MySQL向けDDLと、従来の`TEXT`上限を超える暗号化メッセージの保存・復号に回帰テストを追加しました。
- 必須のバージョン付きJS/CSS資産をV4.8.671へ更新しました。
