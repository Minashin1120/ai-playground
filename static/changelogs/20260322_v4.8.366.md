# Update 2026-03-22 (v4.8.366)

### 修正: 初期テーマ初期化の安全化
- テーマ色の初期化時に `localStorage.setItem()` を呼んでいたため、環境によっては起動直後の JS が途中で止まり、履歴やアニメーションの初期化まで進まない可能性がありました。
- 初期描画は `chat.html` の head で CSS vars を先に出力して行い、JS 側の起動時処理はストレージ書き込みなしで安全にテーマ適用するよう変更しました。
