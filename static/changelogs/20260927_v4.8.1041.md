# 更新履歴 - V4.8.1041 (2026-09-27)

### Android連携
- **接続先の指定に対応**: Androidアプリのログイン画面で、本OSSをセルフホストしたサーバーを指定できるよう、接続情報（/api/mobile/v1/config）にサーバー名と利用できるログイン方法を追加しました。
- **ブラウザー認証の戻り先**: 公式ホスト以外のサーバーでは、ブラウザー方式のログイン・アカウント連携・安全性確認の完了後に、アプリ固有のリンクでアプリへ戻れるようにしました（PKCE必須）。Turnstile確認後の戻り先は、公式ホストの固定URLではなく接続中のホストになりました。
- **セルフホスト向け設定**: TurnstileもPlay Integrityも使わないサーバー向けに、運営者が明示的に設定した場合だけネイティブログインの安全性確認を省略する設定（MOBILE_NATIVE_GATE）と、ログイン画面の表示名（MOBILE_SERVER_NAME）を追加しました。
- **パスキー**: assetlinks.json にパスキー用の宣言（get_login_creds）を追加しました。
