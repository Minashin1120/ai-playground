# AI Playground Android v1.16.0

- 履歴サイドバーをWeb版と同じ見た目・並びにしました。上部にGitHub、更新履歴、チャット履歴、低速回線モード、設定、ライブラリ、新規チャット、Batch処理、PDF出力のボタンが並びます。
- スレッドの行に名前変更ボタンを追加しました。ブックマークの星は左側に表示されます。
- 履歴とGemsの一覧を下に引っ張ると更新できるようにしました。一覧の最後までスクロールすると続きを自動で読み込みます。
- サイドバーのGemsから、その場でGemの作成・編集・削除ができるようにしました。
- 「チャット履歴」ボタンで、検索付きの履歴一覧を開けるようにしました。
- 低速回線モードを追加しました。通信が遅いときやデータセーバーが有効なときに自動でオンになり、ボタンで自動／オン／オフを切り替えられます。
- サイドバー下部に版表示（押すとアルファ版の注意を表示）、利用規約、プライバシーのリンクを追加しました。
- スマートフォンの上部バーをWeb版と同じ構成（メニュー、タイトル、＋、PDF出力）にしました。タブレットでは上部バーを表示せず、サイドバーに集約します。
- 削除や名前変更の確認をWeb版と同じ形式にしました。ログアウトは確認なしで実行します。
- タイトルのないチャットは「No Title」と表示するようにしました。
- バブルで開く操作は、設定画面のアプリ更新の下に移動しました。
