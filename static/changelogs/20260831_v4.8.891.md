# 更新履歴 - V4.8.891 (2026-08-31)

Excel（xlsx/xlsm）ファイルの編集（edit_file）で、セルへ新しい書式を追加できるようになりました。従来はセルの値のみ編集でき、既存の書式は保持されるだけで新しく書式を追加することはできませんでした。cell_edits の各セルに style を指定すると、塗りつぶし色・フォント（太字・斜体・文字色・サイズ・下線・取り消し線）・罫線（四辺一括または辺ごと）・配置（水平・垂直・折り返し）・表示形式（numberFormat）を追加・変更できます。指定した項目だけが上書きされ、それ以外の既存の書式は維持されます。値の変更を伴わず書式だけを適用することもできます。
