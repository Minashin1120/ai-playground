# アップデート履歴 V4.8.591

**リリース日:** 2026-06-13

## 変更内容

### DeepSeek V4 Flash / V4 Pro のストリーミング修正
- **問題**: DeepSeek V4 モデルが非ストリーミング（`stream=False`）で API を呼び出していたため、推論プロセス（思考連鎖）のトークンが逐次表示されず、ユーザーが最終応答の完了まで待たされていた。
- **修正**: `stream=True` を指定し、`delta.reasoning_content` / `delta.content` をチャンク単位でストリーミング処理するよう変更。
- **根拠**: [DeepSeek Thinking Mode Guide](https://api-docs.deepseek.com/guides/thinking_mode) および [Create Chat Completion API](https://api-docs.deepseek.com/api/create-chat-completion) の公式ドキュメントに準拠。
