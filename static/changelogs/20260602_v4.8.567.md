# V4.8.567 (2026-06-02)

## ログイン画面オーロラ背景アニメーションの視認性調整

### 問題
- V4.8.566 で追加したグラデーションアニメーション背景が「ぼかしすぎていてほとんど見えない」状態でした。

### 調整内容
- 全3対象テンプレート（login.html / signup.html / verify_2fa.html）のオーロラCSSを以下のように強化：
  - `filter: blur(78px)` → `blur(46px)`（デスクトップ）
  - `filter: blur(58px)` → `blur(36px)`（モバイル）
  - ベース不透明度 `0.26` → `0.38`
  - 各blobの色強度を上げ（teal 0.65→0.78、amber 0.55→0.68、cyan 0.42→0.55 など）
  - violet blob の不透明度も `0.22` → `0.30` に引き上げ
- 動き自体（速度・方向・キーフレーム）は変更せず、ユーザーが選んだ「穏やか」な印象を維持
- reduced-motion 時も比例して調整

### 影響
- ログイン関連3画面で、teal / amber を中心とした柔らかい光の移動がはっきり認識できるようになった。
- フォームカードの視認性は維持（カード背景は従来通り）。
- その他のページ・機能に影響なし。
