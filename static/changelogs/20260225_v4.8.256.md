# V4.8.256 (2026-02-25)

## トークン計上修正の不具合修正（Responses API / DBスキーマ）

V4.8.255 のトークン計上改善に関連して発生していた不整合を修正しました。

### 1. `tokens_thought` 保存時のサーバーエラー対策
* **不具合**: `Message(..., tokens_thought=...)` を保存している一方で、`message` テーブル / `Message` モデルに `tokens_thought` カラム定義がなく、保存時に例外が発生する可能性がありました。
* **修正**: `Message.tokens_thought` を追加し、起動時スキーマ補正（`ALTER TABLE message ADD COLUMN tokens_thought`）にも対応。

### 2. Responses API の usage 取得位置を公式仕様に合わせて修正
* **不具合**: ストリームイベントのトップレベル `usage` のみを見ていたため、`response.completed` の `response.usage` を取りこぼすケースがありました。
* **修正**: `response.completed` および `responses.retrieve(...)` の戻り値から `usage` を取得するよう修正。

### 3. OpenAI / xAI の usage schema 差異を吸収
* **内容**: OpenAI Responses API (`output_tokens` / `output_tokens_details`) と xAI 系 (`completion_tokens` / `completion_tokens_details`) の両方に対応。
* **内容**: xAI では `reasoning_tokens` を `tokens_out` に合算し、スレッド合計の過少計上を防止。

### 4. 履歴APIで Thinking トークン内訳を返却
* **内容**: `GET /api/threads/<id>` で保存済み `tokens_thought` を返すようにし、再読み込み後も `Out X (Thought Y)` 表示を維持。

### 5. 互換性調整
* **内容**: Responses API リクエストから `stream_options` を除去（Chat Completions 向けパラメータ混入回避）。
