# Update 2026-03-22 (v4.8.364)

### 修正: バージョン更新後の二重ロード抑止
- `checkVersion()` が `localStorage` の旧 `app_version` を検知しただけで `location.reload()` していたため、デプロイ後の初回アクセスで見た目上の二重ロードが発生していました。
- 現在表示中の bundle がすでに最新 `appVersion` を持っている場合は再読み込みせず、キャッシュ削除と `localStorage` 更新だけを行うようにしました。
- 旧 bundle を掴んでいるケースだけは従来どおり reload するため、更新反映の安全性は維持しています。

### 付随更新
- `app.py` の `APP_VERSION` を `2026-03-22-001` に更新。
- `chat.html` の表示バージョンを `V4.8.364` に更新。
- `chat_app.js` のデバッグログ表示バージョンを `v4.8.364` に更新。
