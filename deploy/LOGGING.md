# ログの収集と保存

フィードバック設定にある2つのスイッチは既定でオフです。「操作ログを記録する」は端末別、「サーバー調査ログを記録する」はアカウントごとの設定です。サーバー設定は同じアカウントでログインしたWeb版・Android版で共有し、「保存」で反映します。他のアカウントには影響しません。

記録するのは、処理の開始・結果・中断、固定エラー分類、HTTP状態、時間、件数、サイズ、固定の設定状態、検証済みの内部ID・操作のランダムIDです。プロンプト、回答、思考、チャットタイトル、添付・アップロード内容とファイル名、APIキー・パスワード・トークンは記録しません。例外・通知・console・事業者の応答の文言、任意のURLも収集せず、許可した項目・型・固定値だけを保存します。

Androidの操作ログがオンの場合、テキスト選択と数式操作について、ランダムIDによる操作の関連付け、フォーカス、選択メニューの要求と表示結果、押下終了400ミリ秒後の状態、数式の描画状態・横幅・縮小率・横スクロール位置と上限も記録します。選択した文字や数式そのものは含みません。これは端末の操作ログであり、管理者診断への自動送信は行いません。

端末の未送信操作ログは設定した保存時間（初期値1時間）で削除します。ブラウザーやアプリの停止中はコードを実行できないため、次回起動時に送信より先に削除します。サーバー調査ログはRedisの `diagnostic:v2:` 名前空間に保存し、各イベントに設定した保存時間のTTLを付けます。追加記録や読み出しで既存イベントの期限を延長しません。アカウントごとに直近最大2000件を参照でき、無効化時は未送信分を削除します。調査ログを既存の運用ファイルへ複製しません。

端末の操作ログがオフでも、サーバー調査ログだけをフィードバックへ添付できます。フィードバック・返信ともログ添付のチェックが必要です。新規フィードバックの「ログを一緒に送信する」は初期状態ではオフで、送信後もオフに戻ります。ログ添付を選択したフィードバック・返信には、その端末の操作ログと、同意が有効で残っている本人のサーバー調査ログを保存します。送信済みコピーは `feedback/<ID>/logs/` へ調査用として保持し、既存の件数・容量・フィードバック削除のルールに従います。受信時も許可項目を検証するため、旧クライアントが送る自由文は保存しません。

既存のサーバー運用ログと管理者Android診断ログは、設定した保存期間による削除の対象外です。新しく出力する内容には同じ機密除外を適用します。旧形式の既存保存ログは書き換えません。アプリの運用ログは発生箇所・重大度・安全な呼び出し位置を残し、自由文・SDK応答・SQLパラメータ・例外本文は出力しません。

明示選択によるチャットコピー、フィードバック本文、添付画像はログとは別の機能です。これらを選んだ場合の送信内容は従来どおりです。

Android管理者診断の送信間隔・容量上限などは [診断ログの説明](../android/docs/DIAGNOSTICS.md) を参照してください。

サーバーの `server.request.start` の `ms` は、最初のアプリケーションフックから認証・ログ同意の確認までの経過時間です。`server.request.end` の `ms` も同じ起点から計測し、AndroidのBearer認証を含む前処理を含めます。従来の計測は認証後から始まっていたため、古いログと範囲が異なります。Apache・Gunicornの受付待ち、Flaskがフックへ入る前の処理、ストリーム本文の送信時間は含みません。認証前には時計の値だけをリクエスト内に保持し、同意を確認するまで記録・保存しません。

通常チャットの配信は `reason_code: 120` の `server.stream.first`／`server.stream.end`／`server.stream.error` で購読開始と解放を記録します。`op` はリクエストの診断ID、`phase` は開始・終了・中断・失敗、`ms` は購読からの経過時間です。無通知でも600秒で終わる配信期限は `server.stream.error` の `reason_code: 123` で記録します。配信の終了はモデルの生成完了とは別です。空行の送信ごとのログや内容のログは追加しません。同意・保存期限・機密除外の条件は既存のサーバー調査ログに従います。

操作ログとサーバー調査ログの保存時間は、設定のフィードバックタブでそれぞれ1〜8760時間の整数を指定できます（初期値1時間）。操作ログはこの端末に即時反映し、サーバー調査ログはアカウント共通で「保存」で反映します。短縮時は期間外のログを削除します。延長は削除済みのログを復元せず、既存のサーバーログの期限も延長しません。件数・容量の上限に達した場合は保存時間内でも古いログから削除します。

入力欄のトークン計測では、既存の操作ログとサーバー調査ログに、`/api/token_estimate` の処理の開始・完了・失敗・中断、提供元、添付の件数、処理時間を記録します。計測APIに送った本文・引用・添付やAPI応答の内容は記録しません。API計測に失敗して概算へ切り替えた場合も、計測失敗と処理完了を区別します。保存の同意・期間は既存の設定に従います。

入力見積の詳細は開いたときだけ追加計測し、既存のモーダル表示・非表示、API通信、計測処理のログで追跡します。内訳の値・ファイル名・本文・引用はログへ追加しません。

AndroidのDNS補助は、操作ログがオンのときだけ `dns.fallback` に開始・成功・失敗（`phase`）、ランダムな処理ID、所要時間、取得したアドレスの件数を記録します。問い合わせたホスト名、IPアドレス、DNS応答、通知の文言、認証情報は記録しません。収集の同意・保存期限・フィードバックへの添付条件は既存の操作ログと同じで、管理者診断への自動送信は追加しません。
