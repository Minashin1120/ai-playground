# V4.8.604 — アニメーション滑らか化

**日付:** 2026-07-09  
**種別:** UI モーション改善（機能変更なし）

## 概要

全体のアニメーションを見直し、過剰なバウンスを抑えて滑らかなイージングに統一。

## 主な変更

### モーションシステム
- CSS 変数で時間・イージングを統一（`--ease-out` / `--ease-standard` / `--dur-*`）
- 強バウンス（overshoot 1.56 等）をソフトな ease-out に置換
- `transition: all` を個別プロパティへ寄せて描画を安定化

### 入場・UI
- メッセージ入場: 穏やかな scale/fade（ユーザーバブルの極端な scale(0.05) を廃止）
- ウェルカム slide-in: 2s → 0.55s（スタッガーは維持）
- モーダル: 開閉カーブを調整、JS は double-rAF + 280ms に同期
- トースト / タグ / サムネイル: 跳ね返りを抑えスムーズに

### その他
- サイドバー / Canvas / コード折りたたみ / Thinking の transition を統一
- スクロール領域に `scroll-behavior: smooth`
- オーロラ背景を translate3d + より緩やかな周期に
- `prefers-reduced-motion` 対応を強化

## 影響範囲

見た目の動きのみ。API・ロジック変更なし。
