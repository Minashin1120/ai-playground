# V4.8.688 (2026-08-02)

## フレームレート計測対象をページ全体と読み込み時へ拡大

- これまで軽量化の自動判定はサイドメニューなど3ボタンのクリック時だけでしたが、任意の対話要素（ボタン／リンク／入力欄／選択欄など）のクリックで計測するよう対象を広げました。
- さらに、ページ読み込み時にテーマ初期化と連動して動くウェルカム画面の入場モーション（`slide-in-animate`）のタイミングで、初回の計測を自動実行します。初回からフレーム落ちがある端末は、操作前の段階でぼかし無効化／軽量モードを適用できます。
- 計測の頻度を抑えるため、前回計測から3秒間は再計測しません（クールダウン）。
- ストリーミング中やモーダルの開閉アニメーション中は一時的な重さを誤判定しやすいため、計測をスキップします。
- 軽量モード（`performance-lite-mode`）適用時に入場アニメーションが無効化され、`opacity: 0` で始まるウェルカム画面の要素が透明のまま表示されなくなる問題を修正しました。`.fade-in`／`.slide-in-animate` を軽量モードでは最終表示状態（不透明・位置リセット）にします。
