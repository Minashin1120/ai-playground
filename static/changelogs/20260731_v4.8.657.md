# V4.8.657

## Canvas のソース選択とスクロール保持を改善

- Canvas の既定ソースを、回答内の最後の Markdown コードブロックへ統一しました。
  - Coding Mode の回答に含まれる先頭の `diff` ブロックではなく、後続の更新後コードを自動表示します。
  - HTML ブロックを優先して遡る旧挙動を廃止し、コードの言語にかかわらず最後のブロックを選択します。
- Source タブにコードブロック選択メニューを追加しました。
  - ユーザーが選択したブロックは、その回答のストリーミング更新中も維持します。
  - 未選択の状態では、新しいコードブロックが生成されるたびに最新ブロックへ追従します。
- モデルのコード生成中に Canvas の内容が更新されても、スクロール位置を保持するよう修正しました。
  - Source 欄の縦横スクロールを DOM 更新前後で維持します。
  - sandbox iframe 内の Live Preview と親画面の間でスクロール位置を安全に同期し、iframe 再生成後に復元します。
  - ソースを明示的に切り替えた場合だけ、新しいブロックの先頭へ移動します。
- 3文字以上のバッククォート／チルダによる Markdown フェンスを Canvas でも解析できるようにし、Coding Mode が生成する長いフェンスに対応しました。
- Canvas の既定選択、Source タブ切替、スクロール保持に対する回帰テストを追加しました。
