# V4.8.687 (2026-08-02)

## 軽量モード自動適用時のトースト通知が表示されない問題を修正

- 自動判定で「軽量表示（最小負荷）」を適用する際、Cookieの書き込みがブラウザのプライバシー設定などで拒否されると例外が発生し、後続のトースト通知が表示されないことがありました（軽量モード自体は画面に反映済み）。
- `writeAdaptiveBlurCookie` を例外安全にし（`readCookieValue` と同じ try-catch 方式）、Cookieが使えなくても処理を中断しないようにしました。
- `enableAdaptiveBlurLite` 内のトースト通知をCookie保存より先に呼び出すよう並べ替え、自動適用時は確実に通知が表示されるようにしました。
- 通知のタップで設定画面の「通常表示の背景ぼかし」へ移動する動作、通知の表示内容は変更していません。
