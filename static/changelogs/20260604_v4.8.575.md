# V4.8.575 変更履歴

## 主な修正・改善
- **Gemini モデル404エラー対策**: `gemini-3.1-flash-lite-preview` など廃止されたプレビューモデルを選択した際に発生する `404 NOT_FOUND "This model ... is no longer available"` を修正。
  - デフォルトのAI設定解釈モデルを安定した `gemini-2.5-flash` に変更。
  - Gemini呼び出しでモデル404/廃止を検知した際、自動的に `gemini-2.5-flash` でフォールバック再試行（ログ出力あり）。
- **管理者向け一時デバッグ機能追加**（設定モーダル AIセクション）:
  - 管理者アカウントの場合、AI適用失敗時に「管理者デバッグログ（一時的）」パネルを自動表示。
  - 選択モデル・エラーメッセージ・詳細（raw_error）を表示。
  - 「コピー」ボタンでクリップボードにログ全文をコピー可能（navigator.clipboard + フォールバック対応）。

これにより、管理者アカウントでAI設定機能のトラブルシューティングが容易になりました（一時的措置）。
