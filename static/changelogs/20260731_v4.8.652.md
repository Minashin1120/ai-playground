# V4.8.652

## DeepSeek V4のPythonコード実行に対応

- DeepSeek V4 Flash／Proを選択した場合も、プロンプトバーの「Python」を利用できるようにしました。
- DeepSeek公式のTool Calls仕様に従い、ストリーミングで分割される関数名・引数と並列ツール呼び出しを復元し、既存のネットワーク隔離済みPythonサンドボックスで実行します。
- Pythonのコードと出力をチャットへ逐次表示し、実行結果を`tool`メッセージとしてDeepSeekへ返してから最終回答を生成します。
- Thinking中のツール呼び出しでは、公式要件どおり`reasoning_content`を後続リクエストへ完全に引き継ぎます。次のユーザーターンでも必要なツール会話コンテキストを復元します。
- ツールの連続呼び出しは最大8ターンに制限し、未登録ツール、不正なJSON引数、空のコードを安全に拒否します。
- DeepSeek V4 Flash／Proの実APIで、ツール呼び出し、隔離Python実行、結果返送、最終回答までの一連の動作を確認しました。
