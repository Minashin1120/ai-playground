# 更新履歴 - V4.8.802 (2026-08-14)

画面の機能と見た目は維持したまま、読み込みと古い端末での描画負荷を下げました。

- チャット用JavaScriptとCSSを圧縮して配信するよう変更しました。編集用の読みやすいソースは残しています。
- Font Awesomeの全アイコンCDNをやめ、使用しているアイコンだけを同一オリジンから配信するようにしました。
- Noto Sans JPとJetBrains Monoの読み込みを非同期にし、読み込みをブロックしないようにしました。文字ウェイトも本文用と見出し用に絞っています。
- 軽量表示ではカスタムWebフォントを読み込まず、システムフォントを使うようにしました。
- 画面外のチャットメッセージは描画を後回しにし、長い履歴でもスクロールが重くなりにくくしました。
- 配布用Apache設定で、静的ファイルをGunicorn経由にせずディスクから直接返し、テキスト資産を圧縮する例を追加しました。
