# V4.8.692 (2026-08-03)

## プロンプトなし・画像のみで送信すると 400 エラーになる問題を修正

- プロンプトテキストを入力せず画像だけを添付して送信すると、サーバー側の `chat_stream` 入力検証がメッセージ本文が空であることを理由に `400 Invalid or oversized message` を返していました。
- 添付ファイル（画像・音声・動画・PDF 等）がある場合はプロンプト本文が空でも送信できるよう、`chat_stream` の検証を「本文が空 かつ 添付なし のときだけ拒否」する形に変更しました。ブラウザ高速モードの保存 API（`save_browser_fast_mode_chat`）にも同じ対策を適用しました。
- 各モデルプロバイダーへ送る現在メッセージの構築で、本文が空の場合は空のテキストパートを送らないよう修正しました（空テキストパートが Gemini / Claude / OpenAI Responses / Grok 側で 400 の原因になるため）。
  - Gemini: `types.Part(text="")` を生成しない
  - Claude: `{"type": "text", "text": ""}` を生成しない
  - OpenAI Responses API / Grok Native SDK: 空テキストの `input_text` / 文字列パートを追加しない
- DeepSeek / Kimi K3（画像直接入力不可）で画像のみを送った場合は、Vision Model による解析結果をユーザーターンの本文として利用して回答生成を継続するようにしました。従来は「request is empty」で中断していました。
