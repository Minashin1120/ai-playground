# V4.8.698 (2026-08-03)

## アカウントBANページでスクロールが発生する問題を修正

- BANページの `body` を `min-height: 100vh` から固定高さ `height: 100vh` / `height: 100dvh` に変更し、`overflow: hidden` を追加しました。モバイルブラウザのアドレスバー分だけページが縦に伸びてスクロールできてしまう問題が解消されました。
- コンテンツ（異議申し立てフォーム等）が画面に収まらない場合は、ページ全体ではなくカード内部だけがスクロールするようにしました（`max-height: calc(100dvh - 32px)` + `overflow-y: auto` + `overscroll-behavior: contain`）。これにより、フレックス中央寄せで上部がスクロール範囲外に押し出されて見えなくなる不具合もあわせて解消されます。
