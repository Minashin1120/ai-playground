# V4.8.572 変更履歴

**日付:** 2026-06-03

## 主な新機能
- **設定モーダル AI アシスタント**: 一般タブ上部に「AIで設定を変更 (ツール使用)」セクションを追加。ユーザーが自然言語の指示（日本語/英語可）を入力し、「モデル選択」ボタンで任意のツール対応モデル（Gemini/GPT/DeepSeek/Grok系など、既存のモデル選択モーダルをフラグ再利用で呼び出し）を指定して「AIで適用」すると、バックエンドで選択モデルのツール呼び出し機能を利用して指示を解釈し、設定モーダル内で管理可能な**安全な項目のみ**を即時DB更新＋フォームUIライブ反映します。
  - 権限厳守: AI_SAFE_EDITABLE_FIELDS のホワイトリスト＋ _apply_ai_settings_update でシークレット/APIキー/管理者専用（admin_api_key_mode, bot_detection_global_enabled, global_system_prompt本体など）/高リスク項目（passkey_only_login, e2ee, パスワード変更など）を完全に除外。非管理者アカウントでは管理者限定設定を変更不可（UI経由と同じロジック）。
  - ロジック統一: 設定更新は handle_settings と同じ代入パターンを _apply_ai... でミラー。
  - 即時適用（A方式）: ツール結果を即保存し、fetchで最新値を取りフォーム要素を更新（保存ボタン押下不要で反映、通常保存は別）。
- 対応モデル: Gemini (google.genai ネイティブツール)、OpenAI互換（GPT/DeepSeek/Grokのopenai client + base_url）。Claudeは未対応メッセージ表示。
- 安全策: プロンプト長制限、要素存在チェック、try-catch、ボタン無効化、AI適用結果のサマリ表示。

## その他の変更
- バックエンド: 新規 `/api/settings/apply-ai-prompt` エンドポイント、AI_SAFE_EDITABLE_FIELDS / AI_NEVER_EDITABLE_FIELDS 定数、_apply_ai_settings_update / _call_llm_for_settings_ai / _build_ai_settings_tool_schema ヘルパーを追加。
- フロントエンド: chat.html / chat_core.v4.8.571.js にAI UIとピッカー再利用ロジック（aiSettingsModelPickerActive フラグ + 分岐で render/select を共有、コード重複ゼロ）。
- バージョン資産: V4.8.572 向け chat_core / chat.custom / chat.tailwind を新規作成。

## 影響・注意
- 既存設定保存・表示に影響なし（AIはオプトイン機能）。
- ツール呼び出しはユーザーのAPIキー（または .env フォールバック）を使用するため、キー未設定モデルはエラー表示。
- グローバルシステムプロンプト、認証情報、管理者専用項目などはAIによる変更対象外です。
