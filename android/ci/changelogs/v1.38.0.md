- New "サーバーを使わずに始める" button on the login screen: use the app without an account. Chats, attachments and API keys stay encrypted on this device and messages go straight to the AI providers (Gemini, OpenAI, Anthropic, xAI, DeepSeek, Kimi, Mistral).
- New "接続" card in Settings (General tab): turn on serverless mode to send messages directly from the device while staying signed in. Chats in this mode are kept on the device; your account settings, Gems and other features keep working through the server.
- API keys for these modes are entered in the API keys tab and stored encrypted on the device. Models that cannot run on the device yet are not selectable; Batch and Coding Mode are not available in these modes.
