# 更新履歴 - V4.8.1091 (2026-10-13)

- 開いているチャットのプロンプトキャッシュを解除できるようにしました。解除するとPromptCacheはオフになり、次に有効にしたときは別のキャッシュを使います。
- モバイルブラウザーでGemini Liveが無音のまま終わることがある問題を修正しました。音声を取得できないときは、空の会話を保存しません。
- Androidアプリで、更新の確認が終わらないことがある問題を修正しました。
- Androidアプリで、共有から開いた画面を使用履歴から開き直したときに、共有された内容を再度処理しないようにしました。
- Androidアプリで、他のアプリのテキスト選択メニュー「プロンプトとして添付」から、選択したテキストを入力欄へ追加できるようにしました。
