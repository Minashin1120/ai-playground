# v4.8.440 (2026-04-21)

### ✨ UI・デザインの刷新
- **Gem専用固定プロンプトのUIを大幅刷新**:
  - プロンプトボタンを、入力欄（プロンプトバー）のすぐ上の透明な空間に浮いているようなレイアウトに変更しました。
  - ボタンの形状を「横長で丸い形（カプセル型・ピル型）」に変更し、背景色を付けることで視認性を高めました。
  - プロンプトを並べるバー自体は完全な透明とし、枠線なども排除したシンプルな浮遊デザインとなっています。
  - 横スクロールにより、多くのプロンプトをスムーズに切り替えることができます。

### 🛠 内部的な変更
- システムバージョンを `V4.8.440` に更新。
