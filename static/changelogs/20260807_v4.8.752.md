# V4.8.752 (2026-08-07)

## ヘルプページを追加

全機能の使い方を解説するヘルプページ（`/help`）を開設しました。**ログインしていない状態でも閲覧できます**。

- 注目機能として「**高速モード（ブラウザ直接送信）**」を最上部に掲載し、使い方の手順、利用できる機能（Python コード実行・Thinking 表示・画像添付・複数ターンの継続）、利用できない機能（検索・URL・Maps・Gems など）、有効化前に確認すべき注意点を詳しく解説しました。
- 高速モードに加えて、マルチモデル対応、BYOK とプライバシー、Thinking 可視化、マルチモーダル、検索・URL・地図・Python 連携、Canvas / Coding Mode、画像生成・音声会話、チャット管理、データ移行、セキュリティ、便利機能、よくある質問（FAQ）の各セクションを掲載しました。
- ページ左側に固定の目次を表示し、スクロール位置に応じて現在のセクションをハイライトします。モバイルでは目次を折りたたみできます。
- トップページ・ログイン画面のヘッダー／フッター、およびチャット画面のサイドバーにヘルプへのリンクを追加しました。
- `robots.txt` に `/help` と `/changelog` を明示的に Allow しました。
