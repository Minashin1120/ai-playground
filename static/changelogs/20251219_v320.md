# V3.2.0 - Live Security Migration
**2025-12-19**

*   **ライブ・マイグレーション機能**: 設定画面でE2EE（暗号化）やFile Isolation（隔離）を切り替えた際、過去のメッセージやファイルも自動的に変換・移動するようになりました。
*   **セキュリティUIの改善**: 設定画面とセットアップ画面に詳細な説明文を追加し、[ALPHA] [NEW] ラベルを付与しました。
*   **デフォルト設定の変更**: 初回セットアップ時のセキュリティ機能をデフォルトOFFに変更し、ユーザーが選択できるようにしました。
*   **画像圧縮のバグ修正**: クライアント側で画像を圧縮した際に、ファイル名が消失してAIが認識できなくなる問題を修正しました。
*   **Gemini 3 Flash UI**: Gemini 3 Flash選択時にThinking（推論）が強制ONになるようUI制御を改善しました。
