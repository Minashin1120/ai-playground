# V4.8.207 (2026-02-16)

- 添付ファイル送信時に `image_items[].name` を受け渡す経路を追加し、モデル向けの送信名を指定できるようにしました。
- サーバー側で送信名の解決ロジックを追加し、優先順位を「リクエスト指定名 > ライブラリ表示名 > 自動連番名」に統一しました。
- 画像の自動送信名を `画像1` / `画像2` ... として生成し、保存ファイル名に依存しないモデル入力名を付与するようにしました。
- OpenAI の `input_file` / `file` 添付では `filename` に送信名を使用し、Gemini/Grok/Responses の画像入力では添付画像名一覧テキストを同時送信するようにしました。
- `chat.html` のタイトルを `V4.8.207` に更新しました。
