# V4.8.276 (2026-02-26)

## STTボタンに録音状態表示とリアルタイム音声波形を追加

添付ボタン横の文字起こし（STT）ボタンで録音開始後、録音中かどうかが分かりにくかったため、録音状態のテキスト表示とリアルタイム波形インジケーターを追加しました。

### 変更内容
* **録音状態テキストを追加**: 入力欄下に `録音準備中…` / `録音中…` / `録音を処理中…` を表示し、録音開始・停止後の状態を明確化。
* **リアルタイム波形を追加**: 現在入力されている音声レベルのみを表示する、横並びバー方式の波形インジケーターを追加（履歴は保持しない）。
* **録音終了時の後始末を追加**: 録音完了・キャンセル・失敗時に波形描画とインジケーターを確実に停止/非表示化。
* **表示バージョン更新**: `chat.html` の表示バージョンと `chat_app.js` キャッシュバスターを `V4.8.276` に更新。
