# V4.8.766 - ウェルカム画面のクイックアクセスを最近実装した5モデルに自動絞り込み

## 変更内容

- ウェルカム画面のモデルクイックアクセスを、静的なボタン一覧から動的描画へ変更しました。
- 各モデル定義（`MODELS`）に内部メタデータ `implementedAt`（実装日, `YYYY-MM-DD`）と、同一日内の順序用 `implementedRank` を追加しました。UIには表示しません。
- 非推奨でないモデルを実装日の新しい順に並べ、上位5件だけをクイックアクセスへ表示します（任意の `quickEmoji` があれば先頭に表示）。
- 以降のモデル追加では、実装日メタデータを付与すればクイックアクセスが自動更新されます。

DBスキーマ変更なし。
