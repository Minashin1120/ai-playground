# v4.8.451 (2026-04-26)

### 🛠 修正・改善
- **DeepSeek V4 の追加**:
  - モデル一覧と初期セットアップに `DeepSeek V4 Flash` / `DeepSeek V4 Pro` を追加しました。
  - 設定画面とセットアップ画面に DeepSeek 用 API Key 入力欄を追加しました。
- **DeepSeek 推論対応**:
  - `deepseek-v4-flash` / `deepseek-v4-pro` を DeepSeek API (`https://api.deepseek.com`) の `chat.completions` にルーティングするようにしました。
  - DeepSeek 系では reasoning effort を DeepSeek 側の仕様に合わせて補正し、思考ログを受け取れるようにしました。
- **利用制限の明確化**:
  - DeepSeek 系はテキスト専用として扱い、画像入力は受け付けないようにしました。
  - 音声文字起こしの LLM ルートでは DeepSeek モデルを未対応として明示的に拒否するようにしました。
- **タイトル生成対応**:
  - DeepSeek を使ったタイトル生成ルートを追加しました。

### 🛠 内部的な変更
- システムバージョンを `V4.8.451` に更新。
