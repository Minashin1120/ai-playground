# 更新履歴 (V4.8.454) - 2026-04-26

## PDF生成エンジンの堅牢化とUI表示の改善

### 修正内容
* **PDF生成時のパースエラー解消**:
    * HTMLの `DOCTYPE`, `Comment`, `Declaration` などのメタノードが原因で ReportLab の `Paragraph` がパースエラー（`syntax error: invalid attribute name rel` 等）を起こす問題を修正しました。
    * 直接テキストを処理する際にも適切なエスケープ（`html.escape`）と改行処理を施すようにし、予期せぬHTMLタグが PDF エンジンに渡るのを防止しました。
    * `head`, `meta`, `link`, `title` などの PDF に不要なタグを明示的に無視するようにガードを強化しました。
* **プログレスバーの視認性と安定性の向上**:
    * プログレスバーの更新を CSS の `transform: scaleX()` から `width` パーセント指定に変更し、アニメーションと表示の正確性を高めました。
    * バーの色が灰色に見える（透明または背景色と混ざる）問題を解決するため、インラインスタイルで確実な琥珀色（#f59e0b）を指定し、光彩エフェクトを追加しました。
* **レンダリングロジックの最適化**:
    * `div` や `body` タグなどがインライン要素（テキストや `b`, `i`, `span` 等）のみを持つ場合に、一つの段落としてまとめて処理するロジックを改善し、PDFのレイアウトがより自然になるように調整しました。

### バージョン情報
* `app.py` の `APP_VERSION` を `2026-04-26-005` に更新。
* `chat.html` の表示バージョンを `V4.8.454` に更新。
