# v4.8.733 — ファイル選択モーダルの表示と通信耐性を修正

v4.8.732 で追加した「インポートするファイルを選択」のモーダルが表示されない問題を修正しました。

- ファイル選択モーダルが `modal-open` クラスを付与しておらず、共通モーダルCSS（`visibility: hidden`）により画面に表示されない状態になっていたため、アプリ共通のモーダル表示処理（`modal-prep` → `modal-open`）に合わせて修正しました。モーダルが容量不足時に確実に表示され、ファイルの選択・確認・キャンセルが操作できるようになりました。
- ストレージ容量確認の応答が大きい場合に、通信状況によって応答ボディの取得に失敗すると「インポートに失敗しました」だけが表示される問題に備え、容量超過応答の取得に失敗した場合は自動で再取得するようにしました。再取得後も失敗する場合は、通信環境の確認を促すメッセージを表示します。
- 設定画面のインポートでも、ファイル選択モーダルをアプリ共通の `showModal` / `hideModal` で表示するよう統一しました。
