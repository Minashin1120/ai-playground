# V4.8.699 (2026-08-03)

## ボット検出時の Cloudflare 認証ボックスの UX を改善

- 非管理者アカウントのボット検出（テレメトリ送信）時に、操作の途中で右下に Cloudflare Turnstile の認証ボックスが表示され、UX を低下させる問題を改善しました。
- Turnstile のレンダリングオプションへ `appearance: 'interaction-only'` を追加しました。これにより、通常の利用中は認証ボックスが一切表示されず、チャレンジはバックグラウンドで実行されます。
- Cloudflare が本当に人による確認を必要と判断した場合（疑わしいボット）だけボックスが表示されるため、セキュリティ強度は維持したまま、正常なユーザーへの表示が排除されます。
- 対象はチャット画面のボット検出ウィジェット（`#turnstile-container`）のみで、ログイン・サインアップ画面の可視ウィジェットには影響しません。
