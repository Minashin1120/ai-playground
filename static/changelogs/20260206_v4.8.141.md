# V4.8.141 (2026-02-06)

- 初回送信時の遅延対策として、`/chat_stream` でスレッド未指定時に自動作成するよう変更。
- フロントエンドの送信前 `POST /api/threads` を廃止し、初回プロンプトを1リクエスト化。
- ストリーム先頭で `thread_id` イベントを返し、初回送信でも即座にURLを `/c/<id>` へ同期。
- `/chat_stream` の保存処理を1トランザクション化（新規スレッド作成・ユーザーメッセージ保存・最終設定更新）。
- 送信パスの同期負荷を下げるため、ユーザーメッセージのトークン数計算を遅延評価に変更。
