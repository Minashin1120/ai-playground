# V4.8.289 (2026-02-26)

## Nano Banana 2 の画像生成不良修正 + オプション表示修正

`Nano Banana 2`（`gemini-3.1-flash-image-preview`）で、`Gemini 3` 系からの切替時に `thinking_level=medium` などの値が隠れたまま持ち越され、画像生成が失敗し得る問題を修正しました。あわせて、`項目` ボタンなしでも `Nano Banana 2` で必要なオプションをプロンプトバーから操作できるようにしました。

### 変更内容
* **画像生成安定化**: `app.py` の Gemini画像生成分岐で、`Nano Banana 2` の `thinking_level` を API仕様に合わせて `minimal/high` に正規化（`low→minimal`, `medium→high`）。
* **Nano Banana 2 オプション対応**: `templates/chat_app.js` の `toggleOptions()` を修正し、`Nano Banana 2` で `Thinking`（レベル選択含む）を表示。
* **SysPrompt 再有効化**: `Nano Banana 2` では `SysPrompt` をプロンプトバーから有効化できるように調整（他の画像モデルの既存挙動は維持）。
* **Gemini画像レスポンス指定の明示化**: Gemini画像生成リクエストで `response_modalities` を `TEXT + IMAGE` として明示。
* **表示バージョン更新**: `chat.html` の表示バージョンと `chat_app.js` キャッシュバスターを `V4.8.289` に更新。
