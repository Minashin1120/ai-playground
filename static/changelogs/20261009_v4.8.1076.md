# 更新履歴 - V4.8.1076 (2026-10-09)

### 新機能
- **自動注入システムプロンプトの項目を追加**: 設定の「自動注入システムプロンプト」に「Gemini コード実行（サンドボックスの実行時間制限）」と「Python + ファイル作成（Gemini コード実行時）」を追加しました。Geminiのコード実行時にモデルへ渡していた案内を、オン・オフや文面の編集ができます。

### 変更・修正
- **ファイル作成とPython実行の併用**: ファイル作成をオンにしたGeminiの回答で、Python実行環境内で作ったファイルを保存済みのように案内してしまうことがある問題を軽減するため、ファイルの作成・編集は専用のツールを使うよう案内を追加しました。
