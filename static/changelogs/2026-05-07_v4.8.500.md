# Changelog (2026-05-07)

## System Version V4.8.500

### Added
- Gemini API (google-genai) において、メディアファイル（画像、PDF、音声、動画）のアップロード時に `display_name` を設定するように変更しました。
- 画像ファイルについて、従来はテキストブロックでファイル名を補足していましたが、Gemini Files API を使用してアップロードし、API の `display_name` 機能を活用するように改善しました。
- **診断システム (Diagnostic System)** を導入しました。PCでは `Ctrl+Shift+D`、スマホではサイドバー下部のバージョン表示を **5回連続タップ** することでデバッグコンソールを表示し、JavaScriptのエラーや動作状況を確認できます。

### Fixed
- システムバージョンの更新に伴う `chat_core.js` の読み込みエラー（404）を修正しました。
- `showModal` および `hideModal` 関数をグローバルスコープに公開し、サイドバーやメニューボタンの反応がなくなる問題を修正しました。
- `chat_core.js` 内の内部バージョン表記を `v4.8.500` に更新しました。

### Changed
- `_gemini_upload_with_retry` 関数を拡張し、`display_name` 引数を追加しました。
- PDF、音声、動画の各処理ループでも `display_name` を渡すように更新しました。
