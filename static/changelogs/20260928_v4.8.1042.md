# 更新履歴 - V4.8.1042 (2026-09-28)

### Android連携
- **チャット同期API**: Androidアプリのサーバー不使用モード向けに、端末で作成したチャット・メッセージ・添付をアカウントへ保存する同期APIと、変更・削除されたチャットの一覧を返すAPIを追加しました。同じ内容を再送しても重複して保存されません。チャットの並び順や既存の画面・動作は変わりません。
- **APIキーの取り込み**: 本人確認を済ませたAndroidアプリが、利用者自身が保存したAPIキーを端末へ取り込めるAPIを追加しました。管理者用のキーは含まれません。
- **メッセージ削除の整理**: メッセージ削除の処理を共通化し、同期の変更記録に反映されるようにしました。
