# 更新履歴 (V4.8.456) - 2026-04-26

## ペイロード取得処理の安定化とフォールバック強化

### 修正内容
* **リクエストストリーム処理の改善**:
    * サーバー側で `get_json()` が失敗した後に生データを取得しようとすると、ストリームが既に消費されておりデータが空になる問題を修正しました。
    * `request.get_data(cache=True)` を使用することで、同一リクエスト内で複数回データを読み取れるように堅牢化しました。
* **生HTML送信へのフォールバック対応**:
    * 万が一クライアントから JSON 形式ではなく生の HTML 文字列がリクエストボディとして送信された場合でも、それを自動検知して PDF 生成プロセスへ渡すフォールバックロジックを追加しました。
* **デバッグログの更なる精緻化**:
    * データの抽出元（JSON, Form, Raw Body）や、取得したデータの長さをログに記録するようにし、特定のコンテンツで失敗した場合の追跡を容易にしました。

### バージョン情報
* `app.py` の `APP_VERSION` を `2026-04-26-007` に更新。
* `chat.html` の表示バージョンを `V4.8.456` に更新。
