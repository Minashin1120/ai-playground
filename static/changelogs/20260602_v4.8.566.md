# V4.8.566 (2026-06-02)

## ログイン画面へのグラデーションアニメーション背景の実装

### 概要
ログイン / 新規登録 / 2段階認証画面に、動きのある美しいオーロラ風グラデーション背景アニメーションを追加しました。ユーザーの選択に基づき、控えめで上品な動き、既存の teal/amber 配色を維持しつつ aurora らしい重なり合う柔らかい光のレイヤーを実装しています。

### 実装内容
- **対象ファイル**:
  - `app/templates/login.html`
  - `app/templates/signup.html`
  - `app/templates/verify_2fa.html`
- 各ページに `.aurora-bg` コンテナ + 4つの `.aurora-blob`（teal / amber / cyan / violet の柔らかいラジアル）を追加。
- 純粋な CSS アニメーション（`@keyframes` + `transform: translate + scale`）で実装。GPU アクセラレーションを活用し、パフォーマンスを重視。
- 3種類の異なる drift アニメーション（37s / 29s / 41s など）を組み合わせ、有機的で呼吸するような動きを表現。
- `mix-blend-mode: screen` により、複数の光のレイヤーが自然に重なり合う aurora らしい表現を実現。
- 既存の body 背景ラジアル + 細かいグリッドオーバーレイはそのまま維持（ユーザーの選択による）。
- `prefers-reduced-motion` 対応：アニメーションを自動的に無効化し、静的な控えめな表示に切り替え。
- モバイルでは blur とサイズを軽減し、描画負荷を抑制。

### 影響・注意点
- メインのチャット画面（chat.html）やその他の一般ページには一切影響しません。
- ログイン画面の視認性は保たれるよう、blob の不透明度を低めに設定（0.22〜0.26）し、フォームカードの backdrop-blur との相性も良好です。
- アクセシビリティ: 動きを苦手とするユーザー向けに reduced-motion 対応済み。
- パフォーマンス: 追加の DOM 要素は 5 個程度・CSS アニメーションのみのため、非常に軽量です。
