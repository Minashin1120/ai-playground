# V4.8.580 変更履歴 (設定検索機能)

**日付:** 2026-06-04

## 新機能
- **設定モーダルに検索ボックスを追加**
  - 設定モーダルヘッダー（タイトルとタブの間）に検索ボックスを設置。
  - 検索時は現在表示中のタブパネル内にオーバーレイとして結果リストを表示。
  - 各結果はタブバッジ（一般/セキュリティ/2要素認証/フィードバック）＋セクション見出し＋一致スニペットを表示。
  - 結果クリックで該当タブに切替 + スムーズスクロール + ハイライトアニメーション（2秒間）。
  - 検索クリア時はオーバーレイを削除し元の設定項目を復元。
  - 該当なしの場合は「〜に一致する設定項目はありません。」と表示。
  - タブクリックで検索クリア。
