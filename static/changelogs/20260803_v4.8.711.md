# V4.8.711 (2026-08-03)

## 検証済みユーザーにも連打ロックを発動

Turnstile検証済み（`botDetectionVerified`）のユーザーでも、送信ボタンなどの**DOMからの高速連打を検出したらアカウントを10分ロック**するよう変更しました。

### 背景

- V4.8.708で「検証済みユーザーには連打ダイアログを出さない」としていましたが、非管理者の検証済みアカウントでDOM連打を実行してもロックが発動しないことが判明。
- サーバーに負荷をかける高速なDOM連打は検証済みユーザーも検出対象とし、連打ロックの条件から `!botDetectionVerified` を除外しました。

### 変更内容（`chat_core.v4.8.711.js`）

- `sendMessage()` 冒頭の連打検知を `if (isBotDetectionActive())` に変更（`&& !botDetectionVerified` を削除）。
- **検証済みでも未検証でも**、2秒以内に5回以上の送信操作を検出したら `runSendSpamVerification()` → `POST /api/bot/lock` で10分ロックを適用し、理由と残り時間のカウントダウン付きロック画面を表示。
- サーバー側 `/api/bot/lock` は検証状態に関係なく動作（管理者のみスキップ）。ロック繰り返し（3回）でBANは従来どおり。

### 補足

- DB変更なし。`APP_VERSION=2026-08-03-023` / `SYSTEM_VERSION=V4.8.711`。旧V4.8.710資産を削除し必須4資産を作成。
- `tests/test_turnstile_bot_detection_regressions.py` の連打ロックテストを「検証済みユーザーでも発動（`!botDetectionVerified` 条件を外す）」に更新。全202件の回帰テスト、Python/JS構文成功。
