# V4.8.660

## Canvas の Blocks から Preview への切替を滑らかに改善

- モバイル版 Canvas の Blocks タブでコードブロックを選択した際、Live Preview が左側からフェードしながら入る短い切替アニメーションを追加しました。
- タブの並び順に基づいてアニメーション方向を決定できる共通処理を追加しました。
- アニメーション中に再度操作された場合は古い状態を破棄し、表示クラスが残らないようにしました。
- OS・ブラウザで「視差効果を減らす」が指定されている場合は、アクセシビリティ設定を優先してアニメーションを無効にします。
- Blocks 選択時のアニメーション指定とCSSキーフレームに対する回帰テストを追加しました。
