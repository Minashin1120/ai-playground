# Update Log (2026-04-14) - V4.8.419

## 修正と改善
* **PDF生成機能のスタイル完全隔離**: 
  * 外部（テーマ設定等）からのスタイル干渉を完全に遮断するため、PDF生成用ラッパー内の全要素に対し、`background-color: #ffffff !important` および `color: #000000 !important` を強制適用する強力なCSSリセットを導入しました。
  * これにより、ダークモード使用時にPDFが黒背景になったり、文字が背景色と衝突して見えなくなる問題を根本的に解決しました。
  * `onclone` 処理での座標リセットをより確実なものに変更。
  * 画像読み込み待機時間を `500ms` に延長し、レンダリングの安定性を向上。

## システム更新
* `APP_VERSION` を `2026-04-14-004` に更新。
* フロントエンドのリソースを `V4.8.419` に更新。
