# V4.8.750 (2026-08-07)

## テーマカラーの初期表示パフォーマンスを改善

- カスタムテーマを設定しているアカウントで、ページ読み込み直後にボタンが反応しない（1〜2秒程度）問題を修正しました。
- 原因は、サーバーが出力するテーマ変数（`--theme-500` 等）のインライン `<style>` が、テーマ既定値を定義するメインCSS（`chat.custom.*.css`）より先に読み込まれていたことです。CSSは同じ詳細度では「後に書かれたルールが勝つ」ため、メインCSSの既定テーマが先勝ちし、初期描画は既定色で行われていました。その後、JSが読み込み時にカスタム色へ変更するため、ページ全体（約125箇所の backdrop-filter やグラデーション等）のスタイル再計算・再レイアウトが発生し、操作可能になるまで遅延していました。
- 修正として、テーマ変数のインライン `<style>` をメインCSSの読み込み後へ移動しました。これにより初回描画からカスタムテーマが正しく適用され、JSによる再適用（値の変更）が不要になり、スタイル再計算を回避できます。
- テーマ未設定のアカウントは既定値のままで変更がないため、影響はありません（従来どおり即座に操作可能）。
