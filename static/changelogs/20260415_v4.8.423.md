# Update Log (2026-04-15) - V4.8.423

## Audio Input Reliability Improvements
- 音声入力（LLM文字起こし）時に「音声が極端に小さい/無音です」というエラーが発生しやすかった問題を改善しました。
- **ハードウェア処理の有効化**: ブラウザ側の録音設定で `echoCancellation` (エコー除去)、`noiseSuppression` (ノイズ抑制)、`autoGainControl` (自動ゲイン制御) を既定で有効にし、入力音量と品質を向上させました。
- **無音判定しきい値の緩和**: サーバー側（`app.py`）での無音判定ロジックを緩和し、静かな環境での囁き声など、比較的小さい入力でも正しく受け付けるよう調整しました。

## WebAuthn / Passkey Support Improvements
- WebAuthn登録時のオプションを更新し、`resident_key=ResidentKeyRequirement.PREFERRED` を追加しました。これにより、Google アカウントなどの同期されたパスキー（Passkeys）をより確実に登録・利用できるようになります。

## PDF Generation Improvements (Rich Paste)
- 大容量のコンテンツ（楽天などの複雑なWebページ全体など）をPDF化する際、ブラウザのCanvasサイズ制限やタイムアウトで処理が止まる問題を修正しました。
- チャンクレンダリング方式を導入し、コンテンツを分割して描画・結合することで、長大なページでも安定してPDF生成が可能になりました。
- 生成中に進捗（0%〜100%）をリアルタイム表示するプログレスバーを実装し、信頼性を向上させました。

## System Updates
- `app.py` の `APP_VERSION` を `2026-04-15-007` に更新。
- フロントエンドのリソースを `V4.8.423` に更新。
