# AI Playground Android v1.25.0

- 回答を待っている間の表示をWeb版と同じにしました。吹き出しの中にモデルに合わせた読み込み中の形（文章・画像・動画・音声・コード）を表示し、「APIに送信中...」「接続完了。モデル応答を待機中...」などの進み具合を表示します。
- Web検索中の「Searching web...」、画像解析の「Image Analysis」、Python実行の「Python Execution」（コードと出力のコピー付き）、生成中のエラー表示をWeb版と同じにしました。
- 通信中は画面の右下に、読み込み中・送信中・保存中などの状態を小さく表示するようにしました。
- 送信時にサーバーのメンテナンス中や接続が切れていた場合、送信内容を保持して自動で再試行するようにしました。回答の受信中に接続が切れたときも、自動で再接続します。これに伴い、手動の「再試行」「再接続」ボタンをなくしました。
- 接続状態のお知らせの文言をWeb版と同じにしました。
