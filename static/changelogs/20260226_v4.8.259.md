# V4.8.259 (2026-02-26)

## 低速回線向け読み込み改善

低速回線（3G/不安定回線）での体感速度改善のため、低速回線モード・キャッシュ強化・gzip圧縮を追加しました。

### 変更内容
* **低速回線モード（自動 + 手動）**: `navigator.connection.effectiveType` / `saveData` を使った自動判定を追加し、サイドバーのトグルから `auto -> on -> off` を切替可能にしました（設定は `localStorage` 保存）。
* **初回メッセージ件数の可変化**: 通常時は初回120件/追加120件、低速回線モード時は初回40件/追加60件に抑制し、長いチャットの初回表示を高速化。
* **テキスト先表示（装飾後回し）**: 低速回線モード時は数式 (`MathJax`) とコード色付け (`highlight.js`) を即時適用せず、テキストを先に表示。可視領域に入った要素から順次装飾する方式に変更。
* **キャッシュ強化（安全な範囲）**: `?v=` 付きまたはバージョン付き静的ファイルに長期キャッシュ (`public, max-age=31536000, immutable`) を適用。`/assets/chat-app.js` はユーザー依存テンプレートのため `private` のままキャッシュ時間のみ延長。
* **gzip圧縮の追加**: HTML / JS / CSS / JSON / SVG の一定サイズ以上のレスポンスに gzip 圧縮を適用（ストリーム応答・`no-transform` 指定は除外）。
