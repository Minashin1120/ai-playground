# 更新履歴 - V4.8.854 (2026-08-26)

## 音声モデルの「真のリアルタイム」会話に対応

OpenAI Realtime / Grok Voice / Gemini native-audio の音声（WebSocket）モデルで、話しながら即座に応答が流れる「真のリアルタイム」音声会話を実装しました。

- サーバーがプロバイダの WebSocket セッションを常時保持し、ブラウザーからマイク音声をリアルタイムに送信します。応答音声と文字起こしは SSE で即時に配信され、発話中も自然に会話が続きます。
- 発話終了の検出（VAD）はサーバー側で行うため、録音→送信→応答待ちの一括操作は不要になりました。話し始めればモデルが応答し、話し掛けると割り込み（バージイン）にも対応します。
- 対象モデル: gpt-realtime-2 / gpt-realtime-translate / gpt-realtime-1.5 / gpt-realtime / gpt-realtime-mini、Grok Voice 全モデル、gemini-2.5-flash-native-audio-preview-12-2025
- 従来の「録音→送信」方式は、文字起こしモデル（GPT Transcribe など）と Gemini Live 直結モデルでは引き続き利用できます。
