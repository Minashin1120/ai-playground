# V4.8.659

## Canvas の Blocks タブを見やすく改善

- Canvas の Blocks タブを、小型チップの折り返し表示から全幅の横長リストへ変更しました。
  - コードブロックを1列で上から順に並べ、生成順を追いやすくしました。
  - 各行にブロック番号、言語、コードの先頭行、表示状態をまとめて表示します。
- 選択中のブロックを背景色、境界線、左端アクセント、状態バッジで明確に判別できるようにしました。
- 長い言語名やコードでも行が縦長にならないよう、省略表示を適用しました。
- キーボード操作とスクリーンリーダー向けのラベルを維持し、コード先頭行も読み上げ対象に追加しました。
- Blocks タブの横長・縦並びレイアウトとコードプレビューに対する回帰テストを追加しました。
