# V4.8.576 変更履歴

**日付:** 2026-06-04

## 主な変更
- **`/settings` コマンドをチャットUIに追加**: メインプロンプトバーで `/settings 自然言語の設定指示` と入力して送信すると、選択中のモデルを使ってAIが設定を解釈・適用するようになりました。
  - プロンプトバーのモデル選択（および各種トグル）をそのまま流用。
  - 成功時はトースト通知 + チャット内に更新サマリーを表示。
  - 失敗時は管理者向け詳細デバッグ（一時的）も利用可能。
- **設定モーダル内の旧AI設定UIを完全削除**: モーダル上の自然言語設定変更UI（紫色のカード、専用モデル選択、適用ボタン、管理者デバッグパネル）は不要になったため削除。ロジックもJSから整理。
- 内部: `/settings` プレフィックス検知による特殊送信ハンドリングを `sendMessage()` に追加。既存の `/api/settings/apply-ai-prompt` を再利用。

これにより、設定変更がより自然にチャット体験に統合されました。
