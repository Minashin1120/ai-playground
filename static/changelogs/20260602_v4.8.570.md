# V4.8.570 (2026-06-02)

## ログイン時の誤ったエラーメッセージ修正（「ネットワークエラーが発生しました」問題）

### 問題
- ユーザー名・パスワードを入力してログインボタンを押した際、特に認証失敗時（パスワード違いなど）に、本来表示されるべき「ユーザー名またはパスワードが正しくありません」ではなく、「ネットワークエラーが発生しました」と表示されるケースがあった。
- 原因:
  - バックエンドの `/login` で AJAX リクエストに対して適切な JSON エラーを返していなかったケース（Turnstile失敗時など英語メッセージ）。
  - フロントエンドの `res.json()` が失敗した場合（サーバーが HTML エラーページを返した場合など）に、無条件で「ネットワークエラー」と表示する実装になっていた。
  - Apache の ProxyErrorOverride や Flask のエラーハンドラにより、500 系エラー時に HTML が返る可能性があった。

### 修正内容
- **バックエンド (`app/app.py`)**:
  - `/login` の AJAX 失敗時メッセージを日本語化:
    - "Invalid credentials" → "ユーザー名またはパスワードが正しくありません"
    - "Auth Error" (Turnstile) → "認証エラーが発生しました"
- **フロントエンド (`app/templates/login.html`)**:
  - メインログインフォームのレスポンス処理を堅牢化:
    - Content-Type を確認し、JSON でない場合は text() でフォールバック解析。
    - JSON パース失敗時も `res.status` に基づいた適切な日本語メッセージを表示（401/403 は認証失敗、5xx はサーバーエラー）。
    - 外側の catch ブロックは「本当のネットワークエラー」の場合のみ表示するようコメントと console.error を追加。
  - TOTP フォームのエラー処理も同様に堅牢化。
- これにより、認証失敗時は常に適切な日本語エラーメッセージが表示され、「ネットワークエラー」という誤解を招く表示が大幅に減少。

### 影響
- ログイン画面のユーザビリティ向上（特にパスワードを間違えた場合のフィードバックが正確になる）。
- その他のページ・機能への影響なし。
