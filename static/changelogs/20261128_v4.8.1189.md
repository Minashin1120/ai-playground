# 更新履歴 - V4.8.1189 (2026-11-28)

### プロジェクト機能（Web版・Android版）
- **プロジェクト管理を追加**: サイドバーの「Projects」セクションからプロジェクトを作成・編集・削除できるようになりました。プロジェクトごとに専用のシステムプロンプトと共有ファイルを設定し、複数チャットで共通の文脈と資料を共有できます。プロジェクトを削除しても所属チャットは削除されず、未所属のチャット一覧へ戻ります。
- **共有ファイルのオンデマンド読込と画像Vision設定**: プロジェクトに追加した共有ファイル（新規アップロードまたはファイルライブラリから選択）は、モデルが必要に応じて参照できます。画像ファイルについてはプロジェクトごとに「Visionモデルを使う」のON/OFF（既定OFF）と使用モデルを選択でき、OFF時は画像の内容を読まずメタ情報のみ渡します。
- **チャット設定・移行・サーバー不使用モードに対応**: Chat Instructionsから所属プロジェクトの切り替えとプロジェクトプロンプトの適用ON/OFFを設定できます。既存チャットの移動・分岐時の所属引き継ぎ、アカウントデータのエクスポート／インポート／重複修復、Web高速モード、およびAndroid版のサーバー不使用モード・オフライン閲覧にも対応しました。
