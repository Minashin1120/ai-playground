# V4.8.719 — 設定画面などの読み込み状態表示を修正

## 修正

- 設定画面を開くGET通信が、設定ボタンの文言に引きずられて「設定を反映中...」と表示される問題を修正しました。
- GET / HEAD通信は、操作したボタン名やURL中の `settings`、`update` などの単語よりHTTPメソッドを優先し、「読み込み中...」から「受信中...」へ切り替えるよう統一しました。
- 設定保存などの更新通信では、従来どおり「保存中...」など操作内容に合った表示を維持します。
- 共通スピナーを利用する全画面の `fetch` / XMLHttpRequest に同じ判定を適用しました。
