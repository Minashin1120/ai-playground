# 更新履歴 - V4.8.969 (2026-09-14)

- サイドメニューに「Batch処理」を追加し、Gemini・OpenAI・xAI のBatchジョブを一覧で確認できるようにしました。
- 一覧には状態（送信待ち・待機中・実行中・結果取得中・完了・失敗・停止など）、モデル、プロバイダー、作成時刻を表示し、「すべて／実行中／終了」のタブで絞り込めます。
- 実行中のBatch処理を「停止」からキャンセルできるようにしました。
- 完了・失敗したBatch処理の履歴は自動で消えず、「履歴から削除」を選んだときだけ削除されます。
- 各項目の「開く」から、そのBatch処理を行ったチャットを開けるようにしました。
