# Update 2026-03-19 (v4.8.360)

### 追加: 履歴スレッドのPDF出力
- **PDF出力ボタン**: `新規チャット` の `+` の横に追加し、現在のスレッド履歴を PDF 用の印刷ページへ送れるようにしました。
- **全件再取得**: 画面上の DOM をキャプチャせず、サーバー側でスレッドの全メッセージを再取得してから印刷ページを生成する方式に変更しました。
- **欠落防止**: 未読込の過去メッセージが抜ける、読み込み途中の内容だけが PDF になる、といったキャプチャ系の不具合を避ける設計にしています。
- **ポップアップ回避**: `window.open` をやめ、同タブ遷移で PDF ページを開くようにして、ブラウザのポップアップ許可やキャンセルでサイト側エラーが出ないようにしました。
