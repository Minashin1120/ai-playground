# v4.8.502 (2026-05-09)

## Grok Imagine 画像生成の強化
- **grok-imagine-image-quality モデルへの対応**
  - 新しい画像生成モデル `grok-imagine-image-quality` を追加しました。
  - **解像度 (1K / 2K) の選択に対応**しました。1Kは $0.05、2Kは $0.07 で生成可能です。
  - 従来の `grok-imagine-image-pro` は非推奨（Deprecated）となり、リストの下位に移動しました。
- **UIの改善**
  - Grok画像生成オプションに「解像度」設定を追加しました。
  - 選択したモデルが `grok-imagine-image-quality` の場合のみ解像度設定が表示されるように最適化しました。
  - セットアップ画面に Grok Imagine カテゴリを追加しました。
