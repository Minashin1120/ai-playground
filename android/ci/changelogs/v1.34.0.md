# AI Playground Android v1.34.0

- メッセージの「Python」ボタンで、Python 実行結果を開けるようにしました。
- 送信したときと回答が完了したときに、Web版と同じく端末を振動させるようにしました。
- 回答の生成中やファイルの送信中に送信しようとしたとき、添付が上限を超えたとき、再生成できないときに、Web版と同じ通知を表示するようにしました。
- メッセージの編集を始めると元の引用を戻し、入力欄にカーソルを移すようにしました。編集のキャンセルでは引用も消します。
- `/` と `@` の候補を、入力欄から離れると閉じるようにしました。`@` の候補は入力が `@` で始まるときに表示し、Gemを適用すると通知してチャットに保存します。
- チャットを開くと、そのチャットで最後に使ったモデルとPromptCacheの状態、ブランチ管理で固定した分岐を反映するようにしました。新しいチャットでは入力欄とPromptCacheを初期化します。
- 一時チャットの切り替えで、チャットのタイトルが変わってしまう不具合を修正しました。一時チャットの画面に「一時チャット設定」ボタンを追加しました。
- PDF出力で、表示中の分岐を出力するようにしました。
- メッセージの文章を、段落をまたいで選択できるようにしました。
- Batchをオンにすると、Coding Modeを解除するようにしました。PromptCacheがオンのときは、チップを枠で囲んで表示します。
- サイドバーからGemや設定などを開いたときに、サイドバーを閉じないようにしました。チャットは読み込みが終わってからサイドバーを閉じます。
- 回答の生成中は、Web版と同じく画面の最下端まで追従するようにしました。上へスクロールすると追従を止め、最下端付近まで戻ると再開します。「一番下へ」ボタンは追従を止めているときに表示します。
- 画像ビューアーで、左右にスワイプして前後の画像へ移動できるようにしました。回答の中の画像も前後移動の対象になります。
