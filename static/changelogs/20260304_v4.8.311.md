# Changelog - V4.8.311 (2026-03-04)

## 改善: 初回トークン待機時間の計測ログを追加
* **フロントエンド計測を追加**:
    * `templates/chat_app.js` の `sendMessage()` で、プロンプト送信開始から回答本文（`content`）の初回表示までの経過時間を計測するようにしました。
    * 初回表示時に、秒数（`latency_seconds`）とミリ秒（`latency_ms`）、モデル名、スレッドID、ジョブIDをサーバーへ送信します。
* **サーバー記録APIを追加**:
    * `app.py` に `POST /api/metrics/first_token` を追加し、受信した計測値を保存するようにしました。
    * 24時間ウィンドウの件数・平均・最小・最大を集計し、デバッグログへ出力します。
* **保存テーブルを追加**:
    * `FirstTokenLatencyMetric` モデル（`first_token_latency_metric` テーブル）を追加し、初回トークン待機秒数を時系列で記録できるようにしました。

## 付随更新
* `templates/chat.html` の表示バージョンを `V4.8.311` に更新。
* `chat_app.js` のキャッシュバスターを `v4.8.311` に更新。
