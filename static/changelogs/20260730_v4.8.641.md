# V4.8.641 — Gemini 3.6 Flash / 3.5 Flash-Lite 対応

**リリース日:** 2026-07-30

## 追加

- Google公式のGAモデル `gemini-3.6-flash` を追加
  - 入力 $1.50 / 100万トークン、出力 $7.50 / 100万トークン
  - Thinkingは公式仕様に合わせて `medium` / `high` に対応
- Google公式のGAモデル `gemini-3.5-flash-lite` を追加
  - 入力 $0.30 / 100万トークン、出力 $2.50 / 100万トークン
  - Thinkingは `minimal` / `medium` / `high` に対応

## 変更

- 新規ユーザーとクイックスタートの既定モデルを Gemini 3.6 Flash に変更
- 新2モデルでは非推奨の `temperature` / `top_p` / `top_k` をAPIへ送信しないよう対応
- 停止済みの `gemini-3.1-flash-lite-preview` は過去チャット互換の内部定義を維持し、モデル選択UIと初期設定画面から非表示化
- 同プレビューモデルを既定・直近モデルにしていたユーザー設定は、安定版の `gemini-3.5-flash-lite` へ自動移行
