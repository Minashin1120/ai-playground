# V4.8.605 — 未アニメーションUIへの入場アニメ追加

**日付:** 2026-07-09  
**種別:** UI モーション（機能変更なし）

## 概要

アニメーションが付いていなかった表示・出現箇所を洗い出し、適切な入場アニメを追加。

## 追加対象

- 画像ビューア / ファイルビューア（フェード＋パネル入場）
- 引用バー / 引用ポップオーバー
- `/` と `@` のサジェストメニュー（本体＋リスト項目のスタッガー）
- ドロップオーバーレイ、ファイルプレビュー帯
- トークンバー、低速回線ピル、Gem/Slash インジケータ
- 固定プロンプトチップ、編集バー、STS パネル
- アップロード行、セッション一覧、ライブラリサムネ
- モバイルサイドバー用オーバーレイ、検索ボックス（Web検索中）
- ブランチツリーノード、ストレージ使用バー
- 一時チャット歓迎パネル

## 備考

- イージングは V4.8.604 のモーション変数を利用
- `prefers-reduced-motion` で無効化
