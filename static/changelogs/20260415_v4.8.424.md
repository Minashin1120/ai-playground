# Update Log (2026-04-15) - V4.8.424

## Audio Input Reliability Adjustments
- 音声入力時のハードウェア処理設定（エコー除去、ノイズ抑制、自動ゲイン制御）を、囁き声や小声がノイズとして遮断されないよう、以前の「無効」設定に戻しました。
- これにより、デバイス側の補正に頼らず、生に近い音声をサーバーへ送るようになります。
- サーバー側の無音判定しきい値の緩和（RMS 80 -> 30, Peak 600 -> 250）は維持し、小声でもエラーにならずに受け付けるよう調整されています。
