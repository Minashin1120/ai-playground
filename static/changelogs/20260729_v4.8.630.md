# V4.8.630

画像を添付したチャットの送信後に `Connection Error: DOMPurify is not defined` が表示され、再読み込み後もチャットを開けなくなる問題を修正しました。

- DOMPurify の配信内容と一致しない SRI ハッシュにより、ブラウザがライブラリを遮断していた問題を修正
- チャット表示に必須の DOMPurify 3.4.11 と Marked 4.3.0 を同一オリジンから配信し、外部 CDN 障害の影響を排除
- ライブラリを利用できない場合でも、安全にエスケープした平文表示へ切り替えて送信・履歴読込全体が停止しないよう改善
- SRI ハッシュ、ローカル配信、Markdownフォールバックを検証する回帰テストを追加
