# V4.8.650 (2026-07-31)

## モデルのコード実行で作成された一部画像の表示不良を修正

- Geminiのコード実行結果がSVG画像を返した場合に、内容はSVGのまま拡張子だけ `.png` となり、回答バブルと画像ビューアーで欠落アイコンになる問題を修正しました。
- コード実行由来のSVGは、スクリプト、イベント属性、外部リソースなどを拒否したうえで、安全なPNGへ変換して保存・表示します。
- PNG、JPEG、WebP、GIFは宣言されたMIMEタイプではなく実データから形式を判定し、画像ではない `inline_data` を誤って画像として表示しないようにしました。
- ストリーム内で同じ画像パートが繰り返された場合は内容ハッシュで重複を除外します。
- 保存名を秒単位の固定連番からミリ秒と乱数を含む一意名へ変更し、同じ秒に複数画像が返る場合の保存先衝突を防止しました。
