# v4.8.735 — アカウント削除が失敗する問題を修正

アカウント削除ができない問題を修正しました。

- チャットの応答速度の診断データ（初回トークンまでの時間、遅延トレース）をアカウント削除時に確実に削除するよう修正しました。これらのデータはアカウントとの関連付けのため削除時に外部キー制約が残り、ユーザーごと削除できない状態になっていました。データの追加は既にすべての利用者に影響するもので、診断機能のオフ状態でも一定のデータが記録される運用であるため、削除対象に含めています。
- ボット検出（Turnstile 検証）や一時ロックの仕組みが原因でアカウント削除がブロックされることがないよう、アカウントの自己削除操作を対象外にしました。ログイン済みの本人が自分のアカウントを削除する操作は、検証待ち状態でも実行できる必要があるためです。
- 設定画面でアカウント削除が失敗した場合に、画面遷移だけでなくエラーメッセージを表示するよう修正しました。従来は失敗してもトップページへ戻ってしまい、削除されていないことが分かりませんでした。削除に成功した場合のみトップページへ移動します。
- 管理者のアカウント管理（Bot Detection）モーダルから削除した際、サーバーがエラーを返した場合にエラー内容を表示するよう修正しました。従来はエラーレスポンスが JSON でない場合に何も表示されないことがありました。
