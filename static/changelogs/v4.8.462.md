# v4.8.462 (2026-04-28)

### 🚀 新機能
- **Android Chrome エッジツーエッジ（Edge-to-Edge）対応**
  - Android版Chrome 135以降でのナビゲーションバー透明化に対応しました。
  - `viewport-fit=cover` の導入により、コンテンツを画面最下部まで拡張しました。
  - `safe-area-inset-bottom` を考慮したレイアウト調整を行い、下部要素（チャット入力欄、サイドバー等）がナビゲーションバーに隠れないよう改善しました。

### 🛠 改善・修正
- システムバージョンを V4.8.462 に更新しました。
- CSSファイルをバージョンアップし、セーフエリア対応のスタイルを追加しました。
