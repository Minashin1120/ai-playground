# 2026-03-22 V4.8.368

## 改善内容
- Windows の「アニメーション効果」OFF で `prefers-reduced-motion` が有効な場合でも、アニメーション依存で `opacity-0` が残る要素を表示するように修正しました。
- `slide-in-animate` / `model-list-animate` / `wave-char` / `fade-in` / `message-group` / `modal-animate` / `edit-bar-animate` を reduced motion 時に最終状態へ固定するよう CSS を拡張しました。
- reduced motion 時は `html` の `scroll-behavior` も即時モードに切り替え、不要なスクロール演出を止めました。
