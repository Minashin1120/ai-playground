# V4.8.754

- **Gemini コード実行（Agentic View）で生成画像が表示・ダウンロードできない問題を修正**
    - **内容**: Gemini のコード実行ツールが出力する `![...](sandbox:/mnt/data/...)` 形式のサンドボックス参照がそのままメッセージに保存され、ブラウザーでは読み込めず画像が表示されない・ダウンロードできない問題を修正。画像データ（`inline_data`）を取得できた場合は実際の保存先 URL（`/files/...`）に書き換えて表示・ダウンロード可能にし、取得できなかった場合は画像データを取得できなかった旨の注記に置き換えるよう変更しました。
    - **内容**: 既に保存済みのメッセージに含まれる `sandbox:` 参照についても、フロントエンド側で壊れた画像として表示されないよう保護しました。
