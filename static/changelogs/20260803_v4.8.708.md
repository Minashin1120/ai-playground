# V4.8.708 (2026-08-03)

## 送信ボタン連打時のボットチェックダイアログを「検証済みユーザーには出さない」よう調整

V4.8.707 で追加した送信ボタン連打ダイアログを、**検証済みユーザーには表示しない**よう変更しました。

### 背景

送信ボタン連打によるサーバー負荷は、実装上ほぼ発生しません（送信中はボタンが停止モードになり送信が発火しない・`abortController`ガード・サーバー側の`client_request_id`による重複409/425拒否のため）。そのため、V4.8.707 の連打ダイアログは「保険」でしたが、**検証済み（Turnstile通過済み）の通常ユーザーにも出るのは過剰**という判断になりました。

### 変更内容（`chat_core.v4.8.708.js`）

- `sendMessage()` 冒頭の連打検知を `if (isBotDetectionActive() && !botDetectionVerified)` に変更。
- **検証済みユーザー（`botDetectionVerified=true`、Redisマーカーあり）** には連打ダイアログを表示しない。
- **未検証・検証中（サイレント検証が完了していない）ユーザー**にのみ、2秒以内5回以上の連打でボットチェックダイアログ（Turnstile）を表示して検証を求める。

### 補足

- DB変更はありません。
- `tests/test_turnstile_bot_detection_regressions.py` の連打ダイアログテストに「検証済みユーザー対象外（`!botDetectionVerified`条件）」を追加。全197件の回帰テスト、Python/JS構文成功。
