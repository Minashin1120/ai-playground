# AI Playground Android v1.21.0

- モデル選択画面をWeb版と同じ構成にしました。検索欄ではモデル名に加えて API のモデル名や対応機能でも探せます。上部のタグで提供元や用途を絞り込めます。カテゴリごとの見出しと説明を表示し、カードには API のモデル名、価格、Agentic View 対応を表示します。
- PromptCache が有効なときは、選択できる提供元をモデル選択画面の上部に表示し、その提供元のモデルだけを一覧に出すようにしました。
- Gem の作成・編集画面をWeb版と同じ項目と表記にしました。固定プロンプトは「名前」と「プロンプト内容」を1行ずつ追加・削除できます。
- SysPrompt の歯車から開く「Chat Instructions」をWeb版と同じ内容にしました。このチャット専用の指示に加えて、全体システムプロンプトの確認、ユーザーシステムプロンプトの編集、自動注入プロンプトの設定もここで行えます。
