# 更新履歴 (V4.8.452) - 2026-04-26

## サーバー側リッチ貼り付けPDF生成の修正と強化

### 修正内容
* **400 Bad Request エラーの解消**:
    * クライアントから送信された大容量の JSON ペイロードをより確実に取得できるよう、リクエスト処理を堅牢化しました。
    * `request.get_json()` と `request.get_data()` の併用時におけるストリーム消費問題を修正しました。
* **PDFレイアウト生成の安定化**:
    * `ReportLab` でのテーブル生成時に発生し得たゼロ除算エラーを防止するガードを追加しました。
    * 表内のセルが空の場合のフォールバック処理を改善しました。
    * 長大な `Preformatted` ブロック（ソースコード等）によるレイアウト崩れやビルドエラーのリスクを軽減するため、内部的な例外ハンドリングを強化しました。
* **エラーハンドリングとリカバリ**:
    * PDFビルドに失敗した場合、シンプルなエラーメッセージを含むPDFを代わりに生成して返すフォールバック機能を実装しました（完全にダウンロードに失敗する状態を回避）。
* **デバッグログの強化**:
    * 生成プロセスの各段階（ペイロード取得、タイトル長、HTML長、生成成功/失敗、ファイルサイズ等）で詳細な `log_force` を追加し、トラブルシューティングを容易にしました。

### バージョン情報
* `app.py` の `APP_VERSION` を `2026-04-26-003` に更新。
* `chat.html` の表示バージョンを `V4.8.452` に更新。
