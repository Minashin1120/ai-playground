# 更新履歴 - V4.8.1024 (2026-09-23)

Androidアプリ向け認証のセキュリティを強化しました。アプリからのログインと新規登録では、端末の安全性を確認できない場合に必ずTurnstileによる確認を行うようにしました。ブラウザー経由のGoogle・Minashinログインは、ログインを開始したアプリだけが完了できるようにしました。アプリでのパスキーログインは、Webと同じく「パスキーのみログイン」を有効にしたアカウントに限定しました。初回設定の完了後は、アプリからの初回設定の再送信とアカウントデータの取り込みを受け付けないようにしました（取り込みはWebから行えます）。Android端末連携の確認画面に、他の人から届いたリンクやコードを許可しないよう注意を表示しました。
