# V4.8.710 (2026-08-03)

## 回答の引用（Quote）ボタンが表示されない問題を修正

テキストを選択した際に表示される「Quote」ボタン（回答の一部を引用して質問する機能）が、V4.8.603 のUIリデザイン以降表示されなくなっていました。ロジック（選択検出・引用バー・送信時の `quote_text` 送信）は残っていたため、原因はUI側の構造でした。

### 原因（`chat.html` / `chat.custom.css`）

- V4.8.603のリデザインで `.composer-dock` に `backdrop-filter: blur(...)` が追加されました。
- CSS仕様上、`backdrop-filter` を持つ要素は**子の `position: fixed` 要素の包含ブロック**になります。
- 引用ボタン `#quote-popover` は `position: fixed` で、JSが選択位置のビューポート座標（`getBoundingClientRect`）を `top` / `left` に設定していますが、`.composer-dock` 内にあったため座標がドック基準に解釈され、ボタンが画面外（上方向）へ押し出されて見えなくなっていました。

### 修正（`chat.html`）

- `#quote-popover-container`（引用ボタン）を `.composer-dock` の外、`<body>` 直下へ移動しました。これで `backdrop-filter` / `transform` を持つ祖先がなくなり、`position: fixed` が正しくビューポート基準で配置されます。
- 引用バー `#quote-bar` はコンポーザー上部に表示する通常フロー要素のため、`composer-dock` 内のまま変更なしです。
- ロジック（`handleQuotePopover`、`currentQuote`、`quote_text` 送信・保存・履歴表示）は変更なしでそのまま動作します。

### 補足

- DB変更はありません。
- Python/JS構文チェック成功。回帰テストは前バージョンのスイートで確認。
