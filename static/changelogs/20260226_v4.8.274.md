# V4.8.274 (2026-02-26)

## STTボタンのLLM文字起こしを「現在の既存モデル」連携へ修正 + 500エラー修正

前回の `V4.8.273` で追加した STTボタンのLLM文字起こしについて、`gpt-audio-mini` 固定実装ではなく、現在選択中の既存LLM（主に OpenAI / Gemini）を使う方式に修正しました。あわせて 500 エラーになっていた経路を修正しました。

### 変更内容
* **仕様修正**: LLM文字起こしは `gpt-audio-mini` 固定ではなく、現在選択中のモデル（`model-select`）を `/transcribe` に渡して実行するよう変更。
* **フロント連携**: STTボタン実行時（非STSモード）に `llm_model` として現在のモデルIDを送信するよう変更。
* **バックエンド修正**: `/transcribe` の LLMモードで OpenAI/Gemini の既存LLM経路を使うよう修正（OpenAI は Responses API 音声入力、Gemini は `generate_content` + 音声入力）。
* **500エラー修正**: `gpt-audio-mini` 固定の不整合な実装を廃止し、LLMモードの例外を整理。未対応モデルは `400` で明示エラーを返すよう改善。
* **UI文言修正**: 設定 > 音声設定の選択肢文言を `現在のLLM（既存モデル）` に変更。
* **表示バージョン更新**: `chat.html` の表示バージョンと `chat_app.js` キャッシュバスターを `V4.8.274` に更新。
