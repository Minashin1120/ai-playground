# Update V4.8.552 (2026-05-27)

### xAI Grok Build 0.1 (Coding) モデルの正式サポート

xAI公式ドキュメント（docs.x.ai）で2026年5月頃に公開された新モデル **Grok Build 0.1**（エイリアス: grok-code-fast-1 / grok-code-fast）をPlaygroundに追加実装しました。

- **モデルID**: `grok-build-0.1`
- **用途**: Agentic coding / ソフトウェアエンジニアリング特化の高速モデル（vision対応、function calling、structured outputs、reasoning対応）
- **コンテキスト**: 256k tokens
- **価格**: Input $1.00/1M tokens, Output $2.00/1M tokens（公式準拠）
- **UI追加箇所**:
  - モデル選択リスト（xAI Grok カテゴリ）
  - ウェルカム画面クイックスタートボタン
  - セットアップ画面のデフォルトモデル選択肢
- **内部対応**:
  - 推論（Thinking / reasoning_effort）UI・バックエンド判定ロジックを更新し、本モデルでも `enable_thinking` や reasoning effort 選択が有効化
  - xAIネイティブSDK経由のツール呼び出し（code_execution / search）および画像入力が既存Grok経路でそのまま利用可能

Grok 4.3 と併用して、コーディング用途では Build 0.1 を推奨します。既存の 4.20 系 / Fast 系モデルも引き続き利用できます（エイリアス経由で最新フラッグシップに解決される場合あり）。
