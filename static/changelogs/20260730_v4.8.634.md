# V4.8.634 — Kimi K3 (Moonshot AI) モデル追加

## 🚀 新機能

- **Kimi K3 モデルを実装**: Moonshot AI のフラッグシップモデル `kimi-k3`（2.8Tパラメータ、1Mコンテキスト）を追加。
  - Kimi API Platform（`api.moonshot.ai/v1`）の OpenAI 互換 Chat Completions API を使用。
  - ストリーミング対応（`reasoning_content` と `content` を分離）。
  - `reasoning_effort` パラメータ対応（`low` / `high` / `max`、既定 `max`）。
  - 環境変数 `MOONSHOT_API_KEY` または設定画面の Kimi API Key で認証。
  - 価格: Input $3.00/1M（Cache Miss）/ $0.30/1M（Cache Hit）、Output $15.00/1M。
  - モデル選択 / クイックスタート / セットアップ画面に対応。
  - 設定画面に Kimi API Key 入力欄を追加。
