# 更新履歴 (V4.8.56) - 2026-01-31

## Grok Imagine Video 修正
- **動画URL抽出ロジックの改善**
    - xAI API の一部のレスポンス形式で、動画 URL が `video` オブジェクト内にネストして返されるケースに対応しました。
    - これにより、動画生成が完了しているにもかかわらず URL が見つからず待機し続けてしまう問題を解消しました。

## ドキュメント更新
- README を現行仕様 (V4.8.56) に合わせて全面更新。
- Windows ローカル実行手順 (WSL2 推奨 / ネイティブ手順の注意点) を追加。

## Grok Imagine 画像編集の修正
- **/v1/images/edits の Content-Type 対応**
    - 画像編集時に JSON + base64 形式で送信するよう修正し、415 (Unsupported Media Type) を解消。
    - xAI 公式ドキュメントに合わせて edits リクエストを JSON 化。

## チャットごとの最終モデル記憶
- **スレッド別のモデル保存**
    - チャットごとに最後に使用したモデルを保存し、再表示時に自動で復元。
    - これによりチャット専用のシステムプロンプト運用が安定。

## クリップボード貼り付け時のアップロードモーダル抑止
- **画像貼り付け時に自動オープンしない**
    - クリップボードから画像を貼り付けた場合は、アップロードモーダルを開かずに処理。

## 履歴/送信不可の復旧
- **thread.last_model 未反映による500を修正**
    - 起動時に `thread.last_model` の列を自動チェック/追加し、/api/threads の500エラーを解消。
