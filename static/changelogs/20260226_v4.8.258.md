# V4.8.258 (2026-02-26)

## 読み込み軽量化（初回ロード / 長いチャット）

読み込み速度の改善として、初回表示の軽量化と長いチャットの段階読み込みを実装しました。

### 変更内容
* **`chat.html` の軽量化**: 大きなインラインCSS/JSを分離し、CSSは `static/css/`、メインJSはテンプレートJS (`templates/chat_app.js`) として別配信に変更。
* **Tailwind CDNの廃止**: `cdn.tailwindcss.com` をやめ、事前ビルドした Tailwind CSS (`static/css/chat.tailwind.v4.8.258.css`) を使用するよう変更。
* **MathJax / Highlight.js の遅延ロード**: 初回表示では読み込まず、数式やコード表示が必要になった時点で動的ロードするよう変更（画像圧縮ライブラリは現状維持）。
* **長いチャットの段階読み込み**: `/api/threads/<id>` に `limit` / `before_id` を追加し、初回は最新メッセージのみ取得・必要時に「過去メッセージを読み込む」で追加取得する方式を実装。
* **DEBUGログI/Oの抑制**: `DEBUG:` プレフィックスの `log_force()` を既定で抑制（`VERBOSE_DEBUG_LOGS=1` で再有効化可能）。
