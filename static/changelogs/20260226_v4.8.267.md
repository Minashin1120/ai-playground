# V4.8.267 (2026-02-26)

## チャット履歴の行クリックで開けないことがある不具合を修正

サイドバーのチャット履歴で、タイトル文字以外（余白や「一時」バッジ付近）をクリックした場合にチャットが開かず、画面が切り替わらないことがある問題を修正しました。

### 変更内容
* **履歴行全体をクリック対象化**: `templates/chat_app.js` の履歴リスト描画で、タイトル文字だけでなく履歴行全体のクリックで `loadMessages()` を実行するよう変更。
* **操作ボタンは除外**: スター / リネーム / 削除ボタン領域は従来どおり個別動作し、チャットを開く処理が誤発火しないようガードを追加。
* **キャッシュ対策**: `templates/chat.html` の `chat_app_js` 読み込みURLのキャッシュバスターを `-v4.8.267` に更新。
* **表示バージョン更新**: `chat.html` のタイトル表示を `V4.8.267` に更新。
