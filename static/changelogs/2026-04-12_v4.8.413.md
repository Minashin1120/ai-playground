# Update v4.8.413 (2026-04-12)

## 修正内容
* **Gemini 3.1 Flash Live STS の「体感 1秒」への挑戦（超高速化）**
  * **ストリーミング開始の早期化**: 音声変換（FFmpeg）と AI 接続の待ち時間を排除するため、これらをストリーミングレスポンスの「内部」に移動しました。これにより、アップロード完了後 **0秒** でレスポンスが開始され、UI が即座に反応します。
  * **インメモリ・パイプ処理の導入**: FFmpeg の処理をディスク I/O を介さないパイプ方式に刷新。音声変換にかかる物理的な時間をミリ秒単位で短縮しました。
  * **AI への送出最適化**: Gemini Live API への音声データ送信を細かなチャンク（4KB）に分割。AI がより早く内容を把握し、回答を開始できるように改善しました。
* **バージョン更新**
  * システムバージョンを `2026-04-12-014` に更新しました。
  * `chat_core.js` を `v4.8.413` に更新しました。
