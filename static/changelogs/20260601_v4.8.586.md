# V4.8.586 (2026-06-01)

## 会話履歴再構築時にGem指示をユーザーメッセージに前置き

各メッセージに保存された `gem_uuid` をもとに、会話履歴再構築時に該当Gemのinstructionをそのユーザーメッセージの内容に前置きするようにしました。

### これまでの問題
V4.8.586(初版)では Gem の instruction を `role: system` として履歴に注入していたため、Gem A → Gem B に切り替わった後も Gem A の指示が履歴に残り続け、後続のプロンプトに影響を与えていました。

### 今回の修正
履歴の system message 注入を廃止し、代わりにユーザーメッセージの内容に直接 Gem 情報を前置きする方式に変更:
- 同一Gemが連続する場合は最初の1メッセージのみに前置き（`last_gem_uuid` で重複防止）
- Gem未選択のメッセージには何も付与しない
- system messageではないため後続ターンに影響しない
- フォーマット: `[Gem: {name}]\n{instruction}\n\n---\n\n{元のメッセージ}`
